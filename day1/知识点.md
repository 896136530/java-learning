# Day 1 知识点：变量与数据类型

> 本文件只讲知识点，练习题见《练习题和代码题目.md》，做完再看《标准答案.md》。

## 1. 变量是什么
程序 = 数据 + 操作。**变量就是给数据起的名字**，本质是一块内存空间：
```java
int age = 20;   // 声明一个 int 类型的变量 age，赋值为 20
```

## 2. Java 的 8 种基本类型（背下来）
| 类型 | 大小 | 范围 | 例子 |
|---|---|---|---|
| byte | 1 字节 | -128 ~ 127 | `byte b = 100;` |
| short | 2 字节 | 约 ±3.2 万 | `short s = 30000;` |
| int | 4 字节 | 约 ±21 亿 | `int age = 20;` |
| long | 8 字节 | 约 ±9.2×10^18 | `long big = 9000000000L;`（**L 后缀**） |
| float | 4 字节 | 小数 | `float f = 3.14f;`（**f 后缀**） |
| double | 8 字节 | 小数（默认） | `double pi = 3.14;` |
| char | 2 字节 | 单个字符 | `char ch = 'A';`（单引号） |
| boolean | — | true / false | `boolean ok = true;` |

**注意**：小数默认是 double；字符串不是基本类型，是 String 类（双引号）。

## 3. 命名规范
- 变量/方法：小驼峰 `myAge`、`totalPrice`
- 类名：大驼峰 `StudentInfo`
- 常量：全大写 `MAX_SIZE`
- 不能以数字开头，不能用关键字（int、class、public…）

## 4. 类型转换（重点，全是坑）
- **自动提升**（小 → 大）：`int i = 100; long l = i;` 没问题
- **强制转换**（大 → 小）：`int x = (int) 3.99;` 结果是 3（**截断，不是四舍五入**）
- **整数除法**：`7 / 2` 结果是 **3**（不是 3.5！）；想得小数要写 `7.0 / 2`
- **溢出**：int 存不下的大数会"绕一圈"，如 `2000000000 * 4` 变成负数
- 字符也能当数字：`'A' + 1` 是 66（'A' 的编码是 65）

## 5. 常量与 var
```java6
final double PI = 3.14159;  // final = 常量，赋值后不能改
var name = "小明";           // JDK10+ 自动推断类型（了解即可）
```
