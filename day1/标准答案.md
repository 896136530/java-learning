## 题 1 答案
```java
byte b = 100;
short s = 30000;
int age = 20;
long big = 9000000000L;   // 不加 L 编译报错
float f = 3.14f;          // 不加 f 编译报错（默认当 double）
double pi = 3.1415926;
char ch = 'A';            // 单引号
boolean ok = true;

System.out.println("byte=" + b + " short=" + s + " int=" + age + " long=" + big);
System.out.println("float=" + f + " double=" + pi + " char=" + ch + " boolean=" + ok);
```

## 题 2 答案
```java
System.out.println("7 / 2   = " + (7 / 2));     // 3    ← 整数除法截断
System.out.println("7.0 / 2 = " + (7.0 / 2));   // 3.5  ← 有小数参与就是小数除法
System.out.println("7 % 2   = " + (7 % 2));     // 1    ← 取余数
System.out.println("(int)3.99  = " + (int) 3.99);  // 3   ← 截断，不四舍五入
System.out.println("(int)-3.99 = " + (int) -3.99); // -3  ← 向零截断
```

## 题 4 答案
临时变量法：
```java
int tmp = a;
a = b;
b = tmp;
```
不借临时变量（加减法技巧，面试偶尔问）：
```java
a = a + b;  // a = 10
b = a - b;  // b = 3
a = a - b;  // a = 7
```

## 题 5 答案
- `int x = 9000000000;` 编译报错：`integer number too large`（整数太大）。改成 `long x = 9000000000L;` 即可。
- `2000000000 * 4` 打印结果是 **-589934592**（负数）——80 亿在 32 位 int 里溢出"绕了一圈"（2^32 = 4294967296，80亿 - 2×2^32 = -589934592）。
- **思考答案**：int 占 4 字节 = 32 位，去掉符号位最大 2^31-1 ≈ 21.47 亿，90 亿超过了；long 占 8 字节 = 64 位，最大约 9.2×10^18，所以装得下。
