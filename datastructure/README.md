# 📘 数据结构跟课线（datastructure/）

> **第三条线，定位与众不同：它不是刷题线，是"课本跟读线"。**

## 为什么单独开这条线

| 线 | 定位 | 跟什么 |
|---|---|---|
| `java/` | 🟦 就业主线 | 你自学的 Java 后端（Day 系列 + 项目） |
| `lanqiao/` | 🟩 蓝桥杯线 | Python 大学 B 组刷题（竞赛加分） |
| `datastructure/` | 📘 **课本跟课线** | 学校课程《数据结构（C语言版·第2版）》+ 考研 408 考点 |

数据结构这门课是你的**学校课程**，冲着绩点、期末、**考研 408**去的——和自学线完全两个体系，所以单独一个家。

## 书目

- **《数据结构（C语言版·第2版）》** 严蔚敏、吴伟民（第2版）· 清华大学出版社
- 国内经典教材：408 考研 + 绝大多数高校数据结构课都用它
- 配套 AnyviewC 可视化教学软件，双色印刷

## 内容形态（每章三件套）

1. **知识点.md** —— 思想笔记：以教材视角讲清"这个东西解决什么问题"，伪码/图示为主
2. **Python落地.py** —— 把算法亲手用 Python 写一遍（**落地用 Python**，不是 C——学思想，不背语法；顺手就是蓝桥的招式）
3. **蓝桥考点.md** —— 这一章的知识在蓝桥 Python 组怎么考、考多深（该深学的深学，该了解的了解）

> C 语言代码：课本/AnyviewC 作业**需要时**喊我，按章补 C 样板（平时不写，省时间）。

## 节奏

**跟学校课表走**——老师讲到哪章，我们就建哪章、练哪章。不抢跑、不欠债。
