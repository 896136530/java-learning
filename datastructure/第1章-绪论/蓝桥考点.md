# 第1章 绪论 —— 蓝桥考点 & 热身

## 这章在蓝桥怎么考

结论先行：**概念题几乎不考，但复杂度直觉是选算法的命根子。**

| 考法 | 说明 | 重要度 |
|---|---|---|
| 直接背概念 | 蓝桥笔试无简答，基本不考 | ☆ |
| 选算法靠大 O | 每题先看 n 范围，高了换低阶算法 | ★★★★★ |
| 公式 vs 循环陷阱 | 能 O(1) 就不 O(n)，能 O(n) 就不 O(n²) | ★★★★★ |

### 蓝桥实际约束（记住这组数字）

- Python 组每题限时通常 **1 秒**
- 约能跑 **10⁷ ~ 10⁸** 次简单操作
- 所以：n ≤ 10⁴ → O(n²) 勉强；n = 10⁵~10⁶ → 只敢 O(n log n) 或 O(n)；n = 10⁹ → 只配 O(1) 或 O(log n)

### 经典场景：求和

1~n 求和：
- 循环累加 → O(n)，n=10⁹ 时**必超时**
- 等差公式 `n*(n+1)//2` → O(1)，**秒过**

这就是用公式把复杂度降下去的教科书例子，也是蓝桥第一梯队送分题的常见陷阱。

**T1 求和**：输入一个整数 n（1 ≤ n ≤ 10⁹），输出 1+2+…+n 的值。
- 想想：n 最大 10⁹，循环能过吗？用哪招？

**T2 判断素数**：输入整数 x（1 < x ≤ 10⁹），输出 `是素数` 或 `不是素数`。
- 提示：试除法只试到哪个数就够了？这决定了你的是 O(n) 还是 O(√n)。
