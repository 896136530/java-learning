## 1. 数据结构学的是什么

一句话：**逻辑结构（长什么样）+ 存储结构（怎么存）+ 运算（能干什么）**。

- 逻辑结构：数据之间是什么关系（抽象层面）
- 存储结构：这个关系在计算机内存里怎么落地（实现层面）
- 运算：插删改查、遍历、排序…

> 类比：逻辑结构 = 交友关系图，存储结构 = 通讯录用"数组还是链表"存好友，运算 = 加好友/删好友。

## 2. 四大逻辑结构（背这四个名字）

| 结构 | 关系 | 例子 |
|---|---|---|
| 集合 | 同属一个集体，彼此无关系 | 全班同学名单 |
| 线性 | 一对一，排队 | 排队打饭、数组/列表 |
| 树形 | 一对多，层级 | 文件夹树、家谱、公司组织架构 |
| 图形 | 多对多 | 地铁线路图、社交网络 |

> Python 直觉：列表=线性；字典的键集合=集合思想；文件夹嵌套=树（后面第6章用 Python 实现）。

## 3. 两大存储结构（全书主线）

| 存储 | 怎么存 | 特点 | Python 对应 |
|---|---|---|---|
| 顺序存储 | 一块连续内存，按下标挨着放 | 读快（直接下标），插入删除要搬移 | `list` |
| 链式存储 | 每个元素存"下一个在哪"（指针/引用）| 插入删除快，读要一个个找 | 自定义 Node 类（第2章做）|

> **全部书有一条主线：同一个逻辑结构（比如线性表），可以用顺序或链式两种方式存，各有各的代价。** 这句话记住，后面每章都在论证它。

## 4. 抽象数据类型 ADT（一个值钱的词）

ADT = 只声明"支持哪些操作"，不管怎么实现。

```
ADT 栈：push(入栈) / pop(出栈) —— 先不管它底层用列表还是链表
```

> Java 彩蛋：这就是你 Day 的一系列 `接口 interface` 思想（Day9 学的抽象类/接口）。**ADT = 接口思想的老祖宗**，面试聊到"面向接口编程"可以追溯到这。

## 5. 算法五大特性（背！期末填空）

1. **有穷性**：必须能在有限步内结束（不能死循环）
2. **确定性**：每一步都有明确含义，同样的输入必得同样输出
3. **可行性**：每一步都能用已有基本操作实现
4. **输入**：有 0 个或多个输入
5. **输出**：至少有 1 个输出

## 6. 时间复杂度（这章的重头戏，务必吃透）

### 大 O 记法是什么
只关心"规模 n 变大时，运行时间增长的**趋势**"，忽略常数和低阶项。

```
3n + 5      → O(n)     （3 和 5 都不重要）
2n² + 100n  → O(n²)    （n² 是老大）
```

### 常见复杂度排序（背）

```
O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2ⁿ)
常数   对数     线性    线性对数     平方     指数
```

### 怎么数（口诀：数循环嵌套层数）

- 单循环 → O(n)
- 双层循环嵌套 → O(n²)
- 每次循环规模折半（while n > 1: n /= 2）→ O(log n)
- 循环里套 while 折半 → O(n log n)

### Python 直觉

```python
# O(1)：一步完事
x = lst[0]

# O(n)：n 次
for x in lst: ...

# O(n²)：双层嵌套
for i in range(n):
    for j in range(n): ...

# O(log n)：规模每次砍半
while n > 1:
    n //= 2
```

> 蓝桥关键：**1 秒大约能跑 10⁷~10⁸ 次简单操作**。n=10⁵ 时 O(n²)=10¹⁰ 次 → 必超时；O(n log n) 轻松过。后面每道题先想 n 多大、我的算法是几阶。

## 7. 空间复杂度（一句话带过）

额外用了多少内存的趋势，记法一样（O(1) 原地 / O(n) 开辅助数组）。蓝桥对空间宽松，内存一般不是瓶颈。
