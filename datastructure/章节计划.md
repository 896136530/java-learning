# 《数据结构（C语言版·第2版）》章节跟课计划

> 用法：**学校课上到哪章，我们就建哪章**（每章一个文件夹：知识点.md + Python落地.py + 蓝桥考点.md）。
> 下表按"408 考研主线"排，课本可能还含 动态存储管理/外部排序/文件 等章——课表到再说。

## 章节地图

| 章 | 核心思想（一句话） | 蓝桥 Python 组怎么考 | 深度建议 |
|---|---|---|---|
| 第1章 绪论 | 数据结构 = 逻辑结构 + 存储结构 + 操作；时间复杂度/空间复杂度 | 不直接考，但**选算法靠复杂度直觉** | 重点：大 O 直觉 |
| 第2章 线性表 | 顺序表（数组）vs 链表（插入删除不搬移）| 数组就是顺序表——每天都用；链表思想用于插入删除多的场景 | 高：Python 里名单/列表就是它 |
| 第3章 栈和队列 | 栈=后进先出（LIFO）；队列=先进先出（FIFO）| 栈：括号匹配/DFS/逆序；队列：BFS/广度遍历——蓝桥中等题常客 | 高：Python list 模拟栈；collections.deque 当队列 |
| 第4章 串 | 子串、模式匹配（朴素/KMP）| 字符串处理 = 蓝桥半壁江山（切片/子串/split）；**KMP 了解思想即可**，蓝桥几乎不要求手写 | 高（处理）/低（KMP）|
| 第5章 数组和广义表 | 多维数组的存储、矩阵压缩 | 二维数组/矩阵遍历/前缀和——**蓝桥高频** | 高：务必熟练 |
| 第6章 树和二叉树 | 递归结构；先/中/后序 + 层序；二叉树重建 | 递归遍历/树的深度/重建二叉树——蓝桥中高频率 | 高：递归是 Python 强项 |
| 第7章 图 | 邻接表/邻接矩阵；DFS/BFS；最短路径（Dijkstra/Floyd）| DFS/BFS 栈与队列应用；图论题蓝桥偶尔考（较难）| 中：思想为主，模板题练 |
| 第8章 查找 | 顺序/二分/哈希表 | **二分查找 + Python 字典(哈希)** = 蓝桥必备 | 高：字典是杀手锏 |
| 第9章 排序 | 冒泡/选择/插入/快排/归并；稳定性 | 排序题蓝桥常给 `sort()` 就用；**快排思想**要会说 | 中：会用+懂思想即可 |

## 落地约定

- 每章 `Python落地.py`：用**纯手写**实现本章核心结构/算法（不许直接调库糊弄——第2、3、8章除外，那几章先学"调库姿势"再练手写）
- 每章 `蓝桥考点.md`：含 1~2 道对应真题/典型题（能在 Python 组真题里找到的那种）
- C 代码：课表/AnyviewC 需要时按章补，平时不建
