# 第2章 线性表 —— 知识点

> 教材：严蔚敏《数据结构（C语言版·第2版）》第2章。
> 一句话：**线性表 = 一串排好队的元素**。两种存储实现：顺序表（数组）和链表。

## 1. 线性表的定义

N 个元素的有限序列：第一个无前驱、最后一个无后继，**中间每个元素有唯一前驱和唯一后继**——就是"一条直线排队"。

- 顺序表（数组）：内存**连续**一块
- 链表：内存**分散**，用"指针"串起来

## 2. 核心对比表（背这个就够）

| 操作 | 顺序表（数组） | 链表 |
|---|---|---|
| 按下标取第 i 个 | **O(1)** ✅ 随机访问 | O(n) 必须从头走 |
| 尾部插入 | O(1)（append）| O(n) 要找到尾巴 |
| 中间/头部插入 | **O(n)**（后面的全要挪）| **O(1)** ✅ 只改指针 |
| 删除 | O(n)（挪）| O(1)（改指针，知道在哪）|
| 找某个值 | O(n) | O(n) |
| 内存 | 连续，可能要整体搬家（扩容）| 分散，但要额外存指针（费空间）|

**一句话记忆**：
- **要"下标随机访问" → 顺序表**
- **要"频繁插入删除" → 链表**
- 顺序表插入代价是"**挪**"，链表代价是"**找**"

## 3. Python 世界里的线性表

- **`list` 就是动态数组（顺序表）**——底层连续内存，自动扩容
- Python 没有内置链表！但你可以手写一个 `Node`（体会"节点+指针"思想）

```python
class Node:
    def __init__(self, val):
        self.val = val        # 数据
        self.next = None      # 指向下一个的"指针"
```

链表的操作本质 = 改这个 `next` 指针。

## 4. 蓝桥视角：你几乎不手写链表

Python 组的线性表题 = **直接操作 list**。但必须知道每个操作的复杂度：

```python
lst[i]          # O(1) 按下标取
lst.append(x)   # O(1) 尾插（摊还）
lst.pop()       # O(1) 尾删
lst.insert(i,x) # O(n) 中间插（挪）
lst.pop(i)      # O(n) 中间删（挪）
lst.index(v)    # O(n) 找值
x in lst        # O(n) 判断在不在
```

> 陷阱：**`lst.insert(0, x)` 在循环里用 n 次 = O(n²)**——头插虽方便，量大必超时（Python落地.py 里有实测）。

## 5. 头插法 vs 尾插法（链表经典考点）

- 头插法：新节点插在最前 → 建出来的链表**和输入顺序相反**
- 尾插法：新节点接在最后 → 顺序一致（但要遍历找尾巴，O(n)）
