# 第2章 线性表 —— 蓝桥考点 & 热身

## 这章在蓝桥怎么考

结论先行：**蓝桥不会让你手写链表**（Python 组），线性表的考法 = **直接操作 list**，但每个操作的复杂度决定你能不能过。

| 考法 | 说明 | 重要度 |
|---|---|---|
| 列表操作题 | 去重/插入保序/反转/区间——`list` 一把梭 | ★★★★★ |
| list 复杂度坑 | 循环里 `insert(0,x)` = O(n²) 必超时；`append` 才是 O(1) | ★★★★★ |
| 蕴含链表思想 | 频繁头插/删除的题，想想用 `deque`（第3章）或反过来从尾做 | ★★★ |

### 蓝桥实战口诀

- 输入一行数 → `list(map(int, input().split()))`
- **要快，永远尾插**：`ans.append(x)`；别 `ans.insert(0, x)`（除非 n 很小）
- 反转：`lst[::-1]` 秒回
- 保序去重：循环 + set 判重（第1章练过的那手）

## 热身题（做完喊「检查 DS」，不给答案）

**T3 插入保序**：输入三行——第一行整数 n，第二行 n 个**升序**整数，第三行一个整数 x。输出一行：把 x 插进去后依然升序的完整序列（数字间一个空格，结尾不要多余空格）。
- 想想：`bisect` / 循环找位置 + `insert`。n ≤ 10⁵ 时 `insert` 一次 O(n) 没问题，别双重循环。

**T4 反转输出**：输入两行——第一行整数 n，第二行 n 个整数。输出一行：这 n 个数反转后的序列（数字间一个空格，结尾不要多余空格）。
- 想想：`[::-1]` 一行；也想想"头插 n 次"和"反转"的关系——线性表操作的本质。
