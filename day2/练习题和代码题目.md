## 题目详情

### 题 1：闰年判断
规则：**能被 4 整除且不能被 100 整除，或者能被 400 整除**。
`int year = 2024;` 判断并打印"2024 是闰年"或"2024 不是闰年"。
改几个年份验证：1900（不是）、2000（是）、2025（不是）。

### 题 2：打印 3 的倍数
用 `for` 循环打印 1~100 之间所有 **3 的倍数**，用空格分隔。
挑战：每打印 5 个换一行。

### 题 3：九九乘法表
用**嵌套 for** 打印九九乘法表，格式：
```
1*1=1
1*2=2 2*2=4
1*3=3 2*3=6 3*3=9
...
```
（对齐用 `\t` 制表符即可）

### 题 4：while 求和
用 `while` 循环计算 `1+2+3+...+100` 的和并打印（结果 5050）。
挑战：再算 1~100 之间所有**偶数**的和（结果 2550）。

### 题 5：成绩等级
规则：90~100 → **A**；80~89 → **B**；70~79 → **C**；60~69 → **D**；0~59 → **E**。
`int score = 85;` 用 switch（提示：`score / 10`）或 if 实现，输出"85 分对应等级 B"。
