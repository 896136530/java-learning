## 题 1 答案（闰年判断）
```java
int year = 2024;
if (year % 4 == 0 && year % 100 != 0 || year % 400 == 0) {
    System.out.println(year + " 是闰年");
} else {
    System.out.println(year + " 不是闰年");
}
```
- 2024 → 是闰年；1900 → 不是（能被100整除但不能被400整除）；2000 → 是；2025 → 不是。

## 题 2 答案（3 的倍数，每行 5 个）
```java
int count = 0;
for (int i = 1; i <= 100; i++) {
    if (i % 3 == 0) {
        System.out.print(i + "\t");
        count++;
        if (count % 5 == 0) {
            System.out.println();   // 每 5 个换行
        }
    }
}
```
不用挑战版（不换行）更简单：`System.out.print(i + " ");`

## 题 3 答案（九九乘法表）
```java
for (int i = 1; i <= 9; i++) {          // 外层：第几行
    for (int j = 1; j <= i; j++) {      // 内层：每行打印到 i
        System.out.print(j + "*" + i + "=" + (j * i) + "\t");
    }
    System.out.println();               // 每行结束换行
}
```

## 题 4 答案（while 求和）
```java
int i = 1, sum = 0;
while (i <= 100) {
    sum += i;
    i++;
}
System.out.println("1+2+...+100 = " + sum);   // 5050

// 挑战：偶数和（从 2 开始，每次 +2）
int j = 2, evenSum = 0;
while (j <= 100) {
    evenSum += j;
    j += 2;
}
System.out.println("1~100 偶数和 = " + evenSum);  // 2550
```

## 题 5 答案（成绩等级，switch 箭头写法）
```java
int score = 85;
switch (score / 10) {
    case 10, 9 -> System.out.println(score + " 分对应等级 A");
    case 8     -> System.out.println(score + " 分对应等级 B");
    case 7     -> System.out.println(score + " 分对应等级 C");
    case 6     -> System.out.println(score + " 分对应等级 D");
    default    -> System.out.println(score + " 分对应等级 E");
}
```
if-else 版：
```java
if (score >= 90) System.out.println(score + " 分对应等级 A");
else if (score >= 80) System.out.println(score + " 分对应等级 B");
else if (score >= 70) System.out.println(score + " 分对应等级 C");
else if (score >= 60) System.out.println(score + " 分对应等级 D");
else System.out.println(score + " 分对应等级 E");
```
思路：`score / 10` 把 90~99 → 9，80~89 → 8 … 正好对应 case。
