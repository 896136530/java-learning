# Day 4 知识点：字典 dict 与集合 set

> 前提：字符串、列表已经熟了。今天两个"查得快"的结构——**字典**和**集合**，都是蓝桥杀手锏（词频统计、去重全靠它们）。

## 1. 字典 dict = 键值对查找表

### 创建
```python
d = {"apple": "苹果", "banana": "香蕉"}   # 最常用：一个字面量
d = {}                                    # 空字典
```

### 查（重点：两种姿势）
```python
d["apple"]     # → "苹果"。⚠️ 键不存在会 KeyError 崩掉！
d.get("dog")   # → None，不崩（老师推荐）
d.get("dog", "查无此词")   # → "查无此词"（给默认值）
```

### 增 / 改（同一个语法）
```python
d["cat"] = "猫"      # 键不存在 → 新增
d["apple"] = "苹果🍎"  # 键已存在 → 覆盖更新
```

### 删
```python
d.pop("cat")    # 删掉并返回它的值（不存在会 KeyError）
del d["cat"]    # 直接删
```

### 遍历三兄弟
```python
for k in d:            # 遍历所有键（最常用）
for k in d.keys():     # 同上，显式写法
for v in d.values():   # 遍历所有值
for k, v in d.items(): # 同时拿键和值（★★ 最常用）
```

### len / in
```python
len(d)          # 键值对个数
"apple" in d    # 判断键在不在 → True
```

## 2. 字典查 O(1)：词频统计的标准套路（背）

一个单词统计出现次数：
```python
d[word] = d.get(word, 0) + 1
```
> 第一次遇到：get 返回 0 → 变成 1；第二次：get 返回 1 → 变成 2。**一行代码计数**。

为什么快：字典底层是**哈希表**，不用一个个找，直接定位 → O(1)。列表查找 `x in lst` 是 O(n)——**数据一大，字典完胜**。

## 3. 集合 set = 自动去重的袋子

### 创建
```python
s = {1, 2, 3}
s = set([1, 2, 2, 3, 3])   # → {1, 2, 3}  重复的自动没了
```

### 加 / 删
```python
s.add(4)
s.remove(4)     # ⚠️ 不存在会 KeyError
s.discard(99)   # 不存在也不报错（稳）
```

### 集合运算（蓝桥爱考）
```python
a | b    # 并集：谁在谁里面都行
a & b    # 交集：两边都有
a - b    # 差集：a 里有 b 里没有
a ^ b    # 对称差：只在一边的
```

### 判断
```python
x in s    # O(1)，超快
```

## 4. 去重的坑：顺序会乱

```python
list(set(nums))   # 去重了，但顺序不保证！⚠️
```
**要保序去重**（保持第一次出现顺序）：自己循环 + set 判重：
```python
seen = set()
result = []
for x in nums:
    if x not in seen:
        seen.add(x)
        result.append(x)
```

## 5. 蓝桥高频三件套

1. **词频统计**（字典 + get 套路）——送分题常客
2. **去重**（集合；要保序就用循环+set）
3. **查表映射**（字典当翻译表/成绩表/映射表）——今天 Ex1/Ex5 就是
