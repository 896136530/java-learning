## 0. 先记住 import 的两种写法

```python
import math                  # 用的时候写全：math.gcd(12, 18)  → 不用记改了哪个名字
from math import gcd         # 直接写名字：gcd(12, 18)
from collections import Counter, deque
```

> ⚠️ **你本机环境：Python 3.9.13**（`python --version` 查的）。今天这一课涉及"版本差异"，记一下免得白折腾：

| 函数 | 你的 3.9.13 能用吗 | 不能用时的替代写法 |
|---|---|---|
| `math.gcd` / `math.isqrt` / `math.comb` | ✅ 能用 | — |
| `math.lcm` | ✅ 能用（3.9 新增）| 老版本用 `a * b // gcd(a, b)` |
| `Counter.total()` | ❌ **不能用**（3.10+）| 用 `sum(c.values())` |
| `Counter.most_common()` / `elements()` / 相减 | ✅ 能用 | — |

> 💡 结论：**`sum(c.values())` 和 `a*b//gcd(a,b)` 这两种写法在哪个版本都能跑**，记这两个最保险（蓝桥考场版本不一定和你电脑一样）。

## 1. math：数学题的好帮手

```python
import math

math.gcd(12, 18)        # 6      最大公约数（greatest common divisor）
math.lcm(4, 6)          # 12     最小公倍数（Python 3.9+ 有）
math.sqrt(16)           # 4.0    ⚠️ 返回浮点数，16**0.5 也一样
math.isqrt(17)          # 4      整数平方根（向下取整，比 int(sqrt) 安全）
                        # ⚠️ 只有 isqrt 返回整数；sqrt 返回浮点数（3.8+ 才有 isqrt）
math.factorial(5)       # 120    阶乘
math.ceil(2.1)          # 3      向上取整
math.floor(2.9)         # 2      向下取整
math.pi                 # 3.141592653589793
abs(-5)                 # 5      这是内置函数，不用 import
```

| 想干什么 | 写法 | 备注 |
|---|---|---|
| 最大公约数 | `gcd(a, b)` | 自带，别手写辗转相除 |
| 最小公倍数 | `lcm(a, b)` | 底层是 `a*b//gcd(a,b)` |
| 判断平方数 | `isqrt(n)**2 == n` | 比 `sqrt` 稳（浮点误差） |
| 向上/向下取整 | `ceil` / `floor` | ⚠️ 返回整数 |
| 排列组合 | `math.comb(n, k)` / `math.perm` | 从 n 个里选 k 个的方案数 |

> ⚠️ `math.sqrt(2)` 是浮点数，`math.sqrt(2)**2` 可能不等于 2（浮点误差）。**整数题尽量用 `isqrt`。**

## 2. collections.Counter：计数神器（今天最值钱的一个）

以前统计词频要写 5 行，现在 1 行：

```python
from collections import Counter

words = ["apple", "banana", "apple", "cherry", "apple"]
c = Counter(words)
print(c)               # → Counter({'apple': 3, 'banana': 1, 'cherry': 1})
```

**Counter 就是个字典**（值是次数），字典的招它全能用，还额外多了几个：

```python
c["apple"]              # 3     取值（和字典一样）
c["durian"]             # 0     ⭐ 坑王变神器：不存在的键返回 0，KeyError 没了
c.most_common(1)        # [('apple', 3)]        出现最多的前 1 个
c.most_common()         # 按次数从多到少全部列出
sum(c.values())         # 5     所有次数之和
                        # ⚠️ c.total() 也行，但那要 Python 3.10+；你的电脑是 3.9.13，会报 AttributeError
                        #    用 sum(c.values()) 万能（老版本、新版本都能跑）
```

**用法 1：一行统计字符串里每个字符**

```python
from collections import Counter
print(Counter("hello"))      # → Counter({'l': 2, 'h': 1, 'e': 1, 'o': 1})
```

**用法 2：给两个 Counter 做加减（蓝桥"找不同"常用）**

```python
a = Counter("aabbc")
b = Counter("abc")
print(a - b)        # → Counter({'a': 1, 'b': 1})   只在 a 里多出来的
print(a & b)        # → Counter({'a': 1, 'b': 1, 'c': 1})   两边都有的（取小的次数）
print(a | b)        # → Counter({'a': 2, 'b': 2, 'c': 1})   取大的次数
print(sum((a - b).values()))   # 2   总共多几个
```

**用法 3：一行数出"出现次数最多"的元素**

```python
nums = [1, 3, 3, 7, 7, 7, 2]
c = Counter(nums)
print(c.most_common(1)[0])       # → (7, 3)      出现最多的元素和次数
print(c.most_common(1)[0][0])    # → 7           只要元素
```

## 3. collections.deque：两头都能进出的队列（顺手了解）

```python
from collections import deque

dq = deque([1, 2, 3])
dq.append(4)          # 右边进 → [1,2,3,4]
dq.appendleft(0)      # 左边进 → [0,1,2,3,4]
dq.pop()              # 右边出 → 4
dq.popleft()          # 左边出 → 0     ⭐ 列表没有这个，pop(0) 很慢
```

> `list.pop(0)` 要挪动后面所有元素（O(n)），`deque.popleft()` 是 O(1)。**队列题（BFS/迷宫）用 deque。** 今天知道就行，Day12~13 讲 BFS 时会正式用。

## 4. itertools：排列组合与配对（会查会抄就够）

```python
from itertools import product, combinations, permutations, accumulate

# 全排列：3 个数排一排有几种排法
list(permutations([1, 2, 3]))          # [(1,2,3), (1,3,2), (2,1,3), ...]  共 6 个

# 组合：从 3 个里选 2 个
list(combinations([1, 2, 3], 2))       # [(1,2), (1,3), (2,3)]

# 笛卡尔积：两个列表两两配对（暴力枚举必备）
list(product([1, 2], "ab"))            # [(1,'a'), (1,'b'), (2,'a'), (2,'b')]

# 前缀和：一行得到"前 n 项累加"（Day10 会细讲，先见识一下）
list(accumulate([1, 2, 3, 4]))         # [1, 3, 6, 10]
```

> ⚠️ 排列组合的结果**是"迭代器"，不能直接打印看全部**，要套 `list(...)`。
> 再⚠️：`permutations([1,2,3])` 是 6 个，`permutations(range(10))` 就是 362 万多个——**数据一大就爆**，蓝桥里只在小数据用。

## 5. bisect：二分查找（有序表里找位置）

```python
from bisect import bisect_left, bisect_right, insort

a = [1, 3, 5, 7, 9]        # 前提：a 必须已经排好序！
bisect_left(a, 5)          # 2    5 应该插在哪个下标（左边优先）
bisect_right(a, 5)         # 3    5 应该插在哪个下标（右边优先）
bisect_left(a, 4)          # 2    4 不存在时，返回"保持有序应插的位置"

insort(a, 4)               # 直接插进去并保持有序 → a = [1,3,4,5,7,9]
```

**怎么用它判断"在不在"**：

```python
i = bisect_left(a, 5)
print(i < len(a) and a[i] == 5)     # True → 5 在表里
```

> ⚠️ 三大坑：① 表**没排序**结果全错；② 返回的是**下标**不是 True/False；③ `bisect` 是"二分"，比 `in` 快得多（10⁵ 数据差几个数量级）——但**前提是有序**。

## 6. 其他天天要用的内置函数

```python
sum([1, 2, 3])              # 6
max([3, 1, 4])              # 4
min([3, 1, 4])              # 1
max([3, 1, 4], key=abs)     # 4    还能配 key（和 sorted 一样）
abs(-5)                      # 5
round(2.567, 2)             # 2.57 四舍五入到 2 位（有浮点小坑，见知识点 7）
divmod(17, 5)               # (3, 2)   商和余数一起拿：17 = 5*3 + 2
sorted([3, 1, 2])           # [1, 2, 3]
len("hello")                # 5
any([False, True])          # True   只要有一个真就是真：any(x > 0 for x in nums)
all([True, False])          # False  全真才真
```

**⭐ `any` / `all` 的秒用**（判断条件成不成立，一行搞定）：

```python
nums = [-3, 5, -1]
print(any(x > 0 for x in nums))    # True   有没有正数
print(all(x != 0 for x in nums))   # True   是不是全都不为 0
```

## 7. ⚠️ 今天的坑

| 坑 | 现象 | 正确做法 |
|---|---|---|
| `input()` 忘 `map(int)` | 变成字符串比较，`'10' < '9'` | `list(map(int, input().split()))` |
| 排列组合忘了 `list()` | 打印出 `<itertools.permutations object at 0x...>` | 套 `list(...)` |
| `math.sqrt` 判平方数 | 大数时浮点误差判错 | 用 `math.isqrt(n)**2 == n` |
| `bisect` 用在没排序的表 | 结果莫名其妙 | 先 `a.sort()` |
| 用 `Counter` 却取了不存在的键就慌 | 其实返回 0，不用 `if` 判 | `c[x]` 直接加 |
| `round(2.675, 2)` | 得到 `2.67` 不是 `2.68`（浮点存储） | 真要精确用 `Decimal`，蓝桥输出一般用 f-string `f"{x:.2f}"` |

**关于输出小数**（蓝桥最爱卡这个）：

```python
x = 7 / 3
print(f"{x:.2f}")      # 2.33    四舍五入到 2 位，最常用 ✅
print(round(x, 2))     # 2.33
print("%.2f" % x)      # 2.33    老写法，也能用
```

## 8. 蓝桥考点提示

- **计数题**：`Counter` 一行搞定（词频、字符统计、找出现最多的）
- **数学题**：`gcd` / `lcm` / `isqrt` 直接用，别手写
- **暴力枚举题**：`product` / `combinations` / `permutations` 省掉多层循环（注意数据规模）
- **有序表查找**：`bisect`（比 `in` 快几个数量级）
- **队列/迷宫**：`deque`（`popleft` 是 O(1)）
- **输出小数**：`f"{x:.2f}"`，别用 `round` 再打印（有时位数不对）
