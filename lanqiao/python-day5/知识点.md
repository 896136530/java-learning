## 1. 为什么要有函数

```python
# 没有函数：同样的逻辑写三遍
a = [1, 2, 3]
s = 0
for x in a:
    s += x
b = [4, 5]
t = 0
for x in b:
    t += x
# 有函数：写一遍，随便调
def my_sum(lst):
    s = 0
    for x in lst:
        s += x
    return s
```

**函数 = 把"一段逻辑"命名，以后按名字调用**。

## 2. 函数四件套（背）

```python
def 函数名(参数1, 参数2):   # 1. def 开头，冒号收尾
    ...                     # 2. 函数体（缩进！）
    return 结果             # 3. return 返回并立刻结束

print(函数名(实参1, 实参2))  # 4. 调用：名字 + 括号 + 实参
```

- **没有 return** 的函数返回 `None`（打印就是 `None`，经典坑）
- **return 之后**的代码不执行（return = 立即下班）

## 3. 参数：形参 vs 实参、默认参数

```python
def greet(name, msg="你好"):   # msg 有默认值 = 不传也行
    return msg + "，" + name + "！"

greet("小明")          # → "你好，小明！"  （就用默认 msg）
greet("小红", "早上好") # → "早上好，小红！" （覆盖默认值）
```

- 定义时括号里的是**形参**（占位符）
- 调用时传的是**实参**（真数据）
- 有默认值的参数**必须放最后**

## 4. 作用域：局部 vs 全局（今天的心脏 ⭐）

```python
count = 0            # 全局变量：模块顶层，谁都看得见

def add():
    count += 1       # ❌ 报错！函数内默认"只读"全局变量，想改必须声明
    return count

def add2():
    global count     # ✅ 声明"我要动的是全局那个 count"
    count += 1
    return count
```

**三条铁律（背）**：
1. 函数内**读**全局变量：直接读，没事
2. 函数内**改**全局变量：必须先 `global 变量名`，否则 Python 会认为你在函数里新造了一个**同名局部变量**（ValueError/行为诡异）
3. 函数内定义的变量 = 局部变量，**函数一结束就消失**，外面拿不到
