## 题目详情（只描述输入输出，自己验证）

### 题 1：问候函数（Ex1_greet.py）
- 定义 `greet(name)`：返回 `你好，` + 名字 + `！`
- 输入：一行，一个名字
- 输出：一行，问候语
- 💡：`return "你好，" + name + "！"`——这是第一次自己写 return

### 题 2：阶乘函数（Ex2_factorial.py）
- 定义 `factorial(n)`：返回 n!（n 的阶乘，n 从 1 乘到 n）
- 输入：一行，一个整数 n（0 ≤ n ≤ 20）
- 输出：一行，n!
- 💡：`0! = 1`（边界！）；n=20 时结果很大，Python 整数随便装
- ⚠️ 试算：n=5 时结果末尾是 0 吗？n=10 时是几位数？（自己验证对不对）

### 题 3：素数判断函数（Ex3_is_prime.py）
- 定义 `is_prime(n)`：n 是素数返回 `True`，否则 `False`
- 输入：一行，一个整数 n（2 ≤ n ≤ 10⁶）
- 输出：一行，`是素数` 或 `不是素数`（别打印 True/False，转成中文）
- 💡：判断到 √n 就够了（第1章 DS 你练过这个思路）；1 不是素数
- ⚠️ 自己试 n=2（最小素数）和 n=4

### 题 4：全局计数器（Ex4_counter.py）
- 题面：定义全局变量 `count = 0`；定义 `add()`：用 `global count` 把 count 加 1 并返回它
- 输入：第一行整数 n；接下来 n 行，每行一个任意字符串
- 输出：n 行，每读一行调用一次 `add()` 并打印返回值（第 k 行就是 k）
- 💡：没有 `global` 这题必炸——先试试不加 global 会报什么错（亲身踩坑）

### 题 5：计算器（Ex5_calc.py）
- 定义 `calc(a, b, op)`：按 op（`+` `-` `*` `/` 之一）返回运算结果
- 输入：一行，`数1 运算符 数2`（空格隔开，运算符是 `+` `-` `*` `/`）
- 输出：一行，运算结果（除法用 Python 3 的 `/`，可能带小数）
- 💡：`op == "+"` 分支判断；注意 `/` 的结果如果是整数会显示成 `3.0`，正常
- ⚠️ 试算：`7 / 2` 应该是什么？`7 + 5` 呢？

### 🎯 复习：成绩表函数版（Review.py）
- 定义 `get_highest(rows)`：rows 是 `[(姓名, 分数), ...]` 列表，返回分数最高的那个 `(姓名, 分数)`（并列取第一个）
- 输入：第一行整数 n；接下来 n 行 `姓名 分数`
- 输出：一行，`姓名 分数`（最高分者）
- 💡：主流程=读 n 行造元组列表 → 调函数 → 打印；你和 Day4 复习题的数据一样，但这次全靠函数封装
