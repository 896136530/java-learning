## 题目详情（只描述输入输出，自己验证）

### 题 1：回文判断（Ex1_palindrome.py）
- 输入：一行字符串 `s`（不含空格）
- 输出：一行 —— 是回文输出 `YES`，否则输出 `NO`
- 💡：`s == s[::-1]` 一行搞定
- ⚠️ 自测：长度 1（`a` → YES）、长度 2（`ab` → NO）、奇数长度、偶数长度、**含大写**（`Aba` → NO，因为 `A` 和 `a` 不是同一个字符）

### 题 2：切片三连（Ex2_slice_three.py）
- 输入：第一行一个字符串 `s`；第二行一个整数 `k`
- 输出：一行，三段用空格隔开 —— ① `s` 的前 `k` 个字符 ② `s` 的后 `k` 个字符 ③ `s` 整个反转
- 💡：`s[:k]`、`s[-k:]`、`s[::-1]`，三段用 `" ".join([...])` 拼起来
- ⚠️ 自测：`k` 等于 `len(s)`（前 k 个 = 整个串，后 k 个 = 整个串）、`k` 等于 1、`len(s)` 等于 2

### 题 3：字符分类统计（Ex3_char_class.py）⭐
- 输入：一行字符串 `s`（**可能含空格，也可能含中文**）
- 输出：一行，四个整数用空格隔开 —— 大写字母个数、小写字母个数、数字字符个数、其他字符个数
- 💡：用 `'A' <= ch <= 'Z'` 这种连续比较（或 `ch.isupper()`）；**中文属于"其他"**（不是字母）
- ⚠️ 自测：纯小写（`abc` → `0 3 0 0`）、纯大写、纯数字、只有符号、**带空格**（空格算"其他"）
- 💡 想清楚：为什么用 `elif` 而不是四个独立 `if`？（因为一个字符只能属于一类）

### 题 4：找出多出来的字符（Ex4_diff_join.py）
- 输入：两行字符串，第一行长、第二行短
- 输出：一行 —— 第一行比第二行"多出来"的那些字符，按**字典序从小到大**拼成一串（没有多出来的就输出空行）
- 💡：`from collections import Counter`；`diff = Counter(第一行) - Counter(第二行)`；`''.join(sorted(diff.elements()))`
- ⚠️ 自测：多出 1 个字符、**多出好几个相同字符**（如 `aabb` 和 `b` → 多出 `a a b`）、两串完全相同（→ 输出**空行**）
- 📌 这题是 Day8 题 3 的**升级版**：上次你输出了列表 `['b','c']`，这次要用 `join` 输出字符串 `bc`

### 题 5：子串出现次数（Ex5_count_sub.py）
- 输入：第一行字符串 `s`；第二行字符串 `t`
- 输出：一行 —— `t` 在 `s` 里出现了几次（**不重叠计数**，即从左往右找到一次就跳过这一整段继续找）
- 💡：
  - 先试 `s.count(t)`，看它对 `s="aaa"`、`t="aa"` 给出什么（**1**），确认它就是不重叠的
  - 然后**再手写一遍**用 `find` 循环实现（`find` 可以指定起点 `s.find(t, start)`）：
    找到一次 → 计数 +1 → `start` 跳到 `pos + len(t)` 继续找 → 找不到（-1）就停
- ⚠️ 自测：`t` 比 `s` 长（→ 0）、`s` 和 `t` 完全相同（→ 1）、`s="aaa" t="aa"`（→ 1）、`s="aaaa" t="aa"`（→ 2）
- 💡 想清楚：为什么"重叠计数"（`aaa` 里 `aa` 出现 2 次）不能用 `count`？什么时候题目会要求重叠？

### 题 6：旋转匹配（Ex6_rotation.py）⭐ 加练
- 输入：第一行字符串 `a`；第二行字符串 `b`
- 输出：一行 —— `b` 能不能通过把 `a` **循环左移若干位**得到？能输出 `YES`，不能输出 `NO`
- 💡：
  - **环形技巧**：`a` 的所有循环移位，都是 `a + a` 的子串！所以先判 `len(a) == len(b)`，再判 `b in a + a`
  - 例：`a="abcde"`，`a+a="abcdeabcde"`，里面能查到 `"cdeab"` → YES；查 `"cdeba"` → NO
- ⚠️ 自测：完全相同（→ YES）、长度不同（→ NO，**先判长度**）、`a="ab" b="ba"`（→ YES）
- 💡 想清楚：为什么必须先判长度？如果不判，`a="ab"`、`b="abab"`（`b in a+a` 成立）会错在哪？

### 🎯 复习：回文检测器（Review.py）
- 输入：第一行一个整数 `n`；接下来 `n` 行，每行一个字符串（**可能含空格、大小写、标点**）
- 输出：`n + 2` 行
  - 前 `n` 行：每行对应输入的一行，是回文输出 `YES`，否则 `NO`
  - 倒数第 2 行：`回文个数 x`（x 是 YES 的行数）
  - 最后一行：`最长整理后长度 y`（y = 所有行"清洗后"字符串长度的最大值）
- **规则（重要，别自己改）**：
  - 判断前要**清洗**：只保留字母和数字，并**统一转小写**（`ch.isalnum()` + `ch.lower()`）
  - **清洗后是空串的行，算回文**（输出 `YES`），长度按 0 算
- 💡：
  - 把"清洗"单独写成一个函数 `normalize(line)`（复习 Day5 函数封装），判断用 `== `切片反转
  - 最长长度用 `len(t)`，别用原串长度（原串含标点，会偏大）
- ⚠️ 自测：`A man, a plan, a canal: Panama`（→ YES）、`hello`（→ NO）、全是标点如 `!!!`（→ YES，清洗后是空串）、`Aa`（→ YES，转小写后 `aa`）
- 💡 想清楚：`No 'x' in Nixon` 清洗后是什么？（→ `noxinnixon`，回文 → YES）
