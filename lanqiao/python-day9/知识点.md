## 0. 先记住一个"反常识"：字符串不能改

```python
s = "hello"
s[0] = "H"          # ❌ TypeError: 'str' object does not support item assignment
s = s.replace("h", "H")   # ✅ 只能"造一个新串"，再让 s 指向它
s = s[:1] + "H" + s[2:]   # ✅ 切片拼接也是造新串
```

> 💡 **字符串是"不可变"的**——所有看似"修改"的方法（`replace`/`upper`/`strip`）**都返回新串，原串不动**。
> 所以忘了写 `s = s.replace(...)` 是新手第一大坑（你的 `s` 还是老样子）。

## 1. 索引与切片（今天的地基）

```python
s = "hello"
s[0]      # 'h'    第一个
s[-1]     # 'o'    最后一个（-1 就是倒数第一）
s[-2]     # 'l'    倒数第二
```

| 写法 | 结果 | 说明 |
|---|---|---|
| `s[1:4]` | `'ell'` | **左闭右开**：下标 1、2、3（不含 4）|
| `s[:2]` | `'he'` | 省略左边 = 从头开始 |
| `s[2:]` | `'llo'` | 省略右边 = 一直到结尾 |
| `s[:]` | `'hello'` | 复制一份（新串）|
| `s[::-1]` | `'olleh'` | **反转**（步长 -1）⭐ 回文就靠它 |
| `s[::2]` | `'hlo'` | 步长 2：隔一个取一个 |
| `s[-2:]` | `'lo'` | **最后两个字符**（超常用）|
| `s[2:100]` | `'llo'` | ⭐ **切片不报越界**（超过长度就自动截到结尾）|
| `s[100:]` | `''` | 空空如也，但**不报错** |

> ⚠️ 对比一下：`s[100]`（**索引**）会 `IndexError` 报错，`s[100:]`（**切片**）不会。
> **能切片就别索引**——少写一堆边界判断。

### 切片公式（背下来）

```
s[起点:终点:步长]     ← 起点包含、终点不包含
```

## 2. join：把列表拼成字符串（蓝桥输出必备）

```python
" ".join(["1", "2", "3"])        # '1 2 3'     空格连接
"-".join(["a", "b"])             # 'a-b'
"".join(["a", "b"])              # 'ab'        无分隔符
" ".join(map(str, [1, 2, 3]))    # '1 2 3'     ⭐ 数字列表要先都变字符串
''.join(sorted("cba"))           # 'abc'       字符串也能直接排序拼接
```

**为什么不用 `+` 拼？**

```python
# ❌ 慢：每次都造一个新串，n 个字符要搬 n 次
result = ""
for ch in s:
    result = result + ch

# ✅ 快：先在列表里攒，最后 join 一次成型
parts = []
for ch in s:
    parts.append(ch)
result = "".join(parts)
```

> 💡 小数据看不出差别，但蓝桥数据一大，循环里 `+` 拼串就是超时的常见原因之一。
> **记法：循环里只用 `append`，最后 `join` 收尾。**

## 3. 常用字符串方法（一张表看完）

| 想干什么 | 写法 | 注意 |
|---|---|---|
| 找子串位置 | `s.find("ab")` | 找不到返回 **-1**（不报错）|
| 找子串位置（严格）| `s.index("ab")` | 找不到**报 ValueError** |
| 找最后一个位置 | `s.rfind("ab")` | 找不到也是 -1 |
| 数出现次数 | `s.count("a")` | ⚠️ **不重叠**：`"aaa".count("aa") == 1` |
| 替换 | `s.replace("a", "b")` | 返回**新串**；`replace(a, b, 2)` 只换前 2 个 |
| 开头/结尾判断 | `s.startswith("http")` / `s.endswith(".py")` | 返回 True/False |
| 按分隔符切开 | `s.split(",")` | 返回列表；`s.split()` 按任意空白切（最常用）|
| 去掉两端空白 | `s.strip()` | `rstrip` 右边、`lstrip` 左边 |
| 大小写 | `s.upper()` / `s.lower()` | 返回新串 |
| 大小写互换 | `s.swapcase()` | `'aB'` → `'Ab'` |
| 是不是数字 | `s.isdigit()` / `ch.isdigit()` | 单个字符也能用 |
| 是不是字母 | `s.isalpha()` / `ch.isalpha()` | |
| 是不是字母或数字 | `s.isalnum()` | 回文题常用 ⭐ |
| 反转 | `s[::-1]` | 没现成方法，用切片 |

> ⚠️ **`find` 和 `index` 的区别就是"找不到时"**：一个是 -1，一个直接崩。
> 蓝桥里"有没有出现过"用 `find`（或 `in`），"必须存在"才用 `index`。

## 4. ord / chr：字符 ↔ 数字（今天第二个重点）

```python
ord("a")    # 97     字符 → 编码
ord("A")    # 65
ord("z")    # 122
ord("0")    # 48
chr(97)     # 'a'    编码 → 字符
chr(ord("a") + 2)   # 'c'      字母往后挪 2 位
```

**要背的三个数**（其他都能推）：

| 字符 | 编码 |
|---|---|
| `'0'` | 48 |
| `'A'` | 65 |
| `'a'` | 97 |

**由此得到两个万能公式**：

```python
# 1) 判断"这个字符是字母/数字"（不用 isalpha 也能写）
'A' <= ch <= 'Z'      # 大写字母（Python 支持这种连续比较，可读性很好）
'a' <= ch <= 'z'
'0' <= ch <= '9'

# 2) 字母表序号（a=1, b=2, ..., z=26）
ord(ch) - ord('a') + 1      # 小写：'c' → 3
ord(ch) - ord('A') + 1      # 大写：'C' → 3
```

> 💡 中文字符也能 `ord`/`chr`：`ord('中') = 20013`（练题 3 会用到）。

## 5. ⭐ 回文判断：两种写法都要会

**回文**：正着读反着读一样。`"level"`、`"abcba"`、`"a"` 都是。

```python
# 写法一：切片反转（一行，最常用）✅
def is_pal(s):
    return s == s[::-1]

# 写法二：双指针（Day11 会重点学，先见个面）
def is_pal2(s):
    i, j = 0, len(s) - 1
    while i < j:
        if s[i] != s[j]:
            return False
        i += 1
        j -= 1
    return True
```

> 💡 **`"aaa".count("aa")` 是 1 不是 2**（不重叠）。同理，**回文比较一定要整体比**，
> 别用 `count` 去数"对称字符有几个"——那样 `"abca"` 也可能被骗过去。

## 6. ⭐ 判断"能不能只留字母数字"（回文升级题必用）

比赛里的回文题常带一句"忽略大小写和标点"，标准做法是**先清洗再判断**：

```python
s = "A man, a plan, a canal: Panama"

# 方法一：列表推导 + isalnum（推荐）
t = ''.join(ch.lower() for ch in s if ch.isalnum())
# → 'amanaplanacanalpanama'

# 方法二：逐个字符判断后 append（更啰嗦但好懂）
parts = []
for ch in s:
    if ch.isalnum():
        parts.append(ch.lower())
t = ''.join(parts)

print(t == t[::-1])     # True
```

> ⚠️ **边界**：如果整行都是标点（比如 `"!!!"`），清洗后会得到**空串 `''`**，
> 而 `'' == ''[::-1]` 是 **True**。所以"全是标点的行算不算回文"要在题目里说清楚
> （今天练习里约定：**空串算回文**，输出 `YES`）。

## 7. 字符串比较与排序

```python
"apple" < "banana"        # True    按字典序（逐字符比编码）
sorted(["banana", "apple", "cherry"])              # ['apple', 'banana', 'cherry']
sorted(["banana", "apple", "cherry"], key=len)     # 按长度
sorted(words, key=lambda w: (len(w), w))           # 长度 + 字典序（Day7 学过）
```

> 💡 中文字符串也能比大小——按 Unicode 编码，**但结果往往不是你以为的拼音顺序**
> （Day28 你已经踩过一次：`"三班" < "二班"`）。**中文别当排序键**。

## 8. 常见坑速查

| 坑 | 现象 | 正确写法 |
|---|---|---|
| 忘了接返回值 | `s.replace("a","b")` 之后 `s` 没变 | `s = s.replace(...)` |
| 索引越界 | `s[10]` → IndexError | 用切片 `s[10:]`，或先 `if len(s) > 10` |
| `+` 拼串 | 数据大时超时 | `append` + `join` |
| `count` 重叠 | `"aaa".count("aa")` 得 1 | 需要重叠要自己写循环（或正则）|
| `find` 当 `index` 用 | 以为找不到会报错 | `find` 返 -1，要判 `!= -1` |
| 忘了 `lower()` | 含大写的回文判成 NO | 先 `ch.lower()` |
| `isalnum` 漏了 | 标点混进去导致判错 | 先清洗 |
