# Python Day 3 知识点：字符串 + 列表

> 前提：if 判断 + 循环已会用。今天学**刷题的两大基本盘**：字符串（词）和列表（一组数），蓝桥从今天起一半题目靠它俩。

## 1. 字符串：一串字符

```python
s = "hello"

len(s)          # 5 —— 长度
s[0]            # 'h' —— 按下标取（从 0 开始）
s[-1]           # 'o' —— 倒数第一个
s[1:4]          # 'ell' —— 切片：含头不含尾！
"e" in s        # True —— 在不在里面
for ch in s:    # 逐个字符遍历
    print(ch)
```

**切片 `s[a:b]` 含头不含尾**——和 `range(1,6)` 一个脾气，蓝桥一半 bug 在这。

## 2. 字符串常用方法（背下来）

| 方法 | 干什么 | 例子 |
|---|---|---|
| `s.split()` | 按空格拆成列表 | `"7 9".split()` → `['7','9']` |
| `s.strip()` | 去掉首尾空白 | `"  hi  ".strip()` → `"hi"` |
| `s.replace(a,b)` | 替换 | `"a-b".replace("-","+")` → `"a+b"` |
| `s.find(x)` / `s.count(x)` | 找位置 / 数个数 | — |
| `" ".join(lst)` | 把列表拼回字符串 | `" ".join(["a","b"])` → `"a b"` |
| `s.upper()` / `s.lower()` | 转大写 / 小写 | — |
| `s[::-1]` | 反转（切片的终极形态） | `"abc"[::-1]` → `"cba"` |

> 字符串**不可变**：`s = s + "x"` 是造了个新字符串，原 s 没动。

## 3. 列表：一组数据

```python
nums = [3, 1, 4, 2]

len(nums)          # 4
nums.append(5)     # 尾部加一个 -> [3,1,4,2,5]
nums.sort()        # 原地从小到大 -> [1,2,3,4,5]
nums.sort(reverse=True)  # 从大到小
sum(nums)          # 总和
max(nums) / min(nums)    # 最大 / 最小
for x in nums:     # 遍历
    print(x)
```

**蓝桥设定的标准读数姿势（记住！）**：

```python
nums = list(map(int, input().split()))   # 一行 "3 1 4 2" → [3,1,4,2]
```

> `input().split()` 拆成字符串列表 → `map(int, ...)` 挨个转成 int → `list(...)` 收成列表。

## 4. 刷题组合技

- **排序输出**：`nums.sort()` 后，`" ".join(map(str, nums))` 拼回一行输出
- **字符串变列表**：`list("abc")` → `['a','b','c']`
- **数转字符串**：`str(123)` → `"123"`
