>
> 一句话：**前缀和把"区间求和"从 O(n) 变成 O(1)；差分把"区间加"从 O(n) 变成 O(1)。**
> 这两个是蓝桥里性价比最高的两个技巧，几乎每套卷子都能用上。

## 0. 先看一个"暴力会超时"的场景

题目：给一个长度为 10 万的数组，然后有 10 万次询问，每次问"第 L 个数到第 R 个数的和"。

**暴力写法**（你目前会这么写）：

```python
for _ in range(q):
    l, r = map(int, input().split())
    print(sum(a[l-1:r]))        # 每次都要把这一段重新加起来
```

**复杂度**：每次询问最坏要加 10 万个数 → 总共 10 万 × 10 万 = **10^10 次加法**。
（计算机每秒大概能做 10^8 次运算 → 要跑 **100 秒以上**）

蓝桥的时间限制通常是 **1~2 秒**。**直接超时，0 分。**

**前缀和的写法**：

```python
print(pre[r] - pre[l-1])        # 两次减法，不管区间多长都是这一步
```

**复杂度**：预处理 O(n) + 每次询问 O(1) → 总共 10 万次运算 → **0.01 秒**。

> ⭐ 差 10000 倍。这就是"算法"的意义：**不是让代码变短，是让复杂度下降一个数量级。**

## 1. 一维前缀和

### 1.1 定义

**前缀和数组 `pre`**：`pre[i]` = 原数组 `a` 的**前 i 个**元素之和。

```
a   = [3, 1, 4, 1, 5]          （长度 5，下标 1~5）
pre = [0, 3, 4, 8, 9, 14]      （长度 6，pre[0] 永远是 0）

pre[0] = 0            ← 人为规定，非常关键（后面对公式有用）
pre[1] = a[1] = 3
pre[2] = a[1]+a[2] = 4
pre[3] = 3+1+4 = 8
pre[i] = pre[i-1] + a[i]
```

### 1.2 ⭐ 区间和公式（今天的核心中的核心）

求 `a[l] + a[l+1] + ... + a[r]`：

```
a[l] + ... + a[r]  =  pre[r] - pre[l-1]
```

**为什么？** 画个图就懂了：

```
pre[r]     = a[1] + a[2] + ... + a[l-1] + a[l] + ... + a[r]
                                    └──────── 这一段多算的 ────────┘
pre[l-1]   = a[1] + a[2] + ... + a[l-1]

相减 → 前面那截被消掉，只剩下 a[l]...a[r]  ✅
```

**验证**：`a = [3,1,4,1,5]`，求下标 2~4（即 `1+4+1 = 6`）：
```
pre[4] - pre[1] = 9 - 3 = 6   ✅
```

> ⚠️ **`pre[0] = 0` 不是装饰，是公式的一部分**：
> 当 `l = 1` 时公式是 `pre[r] - pre[0]`，没有 `pre[0]=0` 就要单独判 `if l == 1`。
> **用"多开一个位置"换掉一个 if** —— 这是写算法题最常用的手法。

### 1.3 Python 写法（注意下标从 0 开始）

Python 的列表下标从 0 开始，但**前缀和的公式习惯用 1 开始**，所以：

```python
a = list(map(int, input().split()))     # a[0] 是第一个数

# 开 n+1 个位置，pre[0] = 0，pre[i] 对应"前 i 个"
n = len(a)
pre = [0] * (n + 1)
for i in range(1, n + 1):
    pre[i] = pre[i-1] + a[i-1]          # ⚠️ a[i-1]！pre 的下标比 a 多 1

# 求"第 l 个数到第 r 个数"（题目里的 l、r 是从 1 开始数的）
print(pre[r] - pre[l-1])
```

> ⚠️ **最容易错的地方：`pre[i] = pre[i-1] + a[i-1]` 里的 `a[i-1]`**。
> `pre` 用 1 开始、`a` 用 0 开始，**差一个**。写错就整体错位。
> 防错技巧：用 `accumulate`（见第 7 节），它自动帮你对齐。

## 2. 差分数组（前缀和的"逆运算"）

### 2.1 问题场景

题目：给一个数组，做 10 万次"**把第 L 到第 R 个数都加 v**"的操作，最后输出整个数组。

**暴力**：每次操作循环 `a[L] += v ... a[R] += v` → 每次 O(n) → 10 万 × 10 万 → **超时**。

**差分**：每次操作**只改两个位置**。

### 2.2 定义

**差分数组 `d`**：`d[i] = a[i] - a[i-1]`

```
a = [3, 1, 4, 1, 5]
d = [3, -2, 3, -3, 4]        （d[1] = 3-0 = 3，d[2] = 1-3 = -2，……）
```

反过来：**`a` 是 `d` 的前缀和**。两者互为逆运算：

```
d --前缀和--> a
a --相邻相减--> d
```

### 2.3 ⭐ 区间加公式

要把 `a[L]...a[R]` 都加 `v`，只需改 `d` 的两个位置：

```
d[L] += v
d[R+1] -= v
```

**为什么？** 再看图：

```
d[L] += v  → 从 L 开始，后面每个数的"增量"都多了 v（也就是 L 往后全都 +v 了）
d[R+1] -= v → 从 R+1 开始，把多加的 v 抵消掉
```

合起来就是：**L 到 R 之间 +v，R 之后不受影响** ✅

**验证**：`a = [3,1,4,1,5]`，把下标 2~4 都 +10：

```
d 原本     = [3, -2, 3, -3, 4]
d[2] += 10 → [3, 8, 3, -3, 4]
d[5] -= 10 → [3, 8, 3, -3, -6]      ← R+1 = 5

复原成 a（前缀和）：[3, 11, 14, 11, -1]

检查： a 原本 [3, 1, 4, 1, 5] → 下标 2~4 加 10 → [3, 11, 14, 11, 5]
                                                   ✅ 前四个对上了
```

❌ **等等，最后一个变了！** 这是新手最容易踩的坑：

> ⚠️ **`R+1` 可能越界**（这里 R = 4，但数组只有 5 个位置，`d[5]` 不存在）。
> 标准做法：**差分数组多开一格**，`d` 开 `n+2` 个位置。
> 让 `d[n+1] -= v` 记在那里，**复原时只取前 n 个**，多出来的那格自然被忽略。

正确做法：

```python
n = len(a)
d = [0] * (n + 2)                    # ⭐ 多开 2 格，给 R+1 留位置

# 建差分
d[1] = a[0]
for i in range(2, n + 1):
    d[i] = a[i-1] - a[i-2]

# 区间 [L, R] 加 v（每次 O(1)！）
d[L] += v
d[R+1] -= v                          # ⭐ R 可能是 n，所以 d 要开到 n+1

# 复原（前缀和）
cur = 0
for i in range(1, n + 1):
    cur += d[i]
    a[i-1] = cur                     # 或者直接 print
```

### 2.4 什么时候用差分？

| 场景 | 用什么 |
|---|---|
| 多次**区间求和**（数组不变） | **前缀和** |
| 多次**区间加**，最后统一输出 | **差分** |
| 多次区间加**且**多次区间求和 | 两个都不够 → 用**树状数组 / 线段树**（以后学） |

> ⭐ 一句话记住：**"查"用前缀和，"改"用差分。**

## 3. 前缀和的三个"变种"（都很常考）

### 3.1 前缀积 / 前缀最大 / 前缀异或

前缀和的思想可以搬给任何"可结合的运算"：

```python
pre_max[i] = max(pre_max[i-1], a[i])         # 前 i 个的最大值
pre_xor[i] = pre_xor[i-1] ^ a[i]             # 前 i 个的异或
```

> ⚠️ 但**减法要成立**才能反推区间值。
> `pre_max` **不能**做 `pre_max[r] - pre_max[l-1]` 来求区间最大值（最大值不可减）。
> 前缀和/前缀异或可以（异或的逆运算是它自己）。

### 3.2 后缀和

从右往左累加：

```python
suf = [0] * (n + 1)
for i in range(n - 1, -1, -1):
    suf[i] = suf[i+1] + a[i]
```

**典型用法**："每个位置左边之和 = 右边之和"这类题目（左边用前缀和，右边用后缀和）。

### 3.3 差分数组的"覆盖次数"用法

差分不只用来加数字，还能统计**每个位置被多少个区间覆盖**：

```python
d[L] += 1
d[R+1] -= 1
# 复原后，a[i] 就是"覆盖位置 i 的区间个数"
```

⭐ 这是"借教室 / 活动安排 / 排班"类题目的标准套路。

## 4. 二维前缀和

### 4.1 定义

`pre[i][j]` = 矩阵从左上角 `(1,1)` 到 `(i,j)` 这个**矩形内所有数之和**。

```
matrix = [[1, 2, 3],
          [4, 5, 6],
          [7, 8, 9]]

pre = [[0, 0, 0, 0],
       [0, 1, 3, 6],
       [0, 5, 12, 21],
       [0, 12, 27, 45]]
```

### 4.2 ⭐ 递推公式（容斥原理）

```
pre[i][j] = pre[i-1][j] + pre[i][j-1] - pre[i-1][j-1] + matrix[i][j]
```

**看图理解**：

```
┌───────────────┬───────┐
│   pre[i-1][j-1]│ 上面  │
│      （多减）  │       │
├───────────────┼───────┤
│      左边      │ (i,j) │
└───────────────┴───────┘

上面的矩形 + 左边的矩形 = 左上角那块被算了两次 → 减掉一次
再加当前格子自己
```

### 4.3 ⭐ 子矩阵求和公式

求 `(x1,y1)` 到 `(x2,y2)` 的矩形和（`x1<=x2`, `y1<=y2`）：

```
sum = pre[x2][y2] - pre[x1-1][y2] - pre[x2][y1-1] + pre[x1-1][y1-1]
```

**理解**：大矩形 − 上面一条 − 左边一条 + 左上角（减了两次，加回来一次）。

图：

```
        y1      y2
     ┌───┬───────┐
x1   │ ? │       │     求这个 ? 区域
     ├───┼───────┤
x2   │   │       │
     └───┴───────┘

pre[x2][y2]          整个大矩形
-pre[x1-1][y2]       减掉上方那条
-pre[x2][y1-1]       减掉左方那条
+pre[x1-1][y1-1]     左上角被减了两次，加回来
```

**验证**：matrix 里求 `(2,2)` 到 `(3,3)`（即 5+6+8+9 = 28）：

```
pre[3][3] - pre[1][3] - pre[3][1] + pre[1][1]
= 45 - 6 - 12 + 1 = 28   ✅
```

### 4.4 Python 写法

```python
n, m = map(int, input().split())
mat = [[0] * (m + 1)]                              # 第 0 行全 0（哨兵行）
for _ in range(n):
    mat.append([0] + list(map(int, input().split())))   # 每行前面补个 0

pre = [[0] * (m + 1) for _ in range(n + 1)]        # ⚠️ 不能用 [[0]*..]*.. ！
for i in range(1, n + 1):
    for j in range(1, m + 1):
        pre[i][j] = pre[i-1][j] + pre[i][j-1] - pre[i-1][j-1] + mat[i][j]
```

> ⚠️ **`[[0]*(m+1)]*(n+1)` 是浅拷贝大坑**（Day6 踩过）——所有行是**同一个列表**！
> 必须用推导式 `[[0]*(m+1) for _ in range(n+1)]`。

## 5. 复杂度对比表（背下来）

| 做法 | 建表 | 单次区间和 | 10^5 次查询 |
|---|---|---|---|
| 暴力 `sum(a[l-1:r])` | 无 | O(n) | **10^10 → 超时** |
| **前缀和** | O(n) | **O(1)** | 10^5 → **秒过** |
| 暴力区间加 | 无 | 每次 O(n) | **10^10 → 超时** |
| **差分** | O(n) | 每次 **O(1)**（改两个位置） | 10^5 → **秒过** |

## 6. 蓝桥实战套路（看到关键词就选工具）

| 题目里的关键词 | 用什么 |
|---|---|
| "多次查询区间和" / "子数组和" | 前缀和 |
| "多次把 L 到 R 加上/减去 v" | 差分 |
| "每个位置被多少个区间覆盖" | 差分（计数版） |
| "子矩阵和" / "矩形区域求和" | 二维前缀和 |
| "左边之和 vs 右边之和" | 前缀和 + 后缀和 |
| "判断能不能满足所有请求"（借教室类） | 差分 + 遍历检验 |

## 7. Python 写法的省事技巧

### 7.1 `itertools.accumulate`（一行建前缀和）

```python
from itertools import accumulate

a = [3, 1, 4, 1, 5]
pre = [0] + list(accumulate(a))
# pre = [0, 3, 4, 8, 9, 14]      ⭐ 和手写完全一样，但一行搞定
```

> ⭐ 推荐用这个：**手写 `pre[i] = pre[i-1] + a[i-1]` 极容易错位**，`accumulate` 不会错。

### 7.2 输入读得快一点

题目说"第一行 n 个数"，可以直接一次读完：

```python
import sys
data = list(map(int, sys.stdin.read().split()))     # 把所有输入一次性读成数字列表
```

数据量大（10 万行以上）时，**`sys.stdin.read()` 比逐行 `input()` 快很多**。
（蓝桥里 Python 常靠这招从超时边缘救回来）

### 7.3 别用 `a.insert(0, 0)` 给列表补哨兵

`insert(0, ...)` 是 O(n)（后面所有元素都要挪）。用**拼接**代替：

```python
mat.append([0] + row)        # ✅ O(m)
row.insert(0, 0)             # ❌ 也能用，但慢
```

## 8. 常见坑速查

| 坑 | 现象 | 正确写法 |
|---|---|---|
| 忘了 `pre[0] = 0` | `l=1` 时 `pre[0]` 取到最后一个元素，结果离谱 | `pre = [0] + list(accumulate(a))` |
| `pre[i] = pre[i-1] + a[i]` | 整体错位一位 | 记住是 `a[i-1]`，或用 `accumulate` |
| 差分数组没多开一格 | `R = n` 时 `d[n+1]` 越界 IndexError | `d = [0] * (n + 2)` |
| 二维前缀和用 `[[0]*m]*n` | 改一行所有行都变 | 推导式 `[[0]*m for _ in range(n)]` |
| 子矩阵公式少写一项 | 边界（`x1=1`）时结果错 | 四项一个都不能少（含 `+pre[x1-1][y1-1]`） |
| 题目下标从 1 起，代码从 0 起 | 差一位 | **统一成 1 开始**（补哨兵），最省心 |
| `sum(a[l:r])` 切错边界 | 少了或多了一个数 | `a[l-1:r]` 才是第 l 到第 r 个（Python 切片右端不含） |

## 9. 自测习惯

相比 Day9，今天多两个必测：

1. **边界 `l = 1` 和 `r = n`**（最容易漏，因为有 `pre[0]` 和 `R+1`）
2. **单元素区间**（`l == r`）
3. **对拍**：写个暴力版和前缀和版，**同一组数据比结果**——
   算法题最靠谱的验证手段就是"**拿慢的验快的**"。
