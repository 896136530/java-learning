### 题 1：前缀和数组与区间和（Ex1_prefix_basic.py）

**输入**：
- 第一行一个整数 `n`
- 第二行 `n` 个整数（数组 `a`，`a[1]` 是第一个）
- 第三行两个整数 `l r`

**输出**：
- 第 1 行：前缀和数组 `pre`（`n+1` 个数用空格隔开，**从 `pre[0]` 开始**）
- 第 2 行：`a[l]` 到 `a[r]` 的和（一个整数）

**要求**：区间和**必须用 `pre[r] - pre[l-1]` 算**，不许用 `sum(...)`。

**自测**：`l = 1`（考验 `pre[0] = 0`）、`l == r`（单元素）、`r = n`（整段）。

---

### 题 2：单次区间加（差分）（Ex2_diff_basic.py）

**输入**：
- 第一行一个整数 `n`
- 第二行 `n` 个整数（原数组）
- 第三行三个整数 `L R v`（把第 `L` 到第 `R` 个数**都加** `v`）

**输出**：一行，修改后的数组（`n` 个数空格隔开）

**要求**：用**差分**做（`d[L] += v; d[R+1] -= v`，再前缀和复原），不许循环加。

**自测**：`R = n`（⭐ `d[R+1]` 越界，看你有没有多开一格）、`L == R`、`v` 是负数。

---

### 题 3：子矩阵求和（Ex3_prefix_2d.py）

**输入**：
- 第一行两个整数 `n m`
- 接下来 `n` 行，每行 `m` 个整数（矩阵）
- 下一行四个整数 `x1 y1 x2 y2`（保证 `x1<=x2`，`y1<=y2`）

**输出**：一行一个整数 —— 以 `(x1,y1)` 为左上角、`(x2,y2)` 为右下角的子矩阵所有数之和

**要求**：用二维前缀和，四项容斥公式，不许两层循环暴力加。

**自测**：整个矩阵（`x1=1,y1=1,x2=n,y2=m`）、单个格子、第一行/第一列（考验 `pre[0][*]`）。

> ⚠️ 提醒：`pre` 用 `[[0]*(m+1) for _ in range(n+1)]`，别写 `[[0]*(m+1)]*(n+1)`。

---

### 题 4：每个位置被几个区间覆盖（Ex4_range_cover.py）⭐

**输入**：
- 第一行两个整数 `n k`（`n` 是位置数，`k` 是区间个数）
- 接下来 `k` 行，每行两个整数 `l r`（表示区间 `[l, r]` 覆盖了这些位置）

**输出**：一行 `n` 个整数 —— 每个位置被多少个区间覆盖

**要求**：用差分做（`d[l] += 1; d[r+1] -= 1`），复杂度 O(n+k)。

**自测**：区间之间有重叠、有完全相同的区间、`l == r`、某个位置完全没被覆盖（应该是 0）。

> 💡 这题是"差分加的不是数字，而是**次数**"——同一套公式，换个解释。

---

### 题 5：借教室（顺序判定）（Ex5_borrow.py）⭐⭐

**场景**：学校有 `n` 天，第 `i` 天最多能借出 `r[i]` 间教室。
依次来了 `k` 个申请，第 `j` 个申请要"第 `L_j` 天到第 `R_j` 天，**每天**借 `v_j` 间"。

**按顺序处理**：一旦某天的**累计借出量超过了当天的上限**，后面的申请就不能再批了。

**输入**：
- 第一行一个整数 `n`
- 第二行 `n` 个整数（每天的上限 `r[i]`）
- 第三行一个整数 `k`
- 接下来 `k` 行，每行三个整数 `L R v`

**输出**：
- 如果**所有申请都能满足** → 输出一行 `0`
- 否则 → 输出两行：第 1 行是**第一个无法满足的申请编号**（从 1 开始数），
  第 2 行是**那天超量的位置编号**（从 1 开始数；如果有多个位置超量，输出**编号最小的那个**）

**要求**：
- 用差分把"每天借出量"建出来（每次申请 `d[L] += v; d[R+1] -= v`），再用前缀和复原
- **每处理完一个申请就检验一次**（发现不行就立刻输出并结束）

> ⚠️ 想清楚：能不能先把**所有**申请都差分完再一起检验？
> （答案是不能——题目要的是"**第一个**失败的申请编号"，全部合在一起就分不出是第几个了）
>
> 💡 进阶想法：如果 k 很大（10 万），"每个申请都重建一次"会超时。
> 那时要用**二分答案**（Day14 会讲：二分"答案在哪个申请"）。

**自测**：所有申请刚好卡在上限（能过）、第 1 个申请就不行、最后一个申请才不行、
多个申请叠在同一天上、**有位置超量但最大值不是第一个超的位置**（考验"编号最小"那个要求）。

### 题 6：左边之和 = 右边之和（Ex6_left_right.py）

**输入**：
- 第一行一个整数 `n`
- 第二行 `n` 个整数

**输出**：一行 —— **第一个**满足"它**左边所有数之和** 等于 它**右边所有数之和**"的位置编号（从 1 开始数）。
如果没有任何位置满足，输出 `-1`。

**注意**：这个位置**自己不算在左边也不算在右边**。

**要求**：用**前缀和**求左边之和、**后缀和**求右边之和，别用切片 `sum()` 硬算（会 O(n²)）。

**自测**：`n = 1`（左右都是 0，应该输出 1）、第一个位置就满足、最后一个位置才满足、
一个都不满足、**有多个满足但要求输出第一个**。

### 🎯 复习：区间修改 + 区间查询（Review.py）⭐⭐

**输入**：
- 第一行两个整数 `n q`
- 第二行 `n` 个整数（初始数组）
- 接下来 `q` 行，每行是下面两种操作之一：
  - `1 L R v` —— 把第 `L` 到第 `R` 个数都加 `v`
  - `2 L R`   —— 询问第 `L` 到第 `R` 个数的和

**输出**：对每个 `2` 操作，输出一行一个整数（按出现顺序）

**要求**：
- 每个 `1` 操作用差分只改**两个位置**（O(1)）
- 每个 `2` 操作前，**先把当前数组复原出来**（差分前缀和），再用前缀和求区间和
- 建议写两个函数：`rebuild()`（差分位移 → 当前数组）和 `range_sum(l, r)`（前缀和求区间和）

> ⚠️ 注意顺序：**先处理完所有 `1` 操作再问**不对 —— 操作是**交替**的，
> 每次询问必须反映它**之前**的所有修改。

**自测**：询问在两个修改之间（考验"及时复原"）、修改后区间和变小（加负 v）、
`l == r`、`L == R`、一次修改都不做只有询问。

**数据范围**

- 保证 `1 <= l <= r <= n`

**样例输入 1**（先拿它试）

**样例输入 2**（⭐ 全是 0，专测边界）

### 真题 2：借教室（`真题2_借教室.py`）

**问题描述**

学校有 `n` 天可以借教室，第 `i` 天最多借出 `r[i]` 间。
现在有 `k` 个申请**按顺序**提交，第 `j` 个申请要"第 `L` 天到第 `R` 天，**每天**借 `v` 间教室"。

学校按顺序审批：**只要某天的累计借出量超过了上限，这个申请就不能批**，且**它后面的申请也全部不批**。

请找出**第一个**无法满足的申请。

> 💡 这题来自蓝桥/NOIP 里的经典套路（"借教室"），核心是**差分 + 顺序判定**。
> 用暴力"每个申请循环加一遍"会超时，用差分每次只改两个位置。

**输入格式**
- 第一行一个整数 `n`
- 第二行 `n` 个整数 `r[1] ~ r[n]`
- 第三行一个整数 `k`
- 接下来 `k` 行，每行三个整数 `L R v`

**输出格式**
- 如果全部申请都能满足 → 输出一行 `0`
- 否则 → 输出两行：
  - 第 1 行：第一个无法满足的申请编号（从 1 开始）
  - 第 2 行：那天**编号最小**的超量位置（从 1 开始）

**数据范围**
- `1 <= n <= 100000`，`0 <= r[i] <= 10^9`
- `1 <= k <= 100000`，`1 <= L <= R <= n`，`0 <= v <= 10^9`

**样例输入 1**（⭐ 全部刚好卡满上限，能全部满足）
```
5
10 10 10 10 10
3
1 3 4
2 4 3
3 5 3
```
**样例输入 2**（第 1 个申请就超了）
```
4
1 1 1 1
2
1 4 2
1 2 1
```
**样例输入 3**（⭐ 多申请叠在同一天上）
```
6
3 3 3 3 3 3
5
2 4 2
1 6 1
3 3 1
2 2 1
5 5 2
```

> 💡 自己手算时**逐天列个表**（第 1 天借了几间、第 2 天……），一眼就能看出哪天爆。
> 建议再造一组：只有一个申请、且它自己就超了；还有 `n=1`。

### 真题 3：矩阵查数（`真题3_矩阵查数.py`）⭐⭐⭐

**问题描述**

小蓝有一张 `n` 行 `m` 列的数字表格（镶在墙上的一幅"数字画"）。
他会问你 `q` 次：**以 `(x1,y1)` 为左上角、`(x2,y2)` 为右下角**的那一小块矩形，
里面所有数字加起来是多少？

行列数最大 1000，询问最大 10 万 —— 暴力加会超时，请用**二维前缀和**。

**输入格式**
- 第一行两个整数 `n m`
- 接下来 `n` 行，每行 `m` 个整数（表格内容）
- 下一行一个整数 `q`
- 接下来 `q` 行，每行四个整数 `x1 y1 x2 y2`（保证 `x1<=x2`，`y1<=y2`）

**输出格式**
- `q` 行，每行一个整数 —— 对应查询的子矩阵和

**数据范围**
- `1 <= n, m <= 1000`
- `0 <= 表格里的数 <= 1000`
- `1 <= q <= 100000`
- 保证 `1 <= x1 <= x2 <= n`，`1 <= y1 <= y2 <= m`

**样例输入 1**
```
3 3
1 2 3
4 5 6
7 8 9
4
1 1 3 3
2 2 3 3
1 1 1 1
3 1 3 3
```
**样例输入 2**（单行数组，考验 `n=1`）
```
1 5
9 8 7 6 5
3
1 1 1 5
1 2 1 4
1 5 1 5
```

> 💡 提示：四项容斥一个都不能少，尤其是 `+ pre[x1-1][y1-1]`（最容易漏）。
> 手算技巧：先在纸上把 `pre` 表画出来（`(n+1)×(m+1)` 那张），再套公式，错不了。

## 三、检查清单（交作业前自己过一遍）

- [ ] 每题至少跑了**三组**数据：正常 + **`l = 1` 的边界** + **`r = n` 的边界**
- [ ] 前缀和数组的 `pre[0] = 0` 都在（用 `[0] + list(accumulate(a))` 最稳）
- [ ] 差分数组**多开了格子**（`n+2`），`R = n` 时 `d[R+1]` 不越界
- [ ] 二维前缀和用的是**推导式**建的（不是 `[[0]*m]*n`）
- [ ] 子矩阵公式**四项齐全**（含加回左上角那项）
- [ ] 输出的一行里**没有混进提示文字**（不准出现"请输入：""结果是："）
- [ ] 题 5 是"**第一个**失败的申请编号"，不是"总共失败几个"
- [ ] 题 6 输出的是"**第一个**满足的位置"，不是"所有满足的位置"
- [ ] 复习题的询问是**交替**的（每次询问都要反映它之前的修改）
- [ ] **没有用切片 `sum(a[l-1:r])` 偷懒**（题 1、题 6 明确要求不许）
