### 题 1：有序数组两数之和（Ex1_left_right_sum.py）

**输入**：
- 第一行两个整数 `n target`
- 第二行 `n` 个整数（数组 `a`，**保证非递减**）

**输出**：一行
- 如果存在两个**不同位置**的数之和等于 `target` → 输出这两个数的**下标**（从 1 开始数，小的在前，空格隔开）
- 不存在 → 输出 `-1`

**数据范围**：`2 <= n <= 100000`，`|a[i]| <= 10^9`，`|target| <= 2*10^9`
**保证**：数据里**最多只有一组解**。

**要求**：用**左右指针**（`l=0`、`r=n-1`，每次比较淘汰一个），复杂度 **O(n)**；
不许双重循环 `for i: for j:`（O(n²) 会超时）。

> 💡 提示：`a[l] + a[r] > target` 就把 `r` 往左收，`< target` 就把 `l` 往右推。
> 想清楚"为什么被淘汰的那个元素可以永久不要了"（数组有序是关键）。

**样例输入 1**
```
5 9
1 2 4 7 11
```
**样例输出 1**
```
2 4
```

**样例输入 2**（⭐ 无解，考验 `-1` 分支）
```
4 20
1 3 5 8
```
**样例输出 2**
```
-1
```

**自测**：答案是**最左边两个**（`l` 一开始就命中）、答案是**最右边两个**、无解、
**有重复数字**（如 `2 2 4`，`target=4` → 应输出 `1 2`）、`n = 2`。

### 题 2：验证回文（Ex2_palindrome.py）

**输入**：一行一个字符串 `s`（只含**小写字母和数字**，长度 `1 <= |s| <= 100000`）

**输出**：一行 —— `YES`（是回文）或 `NO`（不是）

**要求**：用**左右指针**从两端往中间比，复杂度 **O(n)**、**O(1)** 额外空间。
**不许**写 `s == s[::-1]`、也不许 `s.reverse()`。

> 💡 提示：`i` 从头、`j` 从尾，`s[i] != s[j]` 就**立刻**输 `NO` 结束（不用比完）。
> 注意循环条件是 `i < j`（奇数长度的中间那个字符不用比）。

**样例输入 1**
```
level
```
**样例输出 1**
```
YES
```

**样例输入 2**（⭐ 第一个和最后一个就不一样，考验"提前退出"）
```
abca
```
**样例输出 2**
```
NO
```

**自测**：`|s| = 1`（单字符一定是回文）、`|s| = 2`、全是同一个字符、
**含数字**（如 `a1b2b1a`）、**只差中间一个字符**（如 `abxba` 是回文、`abxca` 不是）。

### 题 3：有序数组去重（Ex3_dedup_sorted.py）

**输入**：
- 第一行一个整数 `n`
- 第二行 `n` 个整数（**保证非递减**）

**输出**：两行
- 第 1 行：去重后的元素**个数** `k`
- 第 2 行：去重后的 `k` 个元素（保持升序，空格隔开）

**数据范围**：`1 <= n <= 100000`，`|a[i]| <= 10^9`

**要求**：用**快慢指针**（`fast` 读、`slow` 写）**原地**去重，复杂度 **O(n)**；
**不许**用 `set`、也不许 `sorted(set(a))`（那要多开 O(n) 的空间）。

> 💡 提示：`fast` 从 1 扫到 `n-1`；只要 `a[fast] != a[slow]`，就先 `slow += 1` 再把
> `a[fast]` 写到 `a[slow]`。**循环结束后有效长度是 `slow + 1`（不是 `slow`！）**

**样例输入 1**
```
8
1 1 2 2 3 5 5 5
```
**样例输出 1**
```
4
1 2 3 5
```

**样例输入 2**（⭐ 全是同一个数）
```
5
7 7 7 7 7
```
**样例输出 2**
```
1
7
```

**自测**：`n = 1`、**完全没有重复**（应该原样输出）、**重复的元素连续很多个**、
第一个元素就重复、最后一个元素是新的（考验 `slow` 有没有漏加最后一次）。

### 题 4：盛水容器（Ex4_container.py）⭐⭐

**输入**：
- 第一行一个整数 `n`
- 第二行 `n` 个整数 `h[i]`（`h[i] >= 0`，表示第 `i` 条竖线的高度）

**输出**：一行一个整数 —— 能装的最大水量

> **装水量定义**：选两条线 `i < j`，水量 = `min(h[i], h[j]) * (j - i)`（面积）。

**数据范围**：`2 <= n <= 100000`，`0 <= h[i] <= 10^9`

**要求**：用**左右指针 + 贪心**（每次移动**较短**的那条边），复杂度 **O(n)**；
不许 `for i: for j:` 枚举所有线对（O(n²) 会超时）。

> 💡 提示：从最宽的两端开始（宽度最大），**只移动较短的那根**才可能变大。
> 移动长的那根，宽度一定变小、高度又不会变大 → 白算。

**样例输入 1**
```
9
1 8 6 2 5 4 8 3 7
```
**样例输出 1**
```
49
```

**样例输入 2**（⭐ `n = 2`，只能选这一对）
```
2
3 9
```
**样例输出 2**
```
3
```

**自测**：**高度全一样**（答案是 `h * (n-1)`，最宽的一对）、**两端就是最优**、
**最优在中间**、**有 0 高度**、**高度递增 / 递减**（考验"该动哪边"）。

### 题 5：找重复数字（Ex5_find_duplicate.py）⭐⭐⭐

**输入**：
- 第一行一个整数 `n`
- 第二行 `n + 1` 个整数（每个都在 `[1, n]` 之间）

**输出**：一行一个整数 —— 那个**重复**的数字

**保证**：**恰好有一个数字出现了多次**，其余数字都恰好出现 1 次。

**数据范围**：`1 <= n <= 100000`

**要求**：**快慢指针（Floyd 判圈）**，复杂度 **O(n)**、额外空间 **O(1)**。
**不许**排序、**不许**开计数数组、**不许**用 `set`（这题的全部意义就是 O(1) 空间）。

> 💡 提示：把**下标**当成节点，把 `a[i]` 当成 `i` 的"next 指针"，于是这串数变成一条
> **必然带环的链表**，**环的入口就是重复的那个数字**。
> 三步：① `slow=a[0]`、`fast=a[a[0]]` 追到相遇；② `p = 0`；③ `p` 和 `slow` 同速前进，相遇处即答案。
> ⚠️ 第一步的起点**不能**是 `0` 和 `0`（那样第一轮就相遇了）。

**样例输入 1**
```
5
1 3 4 2 2
```
**样例输出 1**
```
2
```

**样例输入 2**（⭐ 重复的不是最后一个，小心"想当然"）
```
4
3 1 3 4 2
```
**样例输出 2**
```
3
```

**自测**：`n = 1`（只有两个数，一定是同一个数）、重复的数字在**第一位**、
重复的数字在**最后一位**、`a[0]` 本身就是重复的那个、**同一个数字出现 3 次**。

### 题 6：定长窗口最大和（Ex6_window_fixed.py）

**输入**：
- 第一行两个整数 `n k`
- 第二行 `n` 个整数（**可以为负**）

**输出**：一行一个整数 —— 长度**恰好为 `k`** 的连续子数组的**最大和**

**数据范围**：`1 <= k <= n <= 100000`，`|a[i]| <= 10^9`

**要求**：**定长滑动窗口**，复杂度 **O(n)**：窗口右移时**加进右边、减掉左边**；
不许每次 `sum(a[i:i+k])` 重算（O(n·k) 会超时）。

> 💡 提示：先算第一个窗口的和，然后 `cur += a[i] - a[i-k]`。
> ⚠️ `best` 的初值要用**第一个窗口的和**（不能写 0，否则全负数的数据会输出 0）。

**样例输入 1**
```
6 3
2 1 5 1 3 2
```
**样例输出 1**
```
9
```

**样例输入 2**（⭐ `k = 1`，等价于"求最大值"）
```
5 1
-3 4 -1 5 -2
```
**样例输出 2**
```
5
```

**样例输入 3**（⭐ `k = n`，只有一个窗口；且有负数）
```
4 4
1 -2 3 4
```
**样例输出 3**
```
6
```

**自测**：`k = 1`、`k = n`、**全是负数**（考验初值）、最大值在**最左边**、
最大值在**最右边**（考验循环边界有没有差一）。

### 🎯 复习：和不超过 S 的最长子数组（Review.py）⭐⭐

**输入**：
- 第一行两个整数 `n S`
- 第二行 `n` 个整数（**都是正整数**，`a[i] >= 1`）

**输出**：两行
- 第 1 行：满足"**区间和 <= S**"的最长连续子数组的**长度**（一个都没有 → 输出 `0`）
- 第 2 行：那个区间的**左右端点**（从 1 开始数，空格隔开）；
  一个都没有 → 输出 `0 0`；**若有多个等长，输出最靠左的那个**

**数据范围**：`1 <= n <= 100000`，`1 <= S <= 10^9`，`1 <= a[i] <= 10^9`

**要求**：**变长滑动窗口**，复杂度 **O(n)**：`r` 扩张、`l` 收缩；
**不许**用前缀和 + 双重循环枚举所有区间（O(n²) 会超时）。

> 💡 提示：`cur` 是窗口 `[l, r]` 的和。`cur > S` 就 `while` 一直退 `l`（**不是 `if`！**）。
> 退到合法之后，`r-l+1` 就是"以 `r` 结尾的最长合法区间长度"。
> ⚠️ 因为**数组全是正数**，退 `l` 之后一定重新合法，滑动窗口才成立。
> ⚠️ "最靠左"：只在**严格变长**时才更新答案（用 `>` 不要用 `>=`）。

**样例输入 1**
```
7 10
3 1 4 2 1 1 5
```
**样例输出 1**
```
5
2 6
```

**样例输入 2**（⭐ 一个都装不下：`S` 比所有元素都小）
```
3 1
5 3 4
```
**样例输出 2**
```
0
0 0
```

**样例输入 3**（⭐ 有多个等长，考验"最靠左"）
```
4 5
2 3 2 3
```
**样例输出 3**
```
2
1 2
```

**自测**：`n = 1` 且 `a[0] <= S`（输出 `1` 和 `1 1`）、`n = 1` 且 `a[0] > S`（输出 `0` 和 `0 0`）、
**整个数组刚好不超**（输出 `n` 和 `1 n`）、`S` 很大（答案就是 `n`）、
**并列时最靠左**（样例 3 就是）、**单个元素超过 S** 但要继续往右找（考验 `while` 有没有写对）。

### 综合训练 1：最长无重复子串（`真题1_最长无重复子串.py`）⭐⭐

**问题描述**

小蓝有一个只含小写字母的字符串 `s`。他想知道：**最长的一段连续字符**，
要求这段里**每个字母都不重复**（也就是没有哪个字母出现两次）。
请你把这段的长度**和这段内容**都找出来。

> 💡 这题来自"**滑动窗口 + 判重**"的经典套路：右指针一直扩，
> 一旦新字符和窗口里的某个字符撞了，就把左指针**直接跳到那个字符的下一位**。

**输入格式**
- 一行一个字符串 `s`（只含小写字母，长度 `1 <= |s| <= 100000`）

**输出格式**
- 第 1 行：最长无重复子串的**长度**
- 第 2 行：那个子串**本身**（若有多个等长，输出**最靠左**的那个）

**数据范围**
- `1 <= |s| <= 100000`
- `s` 只含小写字母 `a`~`z`

**样例输入 1**
```
abcabcbb
```
**样例输出 1**
```
3
abc
```

**样例输入 2**（⭐ 全是同一个字母，答案是 1）
```
bbbbb
```
**样例输出 2**
```
1
b
```

**样例输入 3**（⭐ 有多个长度为 3 的答案，考验"最靠左"）
```
pwwkew
```
**样例输出 3**
```
3
wke
```

> 💡 提示：开一个长度 26 的数组 `last`，`last[c]` 记"字符 `c` 上次出现在哪"。
> 窗口不合法时 `l = last[c] + 1` **一步跳过去**，不用一个一个退。
> ⚠️ `last` 的初值要写 `-1`（表示"没出现过"），而且判断时要写 `last[c] >= l`
> （上次出现的位置**还在窗口里**才算重复，在外面就不算）。
> ⚠️ "最靠左"：只在**严格变长**时更新答案（用 `>`）。
>
> **自己再造一组**：`|s| = 1`（输出 `1` 和那个字符）、**整串本身就不重复**（答案就是整串）、
> `aaaaab`（答案是 `2` 和 `ab`——想想为什么不是别的）。

### 综合训练 2：三数之和（计数版）（`真题2_三数之和.py`）⭐⭐⭐

**问题描述**

给 `n` 个整数（**可能有负数，也可能有重复**）和一个目标值 `target`。
请数一数：有多少个**不同的三元组** `(a, b, c)`，满足 `a + b + c == target`？

> ⚠️ **"不同"是指"三个数的值不同"**：
> 例如数组里有两个 `2`，那么 `(2, 2, 5)` 这一组**只算 1 次**，不管你能凑出多少种下标组合。
> 三元组里**三个下标必须互不相同**（同一个位置的数不能用两次）。
> 顺序不算区别：`(1, 2, 3)` 和 `(3, 2, 1)` 是同一组。

**输入格式**
- 第一行两个整数 `n target`
- 第二行 `n` 个整数

**输出格式**
- 一行一个整数 —— 不同三元组的**个数**

**数据范围**
- `1 <= n <= 2000`（⚠️ 只能做到 O(n²)，`n` 不能给到 10 万）
- `|a[i]| <= 10^9`，`|target| <= 3*10^9`

**要求**
- 先**排序**，固定第一个数后对后两个数用**左右指针**，复杂度 **O(n²)**
- 不许三重循环 `for i: for j: for k:`（O(n³) 一定超时）
- ⚠️ **去重是本题的难点**：`i`、`l`、`r` 三个位置都要跳过重复值

**样例输入 1**（经典数据：答案是 2 组 —— `(-1,-1,2)` 和 `(-1,0,1)`）
```
6 0
-1 0 1 2 -1 -4
```
**样例输出 1**
```
2
```

**样例输入 2**（⭐ 无解，考验输出 0）
```
4 100
1 2 3 4
```
**样例输出 2**
```
0
```

**样例输入 3**（⭐ 六个 2 全是重复值，只算 1 组）
```
6 6
2 2 2 2 2 2
```
**样例输出 3**
```
1
```

> 💡 提示：固定 `i` 之后，就是 Day11 题 1 的"两数之和（有序）"，用左右指针 O(n)。
> 去重三处：`i` 处跳过 `a[i] == a[i-1]`、`l` 处跳过和上一个相同的、
> `r` 处跳过和上一个相同的（**只在命中答案、`l` 和 `r` 都动了之后才跳**）。
> ⚠️ 别用 `set` 存三元组再数个数——那样答案是碰巧对的，**但复杂度没达标**。
>
> **自己再造一组**：`n = 3` 刚好三个数（命中 / 不命中各试一次）、
> `0 0 0 0 0`（`target = 0` → 答案是 `1`）、**有正有负**且 `target = 0`、
> **全部相同的 5 个数且 `target` 不等于 `3` 倍那个数**（答案是 0）。

### 综合训练 3：最小覆盖子串（`真题3_最小覆盖子串.py`）⭐⭐⭐

**问题描述**

给两个小写字母字符串 `s` 和 `t`。请在 `s` 里找一段**最短的连续子串**，
要求它里面**包含了 `t` 里的每一个字符**（`t` 中同一个字符出现几次，这段里就至少要几次）。
输出这段的**长度**和**内容**。

> 💡 这是"**滑动窗口 + 计数**"里最经典的一题（比前两题难，因为窗口是否"合格"
> 不再是一个数字的判断，而是**一堆字符的计数是否都够了**）。

**输入格式**
- 第一行一个字符串 `s`（只含小写字母，长度 `1 <= |s| <= 100000`）
- 第二行一个字符串 `t`（只含小写字母，长度 `1 <= |t| <= 100000`）

**输出格式**
- 如果**不存在**这样的子串 → 只输出一行 `0`
- 如果存在 → 输出两行：
  - 第 1 行：最短覆盖子串的**长度**
  - 第 2 行：那个子串**本身**（若有多个等长最短，输出**最靠左**的那个）

**数据范围**
- `1 <= |s|, |t| <= 100000`
- 两个串都只含小写字母 `a`~`z`

**样例输入 1**
```
adobecodebanc
abc
```
**样例输出 1**
```
4
banc
```

**样例输入 2**（⭐ `t` 比 `s` 需要得更多，不存在）
```
a
aa
```
**样例输出 2**
```
0
```

**样例输入 3**（⭐ 整个 `s` 就是答案）
```
aa
aa
```
**样例输出 3**
```
2
aa
```

> 💡 提示：用两个长度 26 的计数数组 `need`（t 需要多少）和 `have`（窗口里有多少），
> 再用一个 `formed` 数"**已经有几个字符达标了**"。
> 右指针扩张时更新 `have`；当 `formed == 需要达标的字符种数` 时，
> **先记录答案、再收缩左指针**，一收缩就可能不达标，于是 `formed` 减回去。
> ⚠️ 是 `have[c] == need[c]` 的那一刻 `formed += 1`（`need[c] == 0` 的字符**不算**）。
> ⚠️ 输出用的是"**新建的短串长度和内容**"，别忘了记录最短时的**起点下标**。
>
> **自己再造一组**：`s == t`（答案就是整个串）、`t` 只有一个字符（答案是那个字符本身）、
> **完全找不到**（如 `s = "ab"`, `t = "c"`，输出一行 `0`）、
> **最靠左的并列**（造两个等长最短子串，看你是不是输出左边那个）。

## 三、检查清单（交作业前自己过一遍）

- [ ] 题 1 用的是 `while l < r`（不是 `l <= r`），且**没有**双重循环
- [ ] 题 2 **没有**写 `s == s[::-1]`，发现不同就**立刻退出**
- [ ] 题 3 的有效长度是 `slow + 1`（不是 `slow`），且**没有**用 `set`
- [ ] 题 4 每次移动的是**较短**的那条边
- [ ] 题 5 起点是 `a[0]` / `a[a[0]]`（不是 `0` / `0`），第 3 步从 `p = 0` 开始
- [ ] 题 6 的 `best` 初值是**第一个窗口的和**（不是 0）
- [ ] 复习题的收缩用的是 `while`（不是 `if`），并列时输出**最靠左**的区间
- [ ] 综 1 / 综 3 有多组等长答案时输出的是**最靠左**的那个
- [ ] 综 2 的 `i`、`l`、`r` **三处都做了去重**，且没用 `set` 偷懒
- [ ] 综 3 的 `t` 里需要多次的字符（`need[c] > 1`）也处理对了
- [ ] 所有 `while` 里**没有** `sum()`、切片、`in`（有的话就退化成 O(n²) 了）
- [ ] 输出的一行里**没有混进提示文字**（不准出现"请输入：""结果是："）
- [ ] 大数据（`n = 100000`）跑一遍**不超过 1 秒**

## 四、综合训练自测（写完自己跑）

写完全部题目后，3 道综合训练题都要能跑通题目下面给的样例：

1. 每道题先把**样例输入**粘进去跑，和你算的对一遍（题目里给了真值，错了就回头想）
2. 对不上就先在纸上画**窗口的移动过程**（`l`、`r`、窗口里的统计量各是多少）——画出来错在哪自己就浮出来了
3. 样例全过之后，自己再**造一组大数据**（比如 `n = 100000`）测一下会不会超时
4. 如果超时 → 说明你在 `while` 里做了 O(n) 的事（`sum()` / 切片 / `in`），先想复杂度再改代码
