# Day 7 知识点：排序与自定义排序

> 前提：Day3 列表、Day6 二维列表都熟了。今天把"排个序"升级成"**按我的规矩排**"——蓝桥的"排名/排行榜/多字段排序"全靠它。
> 一句话：`sorted(数据, key=按什么排, reverse=要不要降序)`

## 1. 两种排序：sort() 和 sorted()

```python
a = [3, 1, 4, 1, 5]

a.sort()              # 原地排序：直接改 a 自己，返回 None
print(a)              # → [1, 1, 3, 4, 5]

b = sorted(a)         # 返回"新列表"：a 不动
print(b)              # → [1, 1, 3, 4, 5]
print(sorted(a, reverse=True))   # → [5, 4, 3, 1, 1]  降序
```

| | `list.sort()` | `sorted()` |
|---|---|---|
| 改谁 | 原地改自己 | 返回新列表，原数据不动 |
| 返回值 | **None**（⚠️ 坑） | 排好的新列表 |
| 能用在 | 只有列表 | 列表/元组/字符串/字典的 keys 都行 |

## 2. 默认排序规则（不知道这个就会写出诡异结果）

| 数据 | 默认按什么升序 |
|---|---|
| 数字 | 数值大小 |
| 字符串 | **Unicode 码点**：`A < Z < a < z`；**中文不是拼音！**`张`(U+5F20) < `李`(U+674E) |
| 元组/列表 | 先比第 1 个元素，相同再比第 2 个……（天然的"多关键字"） |

```python
sorted(["banana", "Apple", "apple"])   # → ['Apple', 'apple', 'banana']（大写字母码点更小）
sorted(["张三", "李四", "王五"])         # → ['张三', '李四', '王五']（按 Unicode 码点，不是拼音顺序）
```

## 3. key= ：排序前先"加工"每个元素

`key` 是一个函数：**排序时拿"key(元素) 的结果"去比大小**，元素本身不动。

```python
words = ["banana", "cat", "apple"]
sorted(words, key=len)          # → ['cat', 'apple', 'banana']    按长度
sorted(words, key=str.lower)    # → 忽略大小写比
sorted([-3, 1, -2], key=abs)    # → [1, -2, -3]                   按绝对值
```

## 4. lambda：一行写完的小函数

`lambda 参数: 返回值` —— 等价于一个临时 def，专门喂给 key 用。

```python
def second(x):        # 普通写法：4 行
    return x[1]

second = lambda x: x[1]        # lambda 写法：1 行，效果一样

rows = [("张三", 88), ("李四", 95)]
sorted(rows, key=lambda x: x[1])   # → 按分数升序：[('张三',88), ('李四',95)]
```

> 记法：`key=lambda x: x[1]` = "拿每个元素的第 2 个字段来比"。`x` 就是列表里的一个元素（这里是一个元组）。

## 5. ⭐ 多关键字排序（今天的心脏）

蓝桥原话："按分数从高到低，分数相同的按姓名从小到大"——**两件事同时管**，靠一个**元组 key**：

```python
rows = [("张三", 88), ("李四", 95), ("王五", 88)]

# key 返回元组时，先比第 1 项，第 1 项相同再比第 2 项
sorted(rows, key=lambda x: (-x[1], x[0]))
# → [('李四',95), ('张三',88), ('王五',88)]
#   分数降序（88 分那两人里，张三(5F20) < 王五(738B)，所以张三在前）
```

**为什么用负号？** `reverse=True` 是**全局开关**，会把所有关键字一起反过来。想让"分数降序、姓名升序"这种**混合方向**，就把要降序的数字**取负**（数字加负号后，原来的"大"变成"小"，升序排就等于降序了）。

> ⚠️ **字符串不能取负**（`-"张"` 直接报错）。姓名这种要"一升一降"混着排的，今天不用管（题目都只要求姓名升序）；真要处理，用第 6 节的两遍排序法。

## 6. 稳定排序 + 两遍排序（了解，蓝桥偶尔用）

Python 的排序是**稳定的**：两个元素"比不出大小"，**原来的先后顺序会被保留**。利用这点可以一首一尾排两次：

```python
# 先按次要关键字排，再按主要关键字排（第二次是主要的，会盖住第一次）
rows.sort(key=lambda x: x[0])                 # 先按姓名升序
rows.sort(key=lambda x: x[1], reverse=True)   # 再按分数降序（同分的人保留了姓名升序）
```

## 7. ⚠️ 今天最大的坑：`a = a.sort()`

```python
a = [3, 1, 2]
a = a.sort()          # ❌ 大坑！sort() 返回 None
print(a)              # → None   （列表本身被排好了，只是返回值是 None）

# ✅ 两种正确写法
a.sort()              # 原地改，直接用 a
a = sorted(a)         # 要赋值就用 sorted
```

**其他常见坑**
- `input()` 忘了 `map(int, ...)` → 变成字符串排序：`'10'` 排在 `'9'` **前面**（因为逐字符比 `'1' < '9'`）
- 字典列表要排序得写字段名：`key=lambda d: d["score"]`（字典不能 `x[1]`）
- `reverse=True` 会**把所有** key 一起反过来（想混方向就取负）
- 中文按 Unicode 码点排，不是拼音——蓝桥题如果要求"按姓名"会明说规则

## 8. 蓝桥考点提示

- **排行榜取前 k 名**：`sorted(数据, key=..., reverse=True)[:k]`（排序 + 切片）
- **多字段排序**：key 里返回元组（分数降序 + 姓名升序）——蓝桥"成绩排名""多关键字"最常考
- **按公式/按绝对值/按位数排**：key 里写你要的规则，比如 `key=lambda x: (abs(x), x)`
- 数据量 n 很大（10⁵ 以上）时，排序是 O(n log n)，放心用 Python 内置排序（它是 C 写的，比自己写冒泡快几十倍）
