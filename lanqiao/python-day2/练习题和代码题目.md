## 题目详情

### 题 1：奇偶判断
- 输入：一个整数 x
- 输出：一行，`奇数` 或 `偶数`
- 提示：能被 2 整除（`x % 2 == 0`）就是偶数

### 题 2：成绩等级
- 输入：一个整数 score（0~100）
- 输出：一行，按分数给等级——
  - ≥90 → `优秀`
  - ≥80 → `良好`
  - ≥60 → `及格`
  - 其余 → `不及格`
- 提示：用 if / elif / else 一串接住，从上往下第一个满足就命中

### 题 3：求 1 到 n 的和
- 输入：一个整数 n
- 输出：一行，1 + 2 + ... + n 的总和
- 提示：while 或 for 都行；先想清楚"循环几遍、加的是谁"

### 题 4：倒序打印 n 到 1
- 输入：一个整数 n
- 输出：一行，`n n-1 ... 2 1`（数字之间一个空格）
- 提示：`range(起点, 终点, 步长)` 的第三个数用 -1；打印时先想清楚"怎么不带多余空格"

### 题 5：n 个数里找最大（蓝桥姿势）
- 输入：
  - 第一行：整数 n（有几个数）
  - 接下来 n 行：每行一个整数
- 输出：一行，其中最大的数
- 提示：读一个记一个，用"打擂法"——初始擂主取第一个数，后面谁更大谁上位

### 🎯 复习：能被 3 整除的数之和
- 输入：一个整数 n
- 输出：一行，1 到 n 之间所有能被 3 整除的数的总和
- 提示：循环里加一个 if 判断——"重复"和"分流"今天的两张牌一起用
