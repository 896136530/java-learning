# Python Day 2 知识点：if 判断 + 循环

> 前提：Day 1 的 print / 变量 / input / 类型转换过关。今天上程序的两大"筋骨"：**判断**（分流）和**循环**（重复干）。

## 1. if / elif / else：按条件分流

```python
score = int(input())

if score >= 90:
    print("优秀")
elif score >= 80:
    print("良好")
elif score >= 60:
    print("及格")
else:
    print("不及格")
```

**三个铁规矩：**
1. 条件后面要有 **冒号 `:`**
2. 下面缩进的代码才是"该条件下的代码"——**缩进就是语法**，统一 4 个空格
3. `elif` 从上往下**第一个满足就执行**，后面的不再看

## 2. 比较运算符（背下来）

| 运算符 | 意思 |
|---|---|
| `==` | 等于（判断相等！不是 `=`）|
| `!=` | 不等于 |
| `>` `<` `>=` `<=` | 大于 / 小于 / 大于等于 / 小于等于 |
| `and` / `or` / `not` | 且 / 或 / 非 |

> ⚠️ 最容易犯的错：`if x = 5` —— 一个 `=` 是赋值，两个 `==` 才是判断。

## 3. while 循环：不知道几次就用它

```python
i = 1
while i <= 5:          # 条件成立就一直循环
    print(i)
    i = i + 1          # ⚠️ 别忘了让条件向"不成立"靠近！否则死循环
```

## 4. for 循环 + range：知道次数就用它（刷题主力）

```python
for i in range(5):          # 0 1 2 3 4
    print(i)

for i in range(1, 6):       # 1 2 3 4 5（含头不含尾！）
    print(i)

for i in range(5, 0, -1):   # 5 4 3 2 1（第三个数是步长，-1 倒着走）
    print(i)
```

> **range 含头不含尾**——`range(1, 6)` 到 5 为止，背下来，蓝桥题一半的 bug 出在这。

## 5. break 和 continue

```python
for i in range(1, 10):
    if i == 3:
        continue      # 跳过本次，继续下一次（3 不打印）
    if i == 7:
        break         # 直接结束整个循环（7 和后面的都不打印）
    print(i)          # 1 2 4 5 6
```

## 6. 蓝桥杯姿势：读多行数据

蓝桥最常见的输入是"**第一行一个数 n，后面 n 个数**"——配 for 循环正合适：

```python
n = int(input())          # 第一行：有几个数
total = 0
for i in range(n):
    x = int(input())      # 第 i+1 行：读一个数
    total = total + x     # 一边读一边处理
print(total)
```
