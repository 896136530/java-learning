### 题 1：递归求和（Ex1_recursive_sum.py）

**输入**：一行一个整数 `n`

**输出**：一行，`1 + 2 + ... + n` 的值

> 💡 提示：出口是 `n == 1` 时返回 `1`；否则 `return n + 自己的(n-1)`。
> ⚠️ 检查一下每个分支是不是都 `return` 了（漏了会返回 `None`，然后 `TypeError`）。


**样例输入 2**（⭐ 最小规模，考验出口）
```
1
```
**样例输出 2**
```
1
```

**自测**：`n = 2`（3）、`n = 500`（500 层递归在默认 1000 层限制内，安全）、

### 题 3：汉诺塔（Ex3_hanoi.py）

**输入**：一行一个整数 `n`

**输出**：

> 💡 提示：写 `hanoi(n, src, tmp, dst, moves)`。
> ⚠️ **参数顺序是本题唯一难点**：递归时"哪个柱当中转"会变，先把角色说清楚再写。

**样例输出 1**

```
7
A->C
A->B

A->C

B->C
A->C
```

**样例输入 2**（⭐ 最小规模，考验出口）
```
1
```
**样例输出 2**
```
1
A->C
```

**自测**：`n = 2`（3 步，自己先手推一遍）、`n = 3`（7 步）、`n = 10`（1023 行，能跑就行）；
检查第一行是不是**步数**（别漏了）。

### 题 4：快速幂（Ex4_fast_pow.py）

**输入**：一行三个整数 `a b p`

**输出**：一行，`a` 的 `b` 次方对 `p` 取模的结果

**数据范围**：`0 <= a <= 1e9`，`0 <= b <= 1e18`，`1 <= p <= 1e9+7`

**要求**：
- 复杂度必须是 **O(log b)**
- **不许**写 `a ** b`
- **不许**用内置的 `pow(a, b, p)`
- **不许**循环乘 `b` 次

> 💡 提示：`b` 是偶数 → `a^b = (a^(b//2))^2`；`b` 是奇数 → 再乘一个 `a`；**每一步都 `% p`**。
> `b == 0` 时答案是 `1 % p`（`p = 1` 时结果是 0，别写死成 1）。
> 函数开头先 `a %= p`。

**样例输入 1**
```
2 10 1000
```
**样例输出 1**
```
24
```

**样例输入 2**（⭐ `b` 是 1e18，循环乘绝对超时）
```
5 1000000000000000000 1000000007
```
**样例输出 2**
```
921116510
```

**自测**：`b = 0`（注意 `p = 1` 时答案 0）、`a = 0`、`b = 1`、
`b` 是 2 的幂（`2 8 1000` → 256）、`p = 1`、
拿 `a**(b%4+20) % p` 之类的小指数交叉验算几组。

### 题 5：归并排序（Ex5_merge_sort.py）

**输入**：
- 第一行一个整数 `n`
- 第二行 `n` 个整数（空格隔开）

**输出**：一行，升序排好的 `n` 个数，空格隔开

**数据范围**：`1 <= n <= 200000`，`|a[i]| <= 1e9`

**要求**：
- 必须**手写归并排序**（对半切 → 两边各排 → 双指针合并）
- 复杂度 `O(n log n)`
- **不许**用 `sorted()`，**不许**用 `list.sort()`

> 💡 提示：出口是 `len(a) <= 1` 直接返回（0 个或 1 个元素天然有序）。
> 合并时用 `<=` 而不是 `<`（相等先拿左边，排序才**稳定**）。
> 谁先走完，另一个剩下的那截 `extend` 接上就行。
> ⚠️ 别在递归里做 O(n) 的查找（如 `if x in left`），否则退化成 O(n²)。

**样例输入 1**
```
8
5 2 9 1 5 6 3 8
```
**样例输出 1**
```
1 2 3 5 5 6 8 9
```

**样例输入 2**（⭐ n=1，考验出口）
```
1
42
```
**样例输出 2**
```
42
```

**自测**：已经升序、完全逆序、全部相同（`-3 0 -3 10 0 -3` → `-3 -3 -3 0 0 10`）、
`n = 200000` 随机数据计时（**应在 1 秒内**）。

### 🎯 复习题：逆序对（Review.py）⭐⭐⭐

**输入**：
- 第一行一个整数 `n`
- 第二行 `n` 个整数（可能重复）

**输出**：一行，逆序对的个数

**定义**：逆序对 = 满足 `i < j` 且 `a[i] > a[j]` 的数对 `(i, j)`

**数据范围**：`1 <= n <= 100000`，`|a[i]| <= 1e9`

**要求**：
- 用**分治**（把归并排序改一改），复杂度 `O(n log n)`
- **不许**双重循环（O(n²) 会超时）

> 💡 提示：合并两个有序数组时，如果右边拿出来的 `a[j]` 比左边剩下的 `a[i]` 小，
> 那么左边剩下的**全部**都比它大 → **一次性**加 `(mid - i)` 个逆序对。
> ⚠️ 相等不算逆序对（`a[i] > a[j]` 严格大于）。

**样例输入 1**
```
5
2 3 8 6 1
```
**样例输出 1**
```
5
```

**样例输入 2**（⭐ 完全逆序，答案 = n*(n-1)/2 = 6）
```
4
4 3 2 1
```
**样例输出 2**
```
6
```

**自测**：`n = 1`（0）、全部相等（0）、已经升序（0）、
`n = 100000` 随机数据计时（**应在 1 秒内**）。

### 综 1：FBI 树（真题1_FBI树.py）

**背景**：把 01 串对半分成左右两半，各自建树，根在两边之上，就得到一棵"FBI 树"。

**节点类型**：
- 全是 `0` → `B`
- 全是 `1` → `I`
- `0` 和 `1` 都有 → `F`

**输入**：
- 第一行一个整数 `n`
- 第二行一个长度为 `2^n` 的 01 串

**输出**：一行，FBI 树的**后序遍历**结果（先左子树 → 再右子树 → 最后根）

**数据范围**：`0 <= n <= 10`（串长最大 1024）

**要求**：用递归，`O(n·2^n)` 以内都行

> 💡 提示：`fbi(s)` 里先算 `left = fbi(s[:mid])`、`right = fbi(s[mid:])`，
> 返回 `left + right + 自己那一个字母`。
> ⚠️ 写成"自己 + 左 + 右"就是**前序**了，样例立刻对不上。
> 判断类型：`'0' in s` 和 `'1' in s` 都成立 → `F`。

**样例输入 1**
```
3
10001011
```
**样例输出 1**
```
IBFBBBFIBFIIIFF
```

**样例输入 2**（⭐ 只有一层，先手画树）
```
1
01
```
**样例输出 2**
```
BIF
```

**样例输入 3**（⭐ 边界：`n=0`，只有一个叶子）
```
0
1
```
**样例输出 3**
```
I
```

**自测**：串全 `0`（应输出一长串 `B`）、串全 `1`（全是 `I`）、`0` 和 `1` 交替。

### 综 2：数的划分（真题2_数的划分.py）

**题目**：把整数 `n` 分成 `k` 个**正整数**之和，有多少种分法？
**不计顺序** —— `1+1+5`、`1+5+1`、`5+1+1` 算**同一种**。

**输入**：一行两个整数 `n k`

**输出**：一行，方案数

**数据范围**：`1 <= k <= n <= 200`

**要求**：递归 + **记忆化**（答案可能很大，Python 整数不会溢出）

> 💡 提示（两种思路选一个）：
> ① **枚举式**：规定后一个数 ≥ 前一个数（不降序），`dfs(剩余, 还要分几份, 最小能取几)`；
> ② **递推式**：`f(n, k) = f(n-1, k-1) + f(n-k, k)`
>   - 第一种方案里**一定有个 1** → 拿掉这个 1，变成"`n-1` 分 `k-1` 份"
>   - 第二种方案里**每份都 ≥ 2** → 每份先减 1，变成"`n-k` 分 `k` 份"
>   - 出口：`k == 1` 或 `k == n` → 1 种；`k > n` → 0 种
> ⚠️ 不加记忆化，`n = 200` 时要跑很久。

**样例输入 1**（4 种：1+1+5 / 1+2+4 / 1+3+3 / 2+2+3）
```
7 3
```
**样例输出 1**
```
4
```

**样例输入 2**
```
20 6
```
**样例输出 2**
```
90
```

**样例输入 3**（⭐ 大数，答案 4132096）
```
200 6
```
**样例输出 3**
```
4132096
```

**自测**：`n = k`（1 种）、`k = 1`（1 种）、`n = 4 k = 4`（1）、
`n = 200 k = 100`（190569292）、`n = 7 k = 3` 手动把 4 种列出来对一遍。

### 综 3：最大子段和（真题3_最大子段和.py）

**题目**：给一个整数数组，求**连续子段**的最大和（至少选一个数）。

**输入**：
- 第一行一个整数 `n`
- 第二行 `n` 个整数

**输出**：一行，最大子段和

**数据范围**：`1 <= n <= 100000`，`|a[i]| <= 10000`

**要求**：用**分治**，复杂度 `O(n log n)`；不许 O(n²) 枚举左右端点

> 💡 提示：答案只有三种可能 ——
> ① 完全在左半边 → 递归
> ② 完全在右半边 → 递归
> ③ **跨过中点** → 从 `mid` 往左扫出"最大后缀" + 从 `mid` 往右扫出"最大前缀"，两者相加
> 答案 = `max(①, ②, ③)`。
> ⚠️ 全负数时不能把答案初始化成 0（正确答案是最大的那个负数）。
> 📌 这题以后用 DP（Kadane）O(n) 更简单，今天**故意**用分治练"跨界合并"。

**样例输入 1**（答案 = 11 + (-4) + 13 = 20）
```
6
-2 11 -4 13 -5 -2
```
**样例输出 1**
```
20
```

**样例输入 2**（⭐ 全负数，不能输出 0）
```
3
-1 -2 -3
```
**样例输出 2**
```
-1
```

**自测**：`n = 1`（`5` → `5`）、只有一个正数、正数在最左/最右、
`n = 100000` 随机数据计时（**应在 1 秒内**）。
