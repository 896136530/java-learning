# Python Day 1 知识点：输出、变量、输入（零基础入门）

> 蓝桥杯 Python 线 Day 1。本文件只讲知识点，练习题见《练习题和代码题目.md》，做完再看《标准答案.md》。
> 🤖 你有 C / Java 基础，很多概念会"似曾相识"——重点看**和 Java 不一样**的地方。

## 1. 第一个程序：print() 输出

```python
print("你好，世界")   # 输出：你好，世界
print(3 + 5)          # 输出：8（print 可以直接算）
```

- `print()` = Java 的 `System.out.println()`——把内容打印到屏幕
- 字符串用**引号**（单引号双引号都行：`'你好'` 和 `"你好"` 一样）
- 一行代码结尾**不用分号**（Java 要 `;`，Python 不要——千万别加！）

## 2. 变量：不需要声明类型（和 Java 最大区别！）

```python
name = "小明"      # 字符串，直接赋值，不用写 String
age = 18           # 整数，不用写 int
height = 1.75      # 小数，不用写 double
is_student = True  # 布尔，不用写 boolean
```

- **Java**：`String name = "小明";`（要写类型）
- **Python**：`name = "小明"`（什么都不用写，自动判断）
- 变量名规则和 Java 一样：字母/数字/下划线，数字不开头，小驼峰

## 3. 基本类型（会区分就行）

| 类型 | 例子 | 对应 Java |
|---|---|---|
| `int` 整数 | `18` | int |
| `float` 小数 | `3.14` | double |
| `str` 字符串 | `"你好"` | String |
| `bool` 布尔 | `True / False` | boolean |

⚠️ Python 的布尔是 `True` / `False`（**大写开头**！），不是 Java 的小写 `true`/`false`。

## 4. input() 输入（蓝桥杯第一大重点！）

```python
name = input()        # 从键盘读一行【字符串】，存进 name
print("你输入了：" + name)
```

**和 Java 最大的坑**：`input()` 读进来的**永远是字符串**！

```python
age = input()         # 输入 18
print(age + 1)        # ❌ 报错！"18"是字符串，不能和数字加
```

怎么解决？用**类型转换** `int()`：

```python
age = int(input())    # 先把读进来的字符串转成整数
print(age + 1)        # ✅ 输出 19
```

**转换函数**：
- `int("18")` → 18（字符串转整数）
- `float("3.14")` → 3.14（字符串转小数）

## 5. 一行读多个数（蓝桥杯必考姿势）

很多题会给："第一行两个整数 a b"，用 `split()` 切开：

```python
a, b = input().split()   # 输入 "3 5" → a="3", b="5"（还是字符串！）
a = int(a)               # 转整数
b = int(b)
```

更省事的写法（**记住这个**）：
```python
a, b = map(int, input().split())   # 一行搞定：读入 → 按空格切开 → 全部转 int
```

> `map(int, ...)` = "对切出来的每个片段都做 int() 转换"。现在照着用就行，原理后面讲。

## 6. 字符串拼接

```python
name = "小明"
print("你好，" + name)        # 用 + 拼接
print(f"你好，{name}")        # 更高级的 f-string（推荐！f 开头，{变量} 直接插）
# f-string 输出：你好，小明
```

> f-string 是 Python 特色大招：`f"..."` 里用 `{变量名}` 直接嵌入，比 `+` 拼接清爽多了。蓝桥杯写输出建议全程用 f-string。

## 7. 注释

```python
# 单行注释（井号开头，和 Java 的 // 一样）
print("hi")   # 行尾也能加注释
```

## 8. 常见坑（记住这 4 个就不亏）

1. **行尾加分号** → 不报错但难看，别学 Java 习惯
2. **input() 返回字符串**，要和数字运算必须 `int()` / `float()` 转
3. **布尔是 `True/False`** 大写开头，不是 `true/false`
4. **缩进决定代码块**（Python 没有大括号！）：同一级的代码必须对齐，后面学 if/for 时这是最关键的

## 9. Python vs Java 速查（今天够用）

| 操作 | Java | Python |
|---|---|---|
| 输出 | `System.out.println("hi")` | `print("hi")` |
| 声明变量 | `int x = 5;` | `x = 5` |
| 读到字符串 | `Scanner` 一堆代码 | `input()` |
| 字符串转数字 | `Integer.parseInt(s)` | `int(s)` |
| 行尾分号 | 必须 | 不需要 |
