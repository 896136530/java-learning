## 题 4 答案（两个数求和）

```python
a = input()     # 读第一行
b = input()     # 读第二行
a = int(a)      # 转整数！
b = int(b)

print(f"两数之和：{a + b}")
```

> 不加 `int()` 会怎样？`a + b` 变成字符串拼接："3"+"5" = "35"——这就是类型转换的坑。

## 题 5 答案（一行读两个数）

```python
a, b = map(int, input().split())
print(f"两数之和：{a + b}")
```

## 🎯 复习答案（小超市结账）

```python
a, b = map(int, input().split())   # 读两个商品价格
pay = int(input())                 # 读你付的钱（单行输入）

total = a + b                      # 总价
change = pay - total               # 找零
print(f"应找零：{change}元")
```
