## 题目详情

### 题 1：第一次 print（热身）
用 `print()` 输出三行：
```
你好，我是XX（你的名字）
我在学Python，准备蓝桥杯
今天是第1天，加油！
```
（用三条 print，每行一条）

### 题 2：变量（不需要写类型）
- 变量 `name` = 你的名字
- 变量 `age` = 你的年龄
- 变量 `money` = 100.5
- 用 f-string 打印：`我叫XX，今年XX岁，我有100.5元`
- 期望输出（示例）：`我叫小张，今年19岁，我有100.5元`

### 题 3：input() 输入（读字符串）
- 用 `input()` 读入你的名字
- 用 f-string 打印：`你好，XX！欢迎来到Python世界`
- 测试：输入 小张 → 输出 `你好，小张！欢迎来到Python世界`

### 题 4：两个数求和 ⚠️（类型转换重点）
- 用 `input()` 读两个整数（分行输入：先输入第一个数回车，再输入第二个数）
- 计算它们的和
- 打印：`两数之和：XX`
- 测试：输入 3 回车 5 → 输出 `两数之和：8`
- 💡提示：不加 `int()` 直接 `a + b` 会怎样？（试试看！）

### 题 5：一行读两个数 ✅（蓝桥杯核心姿势）
- 用 `input().split()` + `map(int, ...)` 一行读两个整数（同一行输入："7 9"）
- 打印它们的和
- 测试：输入 `7 9` → 输出 `两数之和：16`

### 🎯 复习：小超市结账（综合）
题目背景（蓝桥杯风格的"输入输出"题）：
> 买了两件商品，第一件价格 a 元，第二件价格 b 元，共需付多少钱？
- 第一行输入：两个整数 a 和 b（用题 5 的姿势读）
- 第二行输入：你付的钱 pay（整数）
- 输出：应找零多少钱
- 测试：输入 `12 8` 回车 `30` → 输出 `应找零：10元`
- 💡思路：`总价 = a + b`，`找零 = pay - 总价`
