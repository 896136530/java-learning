## 二、阶段① Python 基础（2026-09，4 周）

> 你已有 Java 基础，语法 4 周足够；正好和下学期学校的 Python 课互相印证，课内跟学、课外按竞赛向补强。

| 周 | 内容 | 过关题目（能独立写出）|

## 三、阶段② 数据结构 + 基础算法（2026-10 → 2027-01，约 16 周）

> 核心思路：**每章 = ①看教材思想 → ②用 Python 实现核心结构 → ③刷对应蓝桥真题 ≥2 道**
> 严蔚敏《数据结构（C 语言版·第 2 版）》章节号以你手上的版本为准，下表按主题对齐。

| 周 | 教材章节（主题）| Python 落地 | 蓝桥常见考法 |
|---|---|---|---|
| W5~6 | 第 2 章 线性表（顺序表/链表）| `list`、`collections.deque` | 模拟题、约瑟夫环 |
| W7~8 | 第 4 章 串（子串/KMP）| `str` 方法（find/count/replace）| **字符串处理（蓝桥高频！）** |
| W9~10 | 第 5 章 数组和广义表（矩阵）| 嵌套 `list` | 矩阵旋转/转置、蛇形填数、坐标模拟 |
| W11~12 | 第 6 章 树和二叉树（遍历）| 字典存树 + 递归 | 树的遍历、二叉树计数 |
| W13~14 | 第 7 章 图（邻接表/DFS/BFS/最短路）| `dict` 邻接表、`heapq` | 迷宫、连通块、Dijkstra 最短路 |
| W15 | 查找（二分/哈希）| `bisect`、`dict` | 二分答案、哈希计数（天天用）|
| W16 | 排序（思想/稳定性）| `sorted()` + `key=` | 自定义排序（多关键字）|
| W17~18（寒假）| **补充：动态规划（教材外必补）** + 并查集 | 二维 `list`、DP 模板 | **背包、最长上升子序列——蓝桥必考** |

**🎯 验收（寒假结束 01 月底）**：教材表中每个主题都能不看答案写出 Python 版核心结构；每主题蓝桥真题 ≥2 道 AC。
