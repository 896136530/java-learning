## 题 2 答案（最大值 + 平均值）
```java
int max = arr[0];
int sum = 0;
for (int i = 0; i < arr.length; i++) {
    if (arr[i] > max) max = arr[i];
    sum += arr[i];
}
double avg = (double) sum / arr.length;   // 注意转成 double，不然整数除法
System.out.println("最大值：" + max);
System.out.println("平均值：" + avg);
```

## 题 3 答案（原地反转）
```java
for (int i = 0; i < arr.length / 2; i++) {
    int tmp = arr[i];
    arr[i] = arr[arr.length - 1 - i];
    arr[arr.length - 1 - i] = tmp;
}
// 打印：6 5 4 3 2 1
```

## 题 4 答案（猜数字游戏）
```java
System.out.println("猜一个 1~100 的数字，你只有 10 次机会！");
for (int i = 1; i <= 10; i++) {
    System.out.print("第 " + i + " 次猜：");
    int guess = sc.nextInt();
    if (guess == target) {
        System.out.println("🎉 恭喜！第 " + i + " 次就猜中了！答案就是 " + target);
        return;                      // 猜中直接结束整个 main
    } else if (guess > target) {
        System.out.println("大了，再试试");
    } else {
        System.out.println("小了，再试试");
    }
}
System.out.println("机会用完了，正确答案是：" + target);
```

## 题 5 答案（成绩统计）
```java
int[] scores = new int[5];
int pass = 0;
for (int i = 0; i < 5; i++) {
    System.out.print("请输入第 " + (i + 1) + " 个成绩：");
    scores[i] = sc.nextInt();
    if (scores[i] >= 60) pass++;
}
System.out.println("及格人数：" + pass + "，不及格人数：" + (5 - pass));
```
