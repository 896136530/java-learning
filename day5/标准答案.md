## 题 2 答案（Rectangle 长方形类）
```java
class Rectangle {
    double width;
    double height;

    double area() {
        return width * height;
    }

    double perimeter() {
        return (width + height) * 2;
    }
}
```

## 题 3 答案（Dog 狗类 + 构造方法）
```java
class Dog {
    String name;
    int age;

    Dog(String name, int age) {
        this.name = name;   // 这里参数和属性不同名，不写 this 也行
        this.age = age;
    }

    void bark() {
        System.out.println(name + "：汪汪！");
    }
}
```

## 题 4 答案（构造方法 + this）
```java
class Phone {
    String brand;
    double price;

    Phone(String brand, double price) {
        this.brand = brand;   // 同名必须用 this，不然属性赋值失败
        this.price = price;
    }

    void showInfo() {
        System.out.println("品牌：" + brand + "，价格：" + price + "元");
    }
}
```
（参数名和属性名一样，没有 this 的话 `brand = brand` 是把参数赋给参数自己，属性永远是 null/0——这就是为什么必须 this）

## 题 5 答案（BankAccount 银行账户）
```java
class BankAccount {
    double balance;

    BankAccount(double balance) {
        this.balance = balance;
    }

    void deposit(double money) {
        balance += money;
    }

    void withdraw(double money) {
        if (balance < money) {
            System.out.println("余额不足");
        } else {
            balance -= money;
        }
    }

    double getBalance() {
        return balance;
    }
}
```
（main 里：`acc.deposit(500)`、`acc.withdraw(200)` 后打印 → 余额 1300.0）
