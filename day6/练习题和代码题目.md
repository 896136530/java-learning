## 题目详情

### 题 1：Student 类封装（入门）
定义一个 `Student` 类：
- **私有属性**：`private String name`、`private int age`
- getter：`getName()`、`getAge()`
- setter：`setName(String name)`、`setAge(int age)`（要用 `this` 区分同名的参数和属性）
- 方法：`printInfo()`，打印 `我叫XX，今年XX岁`
- 在 `main` 里：`new Student()` 后**用 setter 赋值**，再**用 getter 打印**，最后调用 `printInfo()`
- 期望输出：`名字：小明` `年龄：18` `我叫小明，今年18岁`

### 题 2：Person 类 + 年龄校验（封装的价值）
定义一个 `Person` 类：
- **私有属性**：`private String name`、`private int age`
- `setAge(int age)`：如果 `age < 0` 或 `age > 150`，打印"年龄不合法：XX"并**拒绝修改**（保留原值）；否则正常赋值
- getter：`getAge()`
- 在 `main` 里：先 `setAge(20)`，再 `setAge(-5)`，再 `setAge(999)`，最后打印 `getAge()`
- 期望输出：
  ```
  年龄不合法：-5
  年龄不合法：999
  年龄：20
  ```

### 题 3：BankAccount 封装版（Day5 的升级！）
把 Day5 的银行账户改造成封装版：
- **私有属性**：`private double balance`
- 构造方法：`BankAccount(double balance)` 设置初始余额
- `deposit(double money)`：存款
  - 如果 `money < 0`，打印"存款金额不能为负"并返回
  - 否则 `balance += money`
- `withdraw(double money)`：取款
  - 如果 `money < 0`，打印"取款金额不能为负"
  - 否则如果 `balance < money`，打印"余额不足"
  - 否则 `balance -= money`
- `getBalance()`：返回余额
- 在 `main` 里：开户 1000 → 存 500 → 取 200 → 存 -1 → 取 99999 → 打印余额
- 期望输出：
  ```
  存款金额不能为负
  余额不足
  余额：1300.0
  ```

### 题 4：Book 只读类（只读属性的意义）
定义一个 `Book` 类：
- **私有属性**：`private String title`、`private String author`
- **构造方法**：`Book(String title, String author)` 创建时就定死书名和作者
- **只提供 getter**：`getTitle()`、`getAuthor()`（**不写 setter**）
- 在 `main` 里：`new Book("三体", "刘慈欣")`，用 getter 打印
- 期望输出：
  ```
  书名：三体
  作者：刘慈欣
  ```
- 💡思考：为什么不写 setter？（提示：有些数据创建后不该被改——想想书出版之后书名还能随便改吗？）

### 题 5：Employee 员工类（综合封装）
定义一个 `Employee` 类：
- **私有属性**：`private int id`、`private String name`、`private double salary`
- **构造方法**：`Employee(int id, String name, double salary)`
- getter：`getId()`、`getName()`、`getSalary()`
- `setSalary(double salary)`：如果 `salary < 0`，打印"薪资不合法：XX"并拒绝；否则赋值
- `raise(double amount)`：加薪
  - 如果 `amount <= 0`，打印"加薪金额不合法：XX"
  - 否则 `salary += amount`
- 在 `main` 里：创建员工（id=1, name=张三, salary=8000）→ `setSalary(-100)` → `raise(500)` → `setSalary(9000)` → 打印
- 流程推演：`setSalary(-100)` 被拒绝（还是 8000）→ `raise(500)` 变 8500 → `setSalary(9000)` 合法，改成 9000
- 期望输出：
  ```
  薪资不合法：-100.0
  员工：1  张三  9000.0
  ```
