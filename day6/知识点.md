# Day 6 知识点：封装（面向对象三大特征之一）

> 本文件只讲知识点，练习题见《练习题和代码题目.md》，做完再看《标准答案.md》。

## 1. 回顾：Day 5 你写代码的方式

Day 5 里创建对象后，我们是**直接在 main 里改属性**：

```java
Student s = new Student();
s.name = "小明";   // ← 外部直接改属性
s.age = 18;
```

这种方式叫"属性裸奔"——属性是 `public`（默认公开），**谁都能随手改**，而且改的时候**没有任何检查**。

## 2. 为什么需要封装

假设年龄属性被随便改成了 `-5` 或 `200` 岁，程序照样跑——这不合理。
真实世界的对象都有"规矩"：户口本不能自己改年龄，得去派出所走流程。
程序里也一样，**属性应该被"保护"起来，只通过专门的方法来读写**，这就是封装。

**封装（Encapsulation）= 把属性藏起来（private）+ 提供公开方法（getter/setter）去读写，方法里可以加校验。**

## 3. 第一步：属性用 private 藏起来

```java
class Student {
    private String name;   // private = 只有本类内部能访问
    private int age;       // 外部（main）不能直接 s.age = 18 了！
}
```

> 加上 `private` 后，你在 main 里写 `s.age = 18` 会**编译报错**——这正是封装的第一道墙：**不给你直改的机会**。

## 4. 第二步：提供 getter / setter

既然外部不能直接碰属性，就提供公开的"小门"来读写：

```java
class Student {
    private String name;
    private int age;

    // getter：读属性（获取）
    public String getName() {
        return name;
    }
    public int getAge() {
        return age;
    }

    // setter：写属性（设置）
    public void setName(String name) {
        this.name = name;   // this 区分"参数 name"和"属性 name"
    }
    public void setAge(int age) {
        this.age = age;
    }
}
```

**命名规则（背下来）**：
- 读（getter）：`get` + 属性名首字母大写 → `getName()`
- 写（setter）：`set` + 属性名首字母大写 → `setAge()`
- `boolean` 类型的 getter 特殊写法：`is` + 属性名（如 `isVip()`，后面学到再展开）

## 5. setter 里加校验（封装的最大价值）

setter 是唯一入口，所以**检查逻辑就放在这里**：

```java
public void setAge(int age) {
    if (age < 0 || age > 150) {
        System.out.println("年龄不合法：" + age);
        return;            // 不合法就拒绝修改，直接退出
    }
    this.age = age;        // 合法才真的赋值
}
```

这样就算外面有人传 `setAge(-5)`，也改不了——**属性永远处于合理状态**。

## 6. 那构造方法呢？也要 this

构造方法里给属性赋初值，同样用 this：

```java
Student(String name, int age) {
    this.name = name;
    this.age = age;
}
```

「构造方法 + getter/setter」就成了一个标准的封装类样板：

```java
class Student {
    private String name;
    private int age;

    Student(String name, int age) {   // 构造方法：创建时填初值
        this.name = name;
        this.age = age;
    }

    public String getName() { return name; }
    public int getAge() { return age; }
    public void setName(String name) { this.name = name; }
    public void setAge(int age) { this.age = age; }

    void printInfo() {
        System.out.println("我叫" + name + "，今年" + age + "岁");
    }
}
```

## 7. 封装有什么好处（面试常问）

1. **安全**：属性不会被改成非法值（负年龄、负余额……）
2. **可控**：所有修改都过 setter 这一道门，想加规则只改一个地方
3. **隐藏细节**：外面只看到"方法"，看不到内部是怎么存的，后面想改内部实现不影响调用者
4. **后面会更强**：继承、多态、重载都是建立在封装的基础上

## 8. 常见坑（记住）

1. 忘了写 `private` → 属性还是公开的，封装没做
2. 只写 getter 不写 setter → 属性"只读"（创建后不能改）——**这是故意的，有时候正是你要的**
3. setter 里 `name = name` → 自己给自己赋值，属性没变（必须 `this.name = name`）
4. getter 忘了 `return` / 返回类型写错 → 编译报错
5. 别在 getter 里加乱七八糟的副作用，getter 就是"单纯地读"，最好净读
