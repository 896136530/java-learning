## 三、对原路径 10 个疑问的逐条回答

### 1. "一天一个知识点"是不是太慢？
**不是慢，是模式错位。** 3 个月到 Day32（SpringBoot 起步 + MySQL + 事务 + 连接池）已经是同龄人前 20% 的速度。
真正的风险是：Day1~32 只是总工作量的约 1/4，按 3.5 天/Day 线性推下去确实来不及。
**结论：2027 年起主模式从"逐日知识点"切到"项目驱动 + 专题穿插"**，Day 粒度只留给纯新知识点（Redis、JVM）。

> ⚠️ **本仓库修正**：审阅方按 **3.5 天/Day** 估的速。用户 2026-10-14 明确说「**我正常两天可以写一个**」——
> 那 11 天里**有几天没动笔**。所以前半段（Day33~45）实际会提前，见 `学习路线.md` 第八节。

### 2. MyBatis 和 JPA 都学，浪费时间？
**不浪费，主次已经对了。** MyBatis/MyBatis-Plus 是国内 JD 绝对主力，目标池（银行/政务/国企存量系统）更是；
JPA 会用 + 能说清与 MyBatis 的差异即可。
⚠️ **唯一注意：别给 JPA 补深度**（懒加载/N+1 的面试出现率远低于 MyBatis 的动态 SQL / resultMap）。

### 3. Redis / Linux / Docker / RabbitMQ 全堆暑假太晚？
**是，这是全计划最大的崩点。** 必改：**Redis 基础提前到大二下；MQ 降级；JVM+并发挪大三上。**

### 4. 鉴权倒挂补正对不对？还有别的倒挂吗？
**改得对，而且必须。** 同类倒挂还有**三处**：
- **HTTP 基础**（鉴权建立在 HTTP 上，Day44 前必须补）
- **单元测试**（项目"写完后再补测试"比"边写边测"痛苦 3 倍）
- **Git 协作**（实习第一天就要用，寒假项目必须全程 Git）

### 5. 数据结构只跟学校课够不够？
**对就业够用** —— 面试算法考的是 LeetCode，不是数据结构课。学校课（C 版）管考试和概念，
**每周 2~3 道 LeetCode + 蓝桥杯 Python 线才是面试算法主力**。
⚠️ **唯一注意**：LeetCode 要**按专题**刷（数组/链表/树/哈希/DP/图），别乱刷；蓝桥杯季可暂停。

### 6. 第一个项目寒假才做，太晚？
**偏晚，而且比想象中更急**：**2027 年 3~5 月（大二下）就是暑期实习招聘季**，简历上"无项目"会错过第一波机会。
两个补救：
1. **现在~12 月**用碎片时间把已有"命令行记账本"的 Step3 持久化升级成 **Web 版 mini 项目**；
2. 寒假项目定位"**能过简历筛**"即可，不用追求完美。

**更重要：大二暑假（2027-07~08）应该投日常实习，不要全押自学** —— 2026 年行情里实习经历是"最硬的通货"，
一段垂直实习比名校背景更管用。

### 7. 大创和蓝桥杯省赛撞车，会不会两头不落地？
**会，但可以错峰 + 降级。** 大创申报（3 月）和蓝桥杯省赛（4 月中下旬）有空档；
关键是让大创**直接基于项目 1 改写申报书**，3 月中旬前集中 1~2 周写完。
**"2028 冲省一"这条建议删掉** —— 大三下 2~4 月是暑期实习投递+面试高峰，蓝桥杯的边际价值远低于一段暑期实习。
它就是"锦上添花"，不是"雪中送炭"。

### 8. 微服务排大三，对应届生有用吗？
**对这套目标池基本没用，砍。**
真实行情：银行/金融科技岗 JD 写的是 **Spring 生态 + 数据库 + Linux + 消息中间件**，没有一家要求应届生会 SpringCloud。
微服务的校招价值只在互联网大厂，而目标是存量系统为主。
**留 1~2 天看架构图、能说出 Nacos / Gateway / Feign / Sentinel 各是干嘛的即可，不写进简历。** 省下的时间给计网/OS 和项目打磨。

### 9. "不考研"有没有隐藏风险？
**有，可控，但要做两个动作**：
1. **学历筛选是真实存在的** —— 部分后端岗直接写"硕士学历"；好消息是很多银行/金融科技岗**本科可投**
   （兴业银行、宁波银行总行金融科技均明确本科起）。
   结论：**城商行 / 省分行 / 国企子公司 / 民营是主战场**，别把"银行"当铁板一块，也别预设大行总行。
2. **留 Plan B**：秋招（2028-09~11）→ 春招（2029-03~05）→ 国考（2028-11）/ 省考（2029-03）都在毕业前，
   **报名成本极低**，写进日程表，不是心理安慰。

### 10. 每天 2 小时到底够不够？
按"工作日 2h + 周末半天 ≈ **14h/周**"，到 2027-09 投日常实习有约 **11 个月 ≈ 600h**，
够完成"阶段三 + 项目 1 + Redis 基础"—— **前提是砍掉过重内容**。
三个杠杆：
1. **周末从"半天"提到"一天"**（多 30% 时间）
2. **寒暑假全勤** —— 寒假 ≈150h 够项目 1，暑假 ≈450h 是全年最大翻盘点，**绝不能用"周末半天"节奏安排假期**
3. **学校课"保过不保优"**（实验报告及格 + 不挂科，省下时间给主线）

> **真正的危险不是每天 2 小时，是把暑假当普通周来过。**

## 四、一句话总结（原文）

> **整体评价：基本合理偏乐观** —— 方向和选型（MyBatis 为主、砍微服务、双线并行）都是对的，
> **乐观在"排量"上**：暑假任务量不现实、Spring 原理 / HTTP / 测试 / AI 工具四个关键缺口没排、实习窗口被延后。
> 按上面的重排执行，你在 2027-09 投第一份日常实习时，是"**1 个项目 + Redis 基础 + Spring 原理 + 面试八股**"的状态，
> 对目标池完全够格。

**⚠️ 时代性提醒（原文保留）**：
2026-2027 年校招最明显的变化是 **AI 能力已进入 JD 和面试筛选** —— "AI 辅助编程经验优先""了解大模型者优先"已成为常态写法，
纯 CRUD 工程师岗位在大幅收缩。建议把"用 AI 维护学习计划"这件事**变成简历上能写的一项技能**
（如"熟练使用 AI 辅助编码 + 代码审查"），**并在项目里真实使用** —— 这比多背两个八股更有区分度。
