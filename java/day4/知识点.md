# Day 4 知识点：方法（Method）

> 本文件只讲知识点，练习题见《练习题和代码题目.md》，做完再看《标准答案.md》。

## 1. 方法是什么
前面所有代码都堆在 `main` 里。程序一长，`main` 就乱成一团。
**方法 = 一段有名字、能重复调用的代码块**。把重复逻辑抽出来，起个名字，用的时候"喊"它一声就行：

```java
public class Demo {
    public static void main(String[] args) {
        sayHello();   // 调用方法
        sayHello();   // 再调用一次
    }

    // 定义方法
    public static void sayHello() {
        System.out.println("你好！");
    }
}
```

## 2. 方法的定义格式（背下来）
```
修饰符 返回值类型 方法名(参数列表) {
    方法体
    return 返回值;   // 只有返回值类型不是 void 时才需要
}
```

拆开看：
- `public static`：先照着写，Day 5 学"类与对象"时再讲 `static` 是什么意思
- **返回值类型**：这个方法"交回去"什么类型的数据；不交回就写 `void`
- **方法名**：小驼峰、动词开头（`sayHello`、`getMax`、`isEven`）
- **参数列表**：调用时传进来的数据（可以没有，写空括号 `()`）

## 3. 参数与返回值
```java
// 有参数、有返回值：求两数之和
public static int add(int a, int b) {
    return a + b;      // return 把结果"交回去"，并结束方法
}

// 调用
int result = add(3, 5);   // result = 8
```

- **形参**：定义时括号里的变量（`a`, `b`）
- **实参**：调用时传进去的具体值（`3`, `5`）

## 4. return 的两件事
1. **返回结果**（仅当返回值类型不是 `void`）
2. **立即结束方法**（后面的代码不再执行）

```java
public static boolean isEven(int n) {
    if (n % 2 == 0) return true;
    return false;          // 只有上面没 return 才会走到这
}
```

## 5. 方法重载（overload）
**同一个类里，方法名相同、参数列表不同**（个数或类型不同），就叫重载：

```java
public static int add(int a, int b)       { return a + b; }
public static double add(double a, double b) { return a + b; }
public static int add(int a, int b, int c)   { return a + b + c; }
```

⚠️ 重载**只看参数列表**，跟返回值类型、参数名都无关。

## 6. 值传递（重点，全是坑）
- **基本类型**：传的是"值"的**副本**，方法里改参数，**不影响**外面的变量
```java
public static void change(int x) { x = 999; }

int a = 10;
change(a);
System.out.println(a);   // 还是 10，不是 999！
```

- **数组（引用类型）**：传的是"地址"，方法里改元素，**外面也会变**
```java
public static void change(int[] arr) { arr[0] = 999; }

int[] a = {10, 20};
change(a);
System.out.println(a[0]);   // 变成 999！
```

一句话记：**基本类型传值（改了白改），数组传地址（改了真改）**。

## 7. 常见坑（记住）
1. 返回值类型不是 `void` 却忘了写 `return` → 编译报错
2. `return` 的类型和方法声明的返回值类型**不一致** → 报错（如 int 方法 return 一个小数）
3. `void` 方法里写 `return 值;` → 报错；`void` 只能写光杆 `return;` 或不写
4. 想靠"只改返回值类型"来重载 → 不行，会报错（重载只看参数列表）
5. 基本类型参数在方法里改了，外面不变（和直觉相反，重点记）
6. **方法不能定义在方法里面**（方法体里不能再套一个方法定义）
