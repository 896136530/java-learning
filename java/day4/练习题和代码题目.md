## 题目详情

### 题 1：两数之和
定义方法 `add(int a, int b)`，返回 `a + b`。在 `main` 里调用并打印 `3 + 5 = 8`。

### 题 2：数组最大值
定义方法 `getMax(int[] arr)`，返回数组里的最大值。
提示：`int max = arr[0];` 然后循环比较（Day 3 学过）。

### 题 3：判断质数
定义方法 `isPrime(int n)`，是质数返回 `true`，否则返回 `false`。
在 `main` 里遍历 2~20，把质数都打印出来，期望输出：`2 3 5 7 11 13 17 19`。
提示：`n < 2` 直接返回 `false`；从 2 到 `n/2` 逐个试除。

### 题 4：方法重载
定义三个**同名**方法 `area`，分别算正方形、长方形、圆的面积：
- `area(int side)`：正方形，`side * side`
- `area(int w, int h)`：长方形，`w * h`
- `area(double r)`：圆，`3.14 * r * r`

### 题 5：值传递实验
定义两个方法：`changeNum(int x)`（把 `x` 改成 999）和 `changeArr(int[] arr)`（把 `arr[0]` 改成 999）。
在 `main` 里分别调用，观察 `num` 和 `arr[0]` 的变化，想清楚为什么一个变一个不变。
