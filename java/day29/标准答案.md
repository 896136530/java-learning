## 题 3 答案（`ex3/ConfigLoader.java`）⭐

```java
static String loadFromClasspath(String name) {
    return Hold.readResource(name);
}

static int countLines(String content) {
    int n = 0;
    for (String line : content.split("\n")) {
        String s = line.strip();
        if (!s.isEmpty() && !s.startsWith("#")) {
            n++;
        }
    }
    return n;
}
```

**真机输出**（15 行，`db.properties` 未加 timeout 时）：

```
===== 配置文件在 jar 里，还是磁盘上？=====
--- 用【类路径】读（正确姿势）---
读到 4 行有效内容，内容：
  db.url=jdbc:mysql://127.0.0.1:3306/day29
  db.user=root
  db.password=root
  db.pool.size=5
★ 结论：类路径读法在 IDE 里和 jar 里都能用。
--- 用【磁盘路径】读（错误姿势）---
当前工作目录：...\java\day29
src/main/resources/db.properties 存在吗：true（IDE 里侥幸能读到）
⚠️ 打包成 jar 之后，这条路径就不存在了 —— 这就是"能跑不能发货"的典型病。
===== 一句话总结 =====
跟着代码走的文件（配置/模板）→ 放 resources、用类路径读
用户数据文件（账本.txt/导出.csv）→ 用磁盘路径读
```

**判分要点**：
- 有效行数 = **4**（3 行 `#` 注释不算）；用户按题目加了 `db.timeout=3000` 后应为 **5**。
- ⚠️ **`src/main/resources/... 存在吗` 的 true/false 取决于工作目录**：
  - 在 `java/day29` 下跑（`运行Maven.bat`）→ `true`
  - `java -jar` 或别的目录下跑 → **`false`**
  - **两种都算对**，因为这一行的教学目的就是让人看到"磁盘路径不可靠"。判分时看学生有没有理解，不要卡 true/false。
- ⚠️ 如果用户把 `db.properties` 放进了 `src/main/java/`，`Hold.readResource` 会抛
  `IllegalArgumentException：类路径里找不到` —— 这是**真实错误**，要指出来（resources 目录不能改）。

## 题 5 答案（`ex5/BookDao.java`）⭐

```java
public static int insert(Connection conn, Book b) throws SQLException {
    try (PreparedStatement ps = conn.prepareStatement(
            "INSERT INTO book (title, author, price, stock) VALUES (?, ?, ?, ?)")) {
        ps.setString(1, b.title);
        ps.setString(2, b.author);
        ps.setDouble(3, b.price);
        ps.setInt(4, b.stock);
        return ps.executeUpdate();
    }
}

public static int count(Connection conn) throws SQLException {
    try (Statement st = conn.createStatement();
         ResultSet rs = st.executeQuery("SELECT COUNT(*) FROM book")) {
        rs.next();
        return rs.getInt(1);
    }
}

public static List<Book> findByAuthor(Connection conn, String author) throws SQLException {
    List<Book> list = new ArrayList<>();
    try (PreparedStatement ps = conn.prepareStatement(
            "SELECT id, title, author, price, stock FROM book WHERE author = ? ORDER BY id")) {
        ps.setString(1, author);
        try (ResultSet rs = ps.executeQuery()) {
            while (rs.next()) {
                list.add(mapRow(rs));
            }
        }
    }
    return list;
}

public static double totalValue(Connection conn) throws SQLException {
    try (Statement st = conn.createStatement();
         ResultSet rs = st.executeQuery("SELECT SUM(price * stock) FROM book")) {
        rs.next();
        return rs.getDouble(1);      // 表为空时 SUM 返回 NULL → getDouble 给 0.0（正好）
    }
}

public static List<Book> findAll(Connection conn) throws SQLException {
    List<Book> list = new ArrayList<>();
    try (Statement st = conn.createStatement();
         ResultSet rs = st.executeQuery("SELECT id, title, author, price, stock FROM book ORDER BY id")) {
        while (rs.next()) {
            list.add(mapRow(rs));
        }
    }
    return list;
}
```

## 环境类必查项（批改前的 checklist）

1. **MySQL 必须先起来**：`E:\mysql\bin\mysqld.exe --defaults-file=E:\mysql\my.ini`（`运行Maven.bat` 会自动起，等 10 秒）。
   没起来 → 全套报 `Communications link failure / Connection refused`（**不是学生的错**）。
2. **Maven 路径**：`C:\Users\89613\.vscode\extensions\oracle.oracle-java-26.0.1\nbcode\java\maven\bin\mvn.cmd`
   （扩展版本号变了就要改 `运行Maven.bat` 第 4 行）。
3. **`target/` 必须已加进 .gitignore**（本次已加）——否则会提交一堆编译产物。
4. **中文输出捕获**（批改踩坑）：Maven 写控制台是 GBK，直接重定向会得到乱码/被判成二进制文件。
   可靠办法：用 `[System.Diagnostics.ProcessStartInfo]` 配 `StandardOutputEncoding = UTF8`，
   或直接 `java -Dstdout.encoding=UTF-8` 配 cmd 重定向；**别用 pwsh 管道接 Maven 输出**。
   ⚠️ 本机 pwsh 里 `ProcessStartInfo.ArgumentList` 不可用（要用 `Arguments` 字符串）。
