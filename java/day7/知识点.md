# Day 7 知识点：继承（面向对象三大特征之二）

> 本文件只讲知识点，练习题见《练习题和代码题目.md》，做完再看《标准答案.md》。

## 1. 回顾：封装之后还要解决什么问题

Day 6 学会了把属性藏起来（private）。现在新问题来了：
假设你要写"学生类"和"老师类"，发现它们**很多属性方法一模一样**（name、age、介绍自己）……

```java
class Student {
    private String name;
    private int age;
    public void sayHello() { System.out.println("我叫" + name); }
}

class Teacher {
    private String name;
    private int age;
    public void sayHello() { System.out.println("我叫" + name); }
}
```

**代码复制粘贴两遍**——这就是糟糕设计：改一处要改两处，还容易漏。怎么办？**把公共的部分抽到"父类"，让子类继承**。

## 2. 继承是什么

**继承（extends）= 子类"白拿"父类的东西**：父类有的属性和方法，子类自动就有。

```java
// 父类：人和动物的共同特征
class Person {
    String name;
    int age;

    void sayHello() {
        System.out.println("我叫" + name);
    }
}

// 子类：继承 Person，自动拥有 name/age/sayHello
class Student extends Person {
    int studentId;      // 子类自己的新属性

    void study() {      // 子类自己的新方法
        System.out.println(name + "在学习");
    }
}
```

```java
Student s = new Student();
s.name = "小明";       // 名字是父类给的 ✅
s.age = 18;            // 年龄是父类给的 ✅
s.sayHello();          // 方法是父类给的 ✅
s.study();             // 这是子类自己的 ✅
```

**记法**：`class 子类 extends 父类`（子 extends 父 = 儿子继承老爸）

## 3. 继承的术语（背下来）

| 术语 | 例子 | 说明 |
|---|---|---|
| 父类 / 超类 /基类 | `Person` | 被继承的那个 |
| 子类 / 派生类 | `Student` | 继承别人的那个 |
| **单继承** | Java 一个类**只能 extends 一个父类** | 不能 `class A extends B, C`（多继承不允许，后面接口可以）|

> ⚠️ Java 所有类都直接或间接继承 `Object`（以后学到）。

## 4. 子类能用父类哪些东西？

| 权限 | 子类能用？ | 举例 |
|---|---|---|
| `public` | ✅ 能 | 公开方法 |
| `protected` | ✅ 能（重点，专门给继承用的）| 见下节 |
| 默认（不写）| ✅ 同包能 | 同一个包内可以 |
| `private` | ❌ **不能直接访问** | 父类的私有属性能"用"（通过父类方法），但不能直接 `super.name` 碰 |

**private 的东西子类碰不到，但可以通过父类的 public 方法间接用**（这就是封装+继承的配合）。

## 5. protected：专门给继承用的权限

```java
class Person {
    protected String name;   // protected：子类可以直接访问
}

class Student extends Person {
    void test() {
        System.out.println(name);  // ✅ protected 子类能直接用
    }
}
```

> 记忆：`public` 谁都能用 > `protected` 子类+同包能用 > 默认同包能用 > `private` 只有自己能用。

## 6. super：找"爸爸"的关键字

`super` = 父类的引用，两个主要用途：

### 用途 1：调用父类的构造方法（最常见！）

```java
class Person {
    String name;

    Person(String name) {
        this.name = name;
    }
}

class Student extends Person {
    int studentId;

    Student(String name, int studentId) {
        super(name);          // ← 调用父类构造方法，把 name 交给父类处理
        this.studentId = studentId;
    }
}
```

**规则**：子类构造方法**第一行**必须调用父类构造方法：
- 写了 `super(参数)` → 调父类那个构造方法
- 没写 → Java 自动调父类的**无参构造** `super()`，但父类如果没有无参构造 → **编译报错**！

### 用途 2：调用父类的普通方法

```java
class Student extends Person {
    void sayHello() {
        super.sayHello();          // 先执行父类原来的逻辑
        System.out.println("我还是一名学生");
    }
}
```

## 7. 方法重写（Override）—— 继承的灵魂

**重写 = 子类把父类的方法"换一个实现"**，方法名、参数列表、返回值全一样，只是内容不同。

```java
class Person {
    void introduce() {
        System.out.println("我是人");
    }
}

class Student extends Person {
    @Override                      // 注解：告诉编译器"我要重写"
    void introduce() {
        System.out.println("我是学生");   // 换成了自己的实现
    }
}
```

**重写 vs 重载（Day 4 学的）对比——高频面试题！**

| | 重写 Override | 重载 Overload |
|---|---|---|
| 发生位置 | **父类子类之间** | **同一个类里** |
| 方法名 | 必须相同 | 必须相同 |
| 参数列表 | 必须**相同** | 必须**不同** |
| 目的 | 改变父类行为 | 同一方法处理不同类型 |

## 8. 常见坑（记住）

1. `extends` 拼错 → 编译报错；Java 一个类只能继承一个父类
2. 父类没有无参构造 + 子类构造方法第一行没写 `super(参数)` → 编译报错
3. `super` 必须在构造方法**第一行**（和 `this()` 不能同时用）
4. private 属性子类**不能直接访问**（要用父类的方法或 protected）
5. 重写时方法名/参数/返回值类型不一样 → 那叫"新方法"，不是重写（`@Override` 会给警告）
6. 想通过"继承"省事乱套：猫继承狗？**语义要合理**才用继承，父子关系要说得通（学生是人 ✅，狗是猫 ❌）
