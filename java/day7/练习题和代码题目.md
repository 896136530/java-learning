## 题目详情

### 题 1：Animal + Dog（继承入门）
写两个类：
- **父类 `Animal`**：属性 `String name`；构造方法 `Animal(String name)`；方法 `eat()` 打印 `XX在吃东西`
- **子类 `Dog`**：`extends Animal`，新方法 `bark()` 打印 `XX汪汪叫`
- `main` 里：`new Dog("旺财")` → 调用 `eat()` 和 `bark()`
- 期望输出：
  ```
  旺财在吃东西
  旺财汪汪叫
  ```

### 题 2：Person + Student（super 构造方法）
写两个类：
- **父类 `Person`**：属性 `String name`、`int age`；构造方法 `Person(String name, int age)` 赋值
- **子类 `Student`**：`extends Person`，新属性 `int studentId`；构造方法 `Student(String name, int age, int studentId)`——**第一行用 `super(name, age)`**，再给 studentId 赋值；方法 `showAll()` 打印全部三个属性
- `main` 里：`new Student("小明", 18, 2025001)` → 调用 `showAll()`
- 期望输出：`姓名：小明，年龄：18，学号：2025001`

### 题 3：方法重写（@Override）
写三个类：
- **父类 `Animal`**：方法 `sound()` 打印 `动物发出声音`
- **子类 `Dog`**：`extends Animal`，**重写** `sound()`（加 `@Override`）打印 `狗狗汪汪叫`
- **子类 `Cat`**：`extends Animal`，重写 `sound()` 打印 `猫咪喵喵叫`
- `main` 里：分别创建 Dog 和 Cat，调用各自的 `sound()`
- 期望输出：
  ```
  狗狗汪汪叫
  猫咪喵喵叫
  ```
- 💡思考：如果没重写，`new Dog().sound()` 输出什么？（答：父类的"动物发出声音"）

### 题 4：protected + super 调父类方法
写两个类：
- **父类 `Person`**：`protected String name`；`Person(String name)`；方法 `introduce()` 打印 `我是人，我叫XX`
- **子类 `Student`**：`extends Person`，方法 `introduce()` 里**第一行 `super.introduce()`**（先调父类方法）再打印 `我还是学生`
- `main` 里：`new Student("小红")` → 直接访问 `name`（验证 protected 子类能用）→ 调用 `introduce()`
- 期望输出：
  ```
  名字：小红
  我是人，我叫小红
  我还是学生
  ```

### 题 5：综合 —— Employee + Manager（继承综合）
写两个类：
- **父类 `Employee`**：
  - `protected String name`、`protected double salary`
  - 构造 `Employee(String name, double salary)`
  - `getSalary()` 返回 salary
  - `showInfo()` 打印 `员工：XX，薪资：XX元`
- **子类 `Manager`**：`extends Employee`
  - 新属性 `double bonus`（奖金）
  - 构造 `Manager(String name, double salary, double bonus)`——用 `super(name, salary)`，再设 bonus
  - **重写** `getSalary()`：返回 `super.getSalary() + bonus`（工资+奖金）
  - **重写** `showInfo()`：先 `super.showInfo()`，再打印 `奖金：XX元`
- `main` 里：`new Manager("王总", 20000, 5000)` → 打印 `getSalary()` 和 `showInfo()`
- 期望输出：
  ```
  总薪资：25000.0
  员工：王总，薪资：20000.0元
  奖金：5000.0元
  ```
