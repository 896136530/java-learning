## 题 1 答案（Animal + Dog 继承入门）

```java
class Animal {
    String name;

    Animal(String name) {
        this.name = name;
    }

    void eat() {
        System.out.println(name + "在吃东西");
    }
}

class Dog extends Animal {
    Dog(String name) {
        super(name);          // 调父类构造方法
    }

    void bark() {
        System.out.println(name + "汪汪叫");
    }
}
```

（main：`new Dog("旺财")` → eat() 输出 旺财在吃东西，bark() 输出 旺财汪汪叫）

## 题 2 答案（Person + Student super 构造方法）

```java
class Person {
    String name;
    int age;

    Person(String name, int age) {
        this.name = name;
        this.age = age;
    }
}

class Student extends Person {
    int studentId;

    Student(String name, int age, int studentId) {
        super(name, age);            // 第一行必须调父类构造方法！
        this.studentId = studentId;
    }

    void showAll() {
        System.out.println("姓名：" + name + "，年龄：" + age + "，学号：" + studentId);
    }
}
```

（main：`new Student("小明", 18, 2025001)` → showAll() 输出 姓名：小明，年龄：18，学号：2025001）

## 题 3 答案（方法重写 @Override）

```java
class Animal {
    void sound() {
        System.out.println("动物发出声音");
    }
}

class Dog extends Animal {
    @Override
    void sound() {
        System.out.println("狗狗汪汪叫");
    }
}

class Cat extends Animal {
    @Override
    void sound() {
        System.out.println("猫咪喵喵叫");
    }
}
```

（main：`new Dog().sound()` → 狗狗汪汪叫；`new Cat().sound()` → 猫咪喵喵叫）

## 题 4 答案（protected + super 调父类方法）

```java
class Person {
    protected String name;

    Person(String name) {
        this.name = name;
    }

    void introduce() {
        System.out.println("我是人，我叫" + name);
    }
}

class Student extends Person {
    Student(String name) {
        super(name);
    }

    @Override
    void introduce() {
        super.introduce();           // 先调父类的方法
        System.out.println("我还是学生");
    }
}
```

（main：访问 `s.name`（protected 子类能用）→ 我是人，我叫小红 → 我还是学生）

## 题 5 答案（Employee + Manager 综合）

```java
class Employee {
    protected String name;
    protected double salary;

    Employee(String name, double salary) {
        this.name = name;
        this.salary = salary;
    }

    double getSalary() {
        return salary;
    }

    void showInfo() {
        System.out.println("员工：" + name + "，薪资：" + salary + "元");
    }
}

class Manager extends Employee {
    double bonus;

    Manager(String name, double salary, double bonus) {
        super(name, salary);
        this.bonus = bonus;
    }

    @Override
    double getSalary() {
        return super.getSalary() + bonus;    // 工资 + 奖金
    }

    @Override
    void showInfo() {
        super.showInfo();
        System.out.println("奖金：" + bonus + "元");
    }
}
```

（main：`new Manager("王总", 20000, 5000)` → getSalary()=25000.0 → showInfo() 两行输出）
