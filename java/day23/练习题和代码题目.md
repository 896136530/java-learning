## Ex1：造一个 Student 类（零件）

写 `class Student`：字段 `String name`、`int score`，构造方法 `Student(name, score)`，再加：

- `toString()`：返回 `姓名 分数`（例如 `张三 88`）——**没有它打印出来是内存地址乱码**
- `static int maxOf(Student a, Student b)`：返回两人中较高的分数

- 期望输出：
  ```
  张三 88
  李四 95
  最高分：95
  ```
- 提示：`toString` 要加 `@Override`；`maxOf` 是三目运算符 `条件 ? A : B` 的好机会

## Ex2：用 List 管一个班（排队）

写 `class TeamUtil`，三个静态方法：

- `static int count(List<Student> list)` → 返回人数
- `static void printAll(List<Student> list)` → 挨个打印学生（用增强 for）
- `static int total(List<Student> list)` → 返回总分

- 期望输出：
  ```
  共 3 人
  张三 88
  李四 95
  王五 76
  总分：259
  ```
- 提示：`printAll` 里直接 `System.out.println(s)` 就会用到 Ex1 的 `toString`

## Ex3：HashMap 按姓名查成绩（查表）

写 `class ScoreTable`，内部用 `Map<String, Integer>` 存 姓名→成绩：

- `void put(String name, int score)` → 存/改
- `Integer get(String name)` → 查，**查不到返回 null**（返回类型必须是 `Integer`，`int` 会 NPE！）
- `int size()` → 在册人数

- 期望输出：
  ```
  李四 95
  赵六 无成绩
  在册人数：3
  ```
- 提示：这就是 Day13 的查表套路；注意 `main` 里已经判过 null 了

## Ex4：成绩榜排序（Comparable 复合比较）⭐

写 `class Student implements Comparable<Student>`，规则：

1. **分数高的排前面**（降序）
2. **分数相同**时，**姓名按字典序升序**（张三 在 王五 前面）

- 数据：张三88、李四95、王五88、赵六76（**故意有同分**）
- 期望输出：
  ```
  李四 95
  张三 88
  王五 88
  赵六 76
  ```
- 提示：`compareTo` 里先算 `int c = Integer.compare(o.score, this.score);`，若 `c != 0` 直接返回它；否则返回 `this.name.compareTo(o.name)`
- ⚠️ 只比分数不比姓名 → 同分的顺序不确定，判题会挂；这才是"复合比较"的意义

## Ex5：分数段统计（Map 计数套路）⭐

写 `class StatUtil` 的静态方法 `static Map<String, Integer> byLevel(int[] scores)`：

- ≥90 → `"优秀"`；80~89 → `"良好"`；60~79 → `"及格"`；<60 → `"不及格"`
- 返回一个 Map：**档位名 → 人数**

- 数据：`{95, 88, 76, 100, 60, 45}`
- 期望输出：
  ```
  优秀 2 人
  良好 1 人
  及格 2 人
  不及格 1 人
  ```
- 提示：计数套路 `map.put(level, map.getOrDefault(level, 0) + 1)`；`main` 用 `getOrDefault(lv, 0)` 打印，所以某档 0 人也不会打 null

## Review：排行榜系统（全家桶综合）⭐⭐

写 `class RankBoard` 的两个静态方法（`Student` 类要自己补，字段 `name`/`score` + 构造）：

- `static void printTop3(Map<String, Integer> scores)` → 按**成绩降序**打印前 3 名，格式：
  `第1名：钱七 100`
- `static String average(Map<String, Integer> scores)` → 返回**平均分字符串**，保留两位小数（如 `83.80`）

- 数据：张三88 / 李四95 / 王五76 / 赵六60 / 钱七100
- 期望输出：
  ```
  第1名：钱七 100
  第2名：李四 95
  第3名：张三 88
  平均分：83.80
  ```
- 提示：
  - 先 `new ArrayList<>(scores.entrySet())` 把表倒进列表
  - 再 `list.sort(...)` 按 value 降序（`Map.Entry` 用 `getValue()` 拿成绩）
  - 平均分：先 `double` 求和再除人数，用 `String.format("%.2f", avg)`
  - ⚠️ **成绩不能当 key**——同分会互相覆盖，人直接消失
