## Ex1：Student 类（零件）

**考点**：字段 + 构造方法 + `toString`（不重写就是内存地址乱码）。

```java
class Student {
    String name;
    int score;

    Student(String name, int score) {
        this.name = name;
        this.score = score;
    }

    static int maxOf(Student a, Student b) {
        return a.score >= b.score ? a.score : b.score;
    }

    @Override
    public String toString() {
        return name + " " + score;
    }
}
```

- 期望输出：
  ```
  张三 88
  李四 95
  最高分：95
  ```
- 易错：忘了 `@Override toString()` → 打印 `Student@1b6d3586`；`maxOf` 写成实例方法会编译不过（main 里是 `Student.maxOf` 静态调用）

## Ex2：List 管一个班

**考点**：泛型集合 `List<Student>`、增强 for、累加。

```java
class Student {
    String name;
    int score;

    Student(String name, int score) {
        this.name = name;
        this.score = score;
    }

    @Override
    public String toString() {
        return name + " " + score;
    }
}

class TeamUtil {
    static int count(List<Student> list) {
        return list.size();
    }

    static void printAll(List<Student> list) {
        for (Student s : list) {
            System.out.println(s);      // 自动调用 toString
        }
    }

    static int total(List<Student> list) {
        int sum = 0;
        for (Student s : list) {
            sum += s.score;
        }
        return sum;
    }
}
```

- 期望输出：
  ```
  共 3 人
  张三 88
  李四 95
  王五 76
  总分：259
  ```
- 易错：`printAll` 里写 `System.out.println(s.name + " " + s.score)` 也能过，但用 `s` 才是"对象自己会说话"的正解

## Ex3：HashMap 按姓名查成绩

**考点**：Map 查表；返回 `Integer` 而不是 `int`（防拆箱 NPE）。

```java
class ScoreTable {
    Map<String, Integer> map = new HashMap<>();

    void put(String name, int score) {
        map.put(name, score);
    }

    Integer get(String name) {
        return map.get(name);       // 查不到返回 null
    }

    int size() {
        return map.size();
    }
}
```

- 期望输出：
  ```
  李四 95
  赵六 无成绩
  在册人数：3
  ```
- 易错：`int get(...)` → `map.get("赵六")` 返回 null 自动拆箱 → **NullPointerException**（这是 Day13 就埋的雷，今天必须记住）

## Ex4：成绩榜（Comparable 复合比较）

**考点**：`compareTo` 里做**两级比较**：先分数降序，同分姓名升序。

```java
class Student implements Comparable<Student> {
    String name;
    int score;

    Student(String name, int score) {
        this.name = name;
        this.score = score;
    }

    @Override
    public int compareTo(Student o) {
        int c = Integer.compare(o.score, this.score);   // ① 分数降序（倒着比）
        if (c != 0) {
            return c;
        }
        return this.name.compareTo(o.name);             // ② 同分按姓名升序兜底
    }

    @Override
    public String toString() {
        return name + " " + score;
    }
}
```

- 期望输出：
  ```
  李四 95
  张三 88
  王五 88
  赵六 76
  ```
- 易错：只写 `Integer.compare(o.score, this.score)` → 张三/王五（都是 88）顺序**不确定**，判题可能挂
- 加分理解：这就是"**主关键字 + 次关键字**"排序，数据库 `ORDER BY score DESC, name ASC` 一个道理

## Ex5：分数段统计

**考点**：Map 计数套路 `getOrDefault(level, 0) + 1`；多分支 `if-else if`。

```java
class StatUtil {
    static Map<String, Integer> byLevel(int[] scores) {
        Map<String, Integer> map = new HashMap<>();
        for (int s : scores) {
            String level;
            if (s >= 90) {
                level = "优秀";
            } else if (s >= 80) {
                level = "良好";
            } else if (s >= 60) {
                level = "及格";
            } else {
                level = "不及格";
            }
            map.put(level, map.getOrDefault(level, 0) + 1);
        }
        return map;
    }
}
```

- 期望输出：
  ```
  优秀 2 人
  良好 1 人
  及格 2 人
  不及格 1 人
  ```
- 易错：`if` 顺序写反（先判 `>= 60`）→ 95 分会被算成"及格"；**从高往低判**才对
- 小知识：`map.getOrDefault(level, 0) + 1` 和 Day13 的 `containsKey` 写法等价，但更短更安全

## Review：排行榜系统（全家桶综合）

**考点**：`entrySet` → `ArrayList` → `list.sort` 按 value 降序（同分姓名升序）→ 取前 3；平均值 `String.format("%.2f")`。

```java
class RankBoard {
    static void printTop3(Map<String, Integer> scores) {
        List<Map.Entry<String, Integer>> list = new ArrayList<>(scores.entrySet());
        list.sort((a, b) -> {
            int c = Integer.compare(b.getValue(), a.getValue());   // 成绩降序
            if (c != 0) {
                return c;
            }
            return a.getKey().compareTo(b.getKey());               // 同分按姓名升序
        });
        for (int i = 0; i < Math.min(3, list.size()); i++) {
            Map.Entry<String, Integer> e = list.get(i);
            System.out.println("第" + (i + 1) + "名：" + e.getKey() + " " + e.getValue());
        }
    }

    static String average(Map<String, Integer> scores) {
        int sum = 0;
        for (int v : scores.values()) {
            sum += v;
        }
        double avg = (double) sum / scores.size();      // 先转 double！
        return String.format("%.2f", avg);
    }
}
```

- 期望输出：
  ```
  第1名：钱七 100
  第2名：李四 95
  第3名：张三 88
  平均分：83.80
  ```
- 易错 ①：用 `TreeMap<Integer, ...>` 拿成绩当 key 排 → **同分覆盖，人消失**；正确做法是"取出来放 List 重排"
- 易错 ②：`sum / scores.size()` 两个 int 相除 → `83.0`（丢精度）；必须 `(double) sum / size`
- 易错 ③：`String.format("%.2f")` 写成 `"%.2f"` 没问题，但别写成 `%f`（会变 `83.800000`）
- 易错 ④：中文全角冒号 `：` 写成半角 `:` → 判题挂（逐字符比对）
- 加分：打印前先判 `list.size() < 3`，用 `Math.min(3, list.size())` 防越界（本题正好 5 人，但真实数据可能只有 2 人）

## 六题一句话总复习

| 题 | 武器 | 一句话 |
|---|---|---|
| Ex1 | 类 | 字段+构造+toString，对象才会"说人话" |
| Ex2 | List | 排队队伍，增强 for 挨个处理 |

| Ex4 | Comparable | 类内两级比较：分数降序 + 同分姓名升序 |
| Ex5 | Map 计数 | getOrDefault +1，档位从高往低判 |

## 附：本章两句话（面试可背）

1. **Map 存的是"键值对"，List 存的是"顺序"**——要查得快用 Map，要排队遍历用 List。
2. **排序两把钥匙**：`Comparable`（类自己会排，只能有一种默认规则）vs `Comparator`（外挂裁判，想几种规则就写几个）。
