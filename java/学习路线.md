## 二、方向决定（已定，不再改）

**Java 后端开发**

理由（都查过数据，站得住）：
1. **岗位池最大**：银行 / 政务 / 国企 / 传统企业的存量系统全是 Java，这是前端没有的"基本盘"
2. **AI 替代风险低**：AI 最擅长写"页面"，初级前端岗位 2025 年需求下降 9.89%（[InfoQ](https://www.infoq.cn/article/7crxu6xvt3l4bq2pv4av)）；后端涉及业务逻辑和系统设计，AI 难完全替代
3. **一张票多趟车**：既能投民营公司，也能投国企 / 政务 / 考编信息技术岗
4. **和已有进度衔接**：已经学到 Day 6，不浪费

> ⚠️ 不选前端做主线：入门快是优点，但 2025 年"写页面"的初级前端是 AI 冲击最重的岗位（[36氪"前端已死"讨论](https://36kr.com/p/3186164448550789)）。前端当作"全栈兜底"的辅助技能，不作主线。

## 三、城市策略（不挑城市 = 优势）

- **优先**：杭州 / 深圳 / 成都 / 武汉 / 北上广 —— Java 岗位多、起薪 8k~15k
- **保底**：郑州 / 河南本地 —— 起薪 4.5k~7k；国企 / 考编赛道也在这里
