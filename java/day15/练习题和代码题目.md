## 题目详情

### 题 1：安全除法（DivSafe）
写一个类：
- **类 `DivSafe`**：`static int safeDivide(int a, int b)`——返回 `a / b`；**除数为 0 时返回 -1，不许崩**
- main 里（已写好）：`10/2` 和 `10/0`
- 期望输出：
  ```
  10/2=5
  10/0=-1
  ```
- 💡：把除法放进 try，catch 里 catch 哪一个异常？（除零是哪种异常，见知识点表格）

### 题 2：安全转数字（NumParse）
写一个类：
- **类 `NumParse`**：`static int toInt(String s)`——把字符串转成 int；**转不了（比如 "abc"）时返回 0，不许崩**
- main 里（已写好）：`"42"` 和 `"abc"`
- 期望输出：
  ```
  42=42
  abc=0
  ```
- 💡：`Integer.parseInt(s)` 转不了会抛哪种异常？（数字格式，知识点表格里找）

### 题 3：安全取数组（ArrayAt）
写一个类：
- **类 `ArrayAt`**：`static String safeGet(String[] arr, int i)`——返回 `arr[i]`；**越界时返回 "<越界>"，不许崩**
- main 里（已写好）：数组 `{"a","b"}`，取下标 1 和 9
- 期望输出：
  ```
  取[1]：b
  取[9]：<越界>
  ```

### 题 4：多异常分流（Describe）
写一个类：
- **类 `Describe`**：`static String describe(int[] arr, int i)`——
  - 正常：返回 `值=数字`
  - **越界**：返回 `越界`
  - **数组是 null**：返回 `数组为null`
  - 都不许崩
- main 里（已写好）：三个测试（正常 / 越界 / null）
- 期望输出：
  ```
  值=2
  越界
  数组为null
  ```
- 💡：一个 try 两个 catch——越界和 NPE 分头接住

### 题 5：容错累加（SafeSum）
写一个类：
- **类 `SafeSum`**：`static int sumTo(String[] tokens)`——把数组里每个字符串转成 int 累加；**转不了的直接跳过，不许崩**
- main 里（已写好）：`{"1","2","x","3"}`（x 是坏数据）
- 期望输出：
  ```
  总和：6
  ```
- 💡：循环里套 try-catch，坏数据被 catch 吞掉继续下一个——"容错处理"实战
