## 题 1 答案（安全除法）

```java
class DivSafe {
    public static int safeDivide(int a, int b) {
        try {
            return a / b;
        } catch (ArithmeticException e) {
            return -1;          // 除零被接住，返回 -1
        }
    }
}
```

（main 输出：**10/2=5** / **10/0=-1**——不崩）

**考点**：除零抛 `ArithmeticException`；catch 里返回"安全值"。
**刁钻用例**：`safeDivide(7, -2)` → -3（整数除法向零取整）；`safeDivide(0, 5)` → 0 不崩。

## 题 2 答案（安全转数字）

```java
class NumParse {
    public static int toInt(String s) {
        try {
            return Integer.parseInt(s);
        } catch (NumberFormatException e) {
            return 0;           // 转不了，返回 0
        }
    }
}
```

（main 输出：**42=42** / **abc=0**）

**考点**：`Integer.parseInt` 转不了抛 `NumberFormatException`。
**刁钻用例**：`"3.14"` 也转不了（不是整数格式）→ 0；`""` 空串 → 0；`"-7"` → -7。

## 题 3 答案（安全取数组）

```java
class ArrayAt {
    public static String safeGet(String[] arr, int i) {
        try {
            return arr[i];
        } catch (ArrayIndexOutOfBoundsException e) {
            return "<越界>";
        }
    }
}
```

（main 输出：**取[1]：b** / **取[9]：<越界>**）

**考点**：越界抛 `ArrayIndexOutOfBoundsException`。
**刁钻用例**：负数下标 `arr[-1]` 也是同一个异常 → <越界>；**arr 为 null 时 `arr[i]` 抛的是 NPE**（不是这个 catch）——知道区别即可。

## 题 4 答案（多异常分流）

```java
class Describe {
    public static String describe(int[] arr, int i) {
        try {
            return "值=" + arr[i];
        } catch (ArrayIndexOutOfBoundsException e) {
            return "越界";
        } catch (NullPointerException e) {
            return "数组为null";
        }
    }
}
```

（main 输出：**值=2** / **越界** / **数组为null**）

**考点**：一个 try 多个 catch，从上往下匹配。
**刁钻用例**：`arr = new int[0]`（空数组）取 `[0]` → 越界（不是 NPE，数组本体不是 null）；NPE 只在 arr 本身为 null 时发生。

## 题 5 答案（容错累加）

```java
class SafeSum {
    public static int sumTo(String[] tokens) {
        int sum = 0;
        for (String t : tokens) {
            try {
                sum = sum + Integer.parseInt(t);
            } catch (NumberFormatException e) {
                // 坏数据跳过，继续下一个
            }
        }
        return sum;
    }
}
```

（main 输出：**总和：6**）

**考点**：循环里套 try-catch = 容错处理；catch 里可以什么都不做（吞掉）。
**刁钻用例**：全坏数据 `{"x","y"}` → 0 不崩；空数组 → 0；`{"1","2","3"}` → 6。
