## 题目详情

### 题 1：读文件第一行（FileRead）
写一个类：
- **类 `FileRead`**：`static String readFirstLine(String path)`——读出文件**第一行**返回；文件不存在等出错了**返回 "读取失败"，不许崩**
- main 里（已写好）：读 `hello.txt`——**你先在旁边建好 `hello.txt`，内容写 `Hello IO!`**
- 期望输出：
  ```
  第一行：Hello IO!
  ```
- 💡：`BufferedReader` + `readLine()`；别忘了 try-with-resources 自动关

### 题 2：数文件行数（LineCount）
写一个类：
- **类 `LineCount`**：`static int countLines(String path)`——返回文件**有多少行**；出错返回 -1
- main 里（已写好）：读 `lines.txt`——**先建好，里面写 3 行**（随便写啥，比如 a / b / c）
- 期望输出：
  ```
  行数：3
  ```
- 💡：`readLine()` 到末尾返回 **null**——用 while 数到 null 为止

### 题 3：写文件（FileWrite）
写一个类：
- **类 `FileWrite`**：`static void writeHello(String path)`——往文件里写入一行 `Hello IO!`（**覆盖模式**）
- main 里（已写好）：写 `out.txt`，然后打印 `写入完成`
- 期望输出：
  ```
  写入完成
  ```
- 跑完**自己打开 out.txt** 确认里面是 `Hello IO!`
- 💡：`BufferedWriter` + `write` + `newLine`

### 题 4：追加一行（AppendLine）
写一个类：
- **类 `AppendLine`**：`static void appendLine(String path, String line)`——把 `line` **追加**到文件末尾（不覆盖原有内容）
- main 里（已写好）：`notes.txt` 末尾追加 `c`——**你先建好 notes.txt，里面写两行 a 和 b**
- 期望输出：
  ```
  追加完成
  ```
- 跑完打开 notes.txt 确认现在是三行（a / b / c）
- 💡：`new FileWriter(path, true)`——**第二个参数 true 就是追加模式**

### 题 5：复制文件（CopyFile）
写一个类：
- **类 `CopyFile`**：`static void copy(String src, String dst)`——把 `src` 文件内容原样复制到 `dst` 文件
- main 里（已写好）：`src.txt` → `dst.txt`——**先建好 src.txt，写一行 `copy me!`**
- 期望输出：
  ```
  复制完成
  ```
- 跑完打开 dst.txt 确认和 src.txt 一样
- 💡：一个 readLine 循环 + 一个 write；**一个 try 括号里可以声明两个资源，分号隔开**
