## 题 1 答案（读文件第一行）

```java
class FileRead {
    public static String readFirstLine(String path) {
        try (BufferedReader br = new BufferedReader(new FileReader(path))) {
            return br.readLine();        // 读第一行
        } catch (IOException e) {
            return "读取失败";           // 文件不存在等，不崩
        }
    }
}
```

（main 输出：**第一行：Hello IO!**）

**考点**：try-with-resources 自动关流；`readLine()` 读一行。
**刁钻用例**：文件不存在 → FileNotFoundException（是 IOException 的子类）被 catch → 返回 "读取失败"；空文件 → readLine 返回 null，第一行显示 null。

## 题 2 答案（数文件行数）

```java
class LineCount {
    public static int countLines(String path) {
        int count = 0;
        try (BufferedReader br = new BufferedReader(new FileReader(path))) {
            while (br.readLine() != null) {   // 到末尾 readLine 返回 null
                count++;
            }
        } catch (IOException e) {
            return -1;
        }
        return count;
    }
}
```

（main 输出：**行数：3**）

**考点**：**`readLine()` 末尾返回 null**——数行数的标志性循环。
**刁钻用例**：空文件 → 0；文件末尾没有换行符也算一行（readLine 读到内容即算）。

## 题 3 答案（写文件）

```java
class FileWrite {
    public static void writeHello(String path) {
        try (BufferedWriter bw = new BufferedWriter(new FileWriter(path))) {
            bw.write("Hello IO!");
            bw.newLine();
        } catch (IOException e) {
            System.out.println("写入失败");
        }
    }
}
```

（main 输出：**写入完成**；out.txt 内容是 `Hello IO!`）

**考点**：`FileWriter(path)` 默认**覆盖模式**——原有内容清掉重写。
**刁钻用例**：重复运行两次 → 文件还是只有一行（每次覆盖）；目录不存在 → FileNotFoundException 被 catch。

## 题 4 答案（追加一行）

```java
class AppendLine {
    public static void appendLine(String path, String line) {
        try (BufferedWriter bw = new BufferedWriter(new FileWriter(path, true))) {
            bw.write(line);
            bw.newLine();
        } catch (IOException e) {
            System.out.println("追加失败");
        }
    }
}
```

（main 输出：**追加完成**；notes.txt 变成 a / b / c 三行）

**考点**：**`new FileWriter(path, true)` 第二个参数 true = 追加模式**——唯一的区别，背下来。
**刁钻用例**：追加到不存在的文件 → 自动创建（不会崩）；连续追加两次 → 两行都加上。

## 题 5 答案（复制文件）

```java
class CopyFile {
    public static void copy(String src, String dst) {
        try (BufferedReader br = new BufferedReader(new FileReader(src));
             BufferedWriter bw = new BufferedWriter(new FileWriter(dst))) {
            String line;
            while ((line = br.readLine()) != null) {
                bw.write(line);
                bw.newLine();
            }
        } catch (IOException e) {
            System.out.println("复制失败");
        }
    }
}
```

（main 输出：**复制完成**；dst.txt 与 src.txt 内容一样）

**考点**：**一个 try 括号声明两个资源（分号隔开）**，顺序读一行写一行；`(line = br.readLine()) != null` 赋值+判断一行搞定。
**刁钻用例**：src 不存在 → catch 输出 复制失败（dst 不会被创建或留空）；二进制文件（图片）用字符流会坏——那是字节流的活，知道即可。
