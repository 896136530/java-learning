# Day 17 知识点：IO 流（文件读写）

> 前提：异常、泛型已通关。今天学程序和外界的"门"——**把数据存进文件、从文件读出来**，面试和项目都绕不开。

## 1. 为什么要 IO？

程序跑完内存就没了（变量、集合全消失）。**文件 = 持久化**：把数据存到硬盘，下次启动还在。
IO = Input/Output：读（Input）和写（Output）。

## 2. 字符流 vs 字节流（一句话记住）

| 方向 | 字符流（处理文本，推荐） | 字节流（处理图片/视频） |
|---|---|---|
| 读 | `Reader`：`FileReader` / `BufferedReader` | `InputStream` |
| 写 | `Writer`：`FileWriter` / `BufferedWriter` | `OutputStream` |

**文本文件用字符流**，今天的练习全是字符流。

## 3. 读文件三连（带缓冲）

```java
try (BufferedReader br = new BufferedReader(new FileReader("input.txt"))) {
    String line = br.readLine();        // 读一行；到末尾返回 null
    while (line != null) {              // 循环读完所有行
        System.out.println(line);
        line = br.readLine();
    }
}   // ← try-with-resources：括号里声明的东西，用完全自动关闭！
```

> **try-with-resources（Java 7+）**：`try (资源) {...}`，不用手写 close()——Day15 预告过的那个加分点，今天就用上。

## 4. 写文件（覆盖 / 追加）

```java
// 覆盖模式（文件原有内容会被清掉重写）
try (BufferedWriter bw = new BufferedWriter(new FileWriter("out.txt"))) {
    bw.write("Hello IO!");
    bw.newLine();
}

// 追加模式：构造器第二个参数传 true
try (BufferedWriter bw = new BufferedWriter(new FileWriter("out.txt", true))) {
    bw.write("再写一行");
    bw.newLine();
}
```

## 5. File 类：文件本身的操作

```java
File f = new File("out.txt");
f.exists();    // 存不存在
f.length();    // 字节数
f.delete();    // 删除
f.getName();   // 文件名
```

## 6. 中文编码坑（必踩必背）

`FileReader/FileWriter` 用**平台默认编码**（Windows 是 GBK，Linux 是 UTF-8）——同一份代码换个系统中文就乱码！
**正规做法**：写文件时指定 UTF-8（`OutputStreamWriter(new FileOutputStream(f), "UTF-8")`），读文件同理。
> 今天的练习用英文内容绕开它；面试问"中文乱码怎么办"就答这一句。
