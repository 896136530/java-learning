# Day 20 知识点：网络编程（Socket）

> 前提：Day17 IO 流（读/写）、Day18/19 多线程已通关。今天把两个技能**合体**——让两台电脑的程序说话。
> 后端面试高频章节，Spring Boot 出身的你必用（HTTP 就是建立在 Socket 之上的）。

## 1. 三个基础概念（背）

| 概念 | 一句话 |
|---|---|
| IP 地址 | 网络里每台电脑的门牌号（`127.0.0.1` = 本机自己，`localhost`）|
| 端口 | 一台电脑上很多程序，端口=哪个程序的房间号（0~65535）|
| Socket（套接字）| 程序之间通信的"插座"——你插上它，就能和对面传输数据 |

> 定位一个服务 = **IP + 端口**。例如访问本机的 31101 端口：`127.0.0.1:31101`。

## 2. 客户端-服务器模型（CS 模型）

- **服务器**：一直开着，等别人来连（`ServerSocket`）
- **客户端**：主动去找服务器（`Socket`）

```
服务器: new ServerSocket(端口)  →  accept() 等待  → 收到客户端 → 读/写
客户端: new Socket("127.0.0.1", 端口) → 连上 → 写/读
```

## 3. 服务器三件套（背）

```java
ServerSocket ss = new ServerSocket(31101);   // 1. 开个房间等客来
Socket s = ss.accept();                       // 2. 有人来了（阻塞等待！）
// 3. 拿输入输出流说话（Day17 的 IO 流老朋友）
BufferedReader in = new BufferedReader(new InputStreamReader(s.getInputStream()));
PrintWriter out = new PrintWriter(s.getOutputStream(), true);   // true = 自动刷新
String line = in.readLine();    // 读一行（阻塞，等对方发）
out.println("服务器回话：" + line);   // 回一句
```

客户端同款，方向反过来：
```java
Socket c = new Socket("127.0.0.1", 31101);
PrintWriter out = new PrintWriter(c.getOutputStream(), true);
BufferedReader in = new BufferedReader(new InputStreamReader(c.getInputStream()));
out.println("你好");      // 发
System.out.println(in.readLine());   // 收
```

## 4. 三个坑（必踩过才算会）

1. **连接被拒 Connection refused**：服务器还没 `accept`，客户端就来了 → 客户端先 `sleep` 一小会儿，或服务器先启动
2. **端口占用 Address already in use**：端口被别人占了（或上次没释放）→ 换端口
3. **`readLine()` 会阻塞**：对方不发完一行（换行符），这边就干等 → 一定要 `println`（自带换行）

## 5. 多线程服务器（Day18 知识落地 🎯）

一个服务器只服务一个客户端没意义——**每来一个客户端，开一个线程伺候它**：

```java
while (true) {
    Socket s = ss.accept();
    new Thread(() -> handle(s)).start();   // 来一个开一个
}
```

> 这就是"线程池"出现之前的服务器形态；Day19 学的那手"共享对象加锁"在服务器里同样适用（比如统计连接数要 synchronized）。

## 6. 面试必背三句话

1. **TCP vs UDP**：TCP 可靠（三次握手、要建立连接）、UDP 快但可能丢包（视频通话）
2. Socket 是**传输层接口**：Java 的 `ServerSocket`=服务端、`Socket`=客户端
3. HTTP 请求（你以后天天调）本质是"客户端用 Socket 发一段特殊格式的文本"——今天学的就是地基
