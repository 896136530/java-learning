## 题目详情

### 题 1：回声服务器（EchoServer）
- main（已写好）：后台线程启动服务器，主线程连上去发 `你好，服务器`，打印收到的回复
- 写类 **`EchoServer`**：`static void start(int port)`——循环 `accept`，读到一行后回 `服务器回话：` + 原文
- 期望输出：
  ```
  服务器回话：你好，服务器
  ```
- 💡：知识点第三节的三件套（ServerSocket → accept → 读一行回一行）

### 题 2：大写服务器（UpperServer）
- main（已写好）：发 `hello`，打印回复
- 写类 **`UpperServer`**：`static void start(int port)`——accept 后读一行，**转大写**（`line.toUpperCase()`）回
- 期望输出：
  ```
  HELLO
  ```
- 💡：服务器端处理数据的思路——收到的数据想怎么加工都行

### 题 3：加法服务器（SumServer）
- main（已写好）：连上后连发两行数字 `3` 和 `4`，打印回复
- 写类 **`SumServer`**：`static void start(int port)`——accept 后读两行，`Integer.parseInt` 求和，回 `3 + 4 = 7` 这种格式
- 期望输出：
  ```
  3 + 4 = 7
  ```
- 💡：**字符串 → 数字**要用 `Integer.parseInt`；回给客户端时拼字符串

### 题 4：计数器服务器（CounterServer）
- main（已写好）：连上后连发三行 `ping` / `pong` / `hi`，逐行打印回复
- 写类 **`CounterServer`**：`static void start(int port)`——同一个连接内，每收到一行回 `第N条：` + 原文（N 从 1 递增）
- 期望输出：
  ```
  第1条：ping
  第2条：pong
  第3条：hi
  ```
- 💡：在 accept 之后的循环里逐行读+计数，**直到对面断开**（readLine 返回 null）

### 题 5：多人服务器（MultiServer）
- main（已写好）：连上后发一个名字 `小明`，打印回复
- 写类 **`MultiServer`**：`static void start(int port)`——循环 accept，**每接一个客户端就 `new Thread` 开线程**去服务（Day18 大招），线程里读一行名字，回 `欢迎，` + 名字 + `！`
- 期望输出：
  ```
  欢迎，小明！
  ```
- 💡：多线程服务器的标准形态（知识点第五节）；`handle` 的逻辑包在线程里，服务器主循环立刻回去 accept 下一个

### 🎯 复习：前缀回声（Review）

  ```
  [echo] hello
  [echo] bye
  ```
