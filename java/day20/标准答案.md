## 题 1 答案（回声服务器）

```java
class EchoServer {
    static void start(int port) {
        try {
            ServerSocket ss = new ServerSocket(port);
            while (true) {
                Socket s = ss.accept();
                BufferedReader in = new BufferedReader(new InputStreamReader(s.getInputStream()));
                PrintWriter out = new PrintWriter(s.getOutputStream(), true);
                String line = in.readLine();
                out.println("服务器回话：" + line);
                s.close();
            }
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```

（main 输出：**服务器回话：你好，服务器**）

**考点**：ServerSocket→accept→读一行回一行；`PrintWriter` 第二参 `true`=自动刷新（否则对方读不到）。
**刁钻用例**：`accept()` 和 `readLine()` 都**阻塞**——服务器没起来客户端就连会 Connection refused；客户端不 `println`（只 print）则 readLine 等不到换行卡死。

## 题 2 答案（大写服务器）

```java
class UpperServer {
    static void start(int port) {
        try {
            ServerSocket ss = new ServerSocket(port);
            while (true) {
                Socket s = ss.accept();
                BufferedReader in = new BufferedReader(new InputStreamReader(s.getInputStream()));
                PrintWriter out = new PrintWriter(s.getOutputStream(), true);
                String line = in.readLine();
                out.println(line.toUpperCase());
                s.close();
            }
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```

（main 输出：**HELLO**）

**考点**：服务器端拿到的是字符串——想怎么加工都行（这就是"协议"的原型）。
**刁钻用例**：服务器固定只服务**一个**连接就回 accept 循环 → 第二个客户端就卡在 accept 没人理（此题恰好只需一个，但多线程版才通用——见 Ex5）。

## 题 3 答案（加法服务器）

```java
class SumServer {
    static void start(int port) {
        try {
            ServerSocket ss = new ServerSocket(port);
            while (true) {
                Socket s = ss.accept();
                BufferedReader in = new BufferedReader(new InputStreamReader(s.getInputStream()));
                PrintWriter out = new PrintWriter(s.getOutputStream(), true);
                int a = Integer.parseInt(in.readLine());
                int b = Integer.parseInt(in.readLine());
                out.println(a + " + " + b + " = " + (a + b));
                s.close();
            }
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```

（main 输出：**3 + 4 = 7**）

**考点**：网络传的都是**字符串**——`Integer.parseInt` 转数字，算完拼回字符串。
**刁钻用例**：客户端少发一行 → 服务器 readLine 永远阻塞（死等）；传非数字 → `NumberFormatException`（真实项目要 try-catch 并回传错误信息）。

## 题 4 答案（计数器服务器）

```java
class CounterServer {
    static void start(int port) {
        try {
            ServerSocket ss = new ServerSocket(port);
            Socket s = ss.accept();
            BufferedReader in = new BufferedReader(new InputStreamReader(s.getInputStream()));
            PrintWriter out = new PrintWriter(s.getOutputStream(), true);
            String line;
            int n = 1;
            while ((line = in.readLine()) != null) {
                out.println("第" + n + "条：" + line);
                n++;
            }
            s.close();
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```

（main 输出：第1条：ping / 第2条：pong / 第3条：hi）

**考点**：**一个连接内循环读**（`while ((line = in.readLine()) != null)`）；客户端关连接后 readLine 返回 null → 退出。
**刁钻用例**：把循环写在 accept 外面（每个连接只读一行）→ 客户端发第二行时没人读。

## 题 5 答案（多人服务器）

```java
class MultiServer {
    static void start(int port) {
        try {
            ServerSocket ss = new ServerSocket(port);
            while (true) {
                Socket s = ss.accept();
                new Thread(() -> handle(s)).start();   // 每来一个开一个线程
            }
        } catch (IOException e) {
            e.printStackTrace();
        }
    }

    static void handle(Socket s) {
        try {
            BufferedReader in = new BufferedReader(new InputStreamReader(s.getInputStream()));
            PrintWriter out = new PrintWriter(s.getOutputStream(), true);
            String name = in.readLine();
            out.println("欢迎，" + name + "！");
            s.close();
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```

（main 输出：**欢迎，小明！**）

**考点**：**多线程服务器标准形态**——accept 循环里 new Thread，主循环立刻回去接下一个；handle 才是"伺候一个客人"的逻辑。
**刁钻用例**：不开线程直接 `handle(s)` → 串行服务，第二个客户端必须等第一个处理完；共享的计数/状态要 synchronized（Day19 的知识）。
