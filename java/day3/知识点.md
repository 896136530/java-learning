# Day 3 知识点：数组与 Scanner 输入

> 本文件只讲知识点，练习题见《练习题和代码题目.md》，做完再看《标准答案.md》。

## 1. 数组：同一类型数据的集合
- 数组长度**固定**，创建后不能变
- **下标从 0 开始**
```java
int[] arr = new int[5];          // 创建长度 5 的数组（默认值 0）
int[] arr2 = {10, 20, 30};       // 直接给初值（长度 3）
int[] arr3 = new int[]{10, 20};  // 等价写法

arr[0] = 99;                      // 给第 1 个元素赋值
System.out.println(arr2.length);  // 长度 = 3
```

## 2. 访问数组（重点）.0
- 合法下标范围：`0 ~ length-1`
- **越界**（比如 `arr[5]`，长度只有 5 时）→ `ArrayIndexOutOfBoundsException`，程序崩溃
- 默认值：`int` → 0，`double` → 0.0，`boolean` → false，引用类型 → null

## 3. 遍历数组
```java
// 方式 1：普通 for（能拿到下标，能修改）
for (int i = 0; i < arr.length; i++) {
    System.out.println(arr[i]);
}

// 方式 2：for-each（只读方便；但改 x 不会影响数组！改的是副本）
for (int x : arr) {
    System.out.println(x);
}
```

## 4. 常用操作模板（背下来）
**求最大值**：
```java
int max = arr[0];
for (int i = 1; i < arr.length; i++) {
    if (arr[i] > max) max = arr[i];
}
```
**求和/平均**：循环里 `sum += arr[i]`，平均 = `(double) sum / arr.length`
**反转**：交换对称位置（`arr[i]` ↔ `arr[length-1-i]`，i 走一半）

## 5. Scanner 输入（让程序"听"用户说话）
```java
import java.util.Scanner;        // 第一行必须导入

Scanner sc = new Scanner(System.in);
int n = sc.nextInt();            // 读一个整数
double d = sc.nextDouble();      // 读一个小数
String s = sc.nextLine();        // 读一行文字
sc.close();                      // 用完关闭（好习惯）
```
配合 `System.out.print(...)` 提示用户输入。

## 6. Random 随机数（写游戏必备）
```java
import java.util.Random;

Random rand = new Random();
int x = rand.nextInt(100);       // 0 ~ 99
int y = rand.nextInt(100) + 1;   // 1 ~ 100
```

## 7. 常见坑（记住）
1. **数组越界**：`arr[arr.length]` 一定报 `ArrayIndexOutOfBoundsException`
2. **`nextInt()` 后面接 `nextLine()` 的坑**：nextInt 会留下一个换行符，直接 nextLine 会读到空字符串。解决：中间再调一次 `sc.nextLine()` 吃掉换行
3. **for-each 改不了数组元素**（改的是副本）
4. 忘了 `import java.util.Scanner` / `java.util.Random` → 编译报错
5. 循环里写 `i <= arr.length` → 越界（应该是 `<`）
