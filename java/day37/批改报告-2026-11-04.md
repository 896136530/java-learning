## 5 个必须改对的概念

1. **EXPLAIN 不执行 SQL**：它是"让 MySQL 说它打算怎么查"，看到的是**估算**（`EXPLAIN ANALYZE` 才会真跑）。
2. **`rows` = 预计扫描行数**，不是返回行数；`rows × filtered` 才是"预计返回"。
   199269 × 10% ≈ 19927；真实 171429 → 差 **8.6 倍**（不是 0.16 倍）。
3. **深分页**：`LIMIT 150000, 20` = 读 150020 行、扔 150000 行、返回 20 行。
4. **回表次数**要能报数字：覆盖索引把 20000 次回表变成 0 次，这才是它快的本质。
5. **游标法省的是"扫描前面的行"**，不是回表；它和延迟关联的收益点不同。
