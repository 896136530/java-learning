## 题 1 答案（求和）

```java
class SumUtil {
    public static int sum(ArrayList<Integer> nums) {
        int total = 0;
        for (int i = 0; i < nums.size(); i++) {   // size() 带括号！不是 length
            total = total + nums.get(i);          // Integer 自动拆箱成 int
        }
        return total;
    }
}
```

（main 输出：**总和：15** / **空表：0**）

**考点**：遍历模板（`i < nums.size()`）+ `get(i)`；空表循环不执行 → 天然返回 0。
**刁钻用例**：`sum(null)` → NullPointerException（对 null 调 size() 崩）——实际项目先判空。

## 题 2 答案（增删查）

```java
class EditUtil {
    public static String lastItem(ArrayList<String> list) {
        return list.get(list.size() - 1);   // 最后一个下标 = size-1
    }

    public static String removeAt(ArrayList<String> list, int index) {
        return list.remove(index);          // remove(下标) 返回被删的元素
    }
}
```

（main 输出：**最后一个：C** / **删掉的：Python** / **删除后还有 2 个**）

**考点**：`size()-1` 是最后一个下标；`remove(下标)` 有返回值（很多人不知道）。
**刁钻用例**：`removeAt(list, 5)` 越界 → IndexOutOfBoundsException；`lastItem(空表)` → 越界崩。

## 题 3 答案（找最长）

```java
class WordUtil {
    public static String longest(ArrayList<String> words) {
        String best = words.get(0);                // 先拿第一个当"擂主"
        for (int i = 1; i < words.size(); i++) {   // 从第 2 个开始比
            if (words.get(i).length() > best.length()) {
                best = words.get(i);               // 有更长的就换擂主
            }
        }
        return best;
    }
}
```

（main 输出：**最长的：Python** / **最长的：bb**）

**考点**：打擂法（擂主+换人）；用 `>` 不用 `>=` → 长度相等时保持先出现的。
**刁钻用例**：`longest(空表)` → `get(0)` 越界崩——先判 `words.isEmpty()`；两个"Python"并列 → 返回最先那个。

## 题 4 答案（删除所有指定值）⚠️ 最重要的一题

```java
class DedupeUtil {
    public static void removeAll(ArrayList<Integer> nums, int target) {
        for (int i = nums.size() - 1; i >= 0; i--) {   // ⚠️ 从后往前删！
            if (nums.get(i) == target) {               // Integer 和 int 比，自动拆箱
                nums.remove(i);
            }
        }
    }
}
```

（main 输出：**[1, 3, 4]**）

**考点（面试高频）**：**边遍历边删必须从后往前**。为什么？
- `[1, 2, 3, 2, 4, 2]` 正着删：删掉下标 1 的 2 → 后面的元素全部前移，原下标 3 的 2 变成下标 2；但 `i` 已经走到 2 并且马上 `i++` → **它被跳过了**
- 从后往前：删的是"尾巴"，前面的下标**不受影响**，一个都漏不掉

**刁钻用例**：`removeAll([2,2,2], 2)` → 从后往前三个全删 ✓（正着删会漏）；`get(i) == target` 也可以写成 `nums.get(i).equals(target)`（Integer 大数值相等时 == 不可靠，虽然 -128~127 有缓存，建议养成 equals 习惯）。

## 题 5 答案（成绩表综合）

```java
class GradeUtil {
    public static int top(ArrayList<Integer> scores) {
        int best = scores.get(0);
        for (int i = 1; i < scores.size(); i++) {
            if (scores.get(i) > best) {
                best = scores.get(i);
            }
        }
        return best;
    }

    public static void raise(ArrayList<Integer> scores) {
        for (int i = 0; i < scores.size(); i++) {
            if (scores.get(i) < 60) {
                scores.set(i, 60);   // set(下标, 新值) 修改
            }
        }
    }
}
```

（main 输出：**最高分：100** / **修改后：[60, 80, 60, 100]**）

**考点**：打擂法复用；`set(下标, 新值)` 修改元素——这就是"数组 `scores[i] = 60`"的 ArrayList 版。
**刁钻用例**：`raise` 里用增强 for 遍历+set → 编译报错？不，是**改不到**（增强 for 的变量是副本）——改值必须用下标 for；`top(空表)` → 崩，先判空。
