 # Day 12 知识点：ArrayList（能自动扩容的"动态数组"）

> 前提：Day 3 数组学过，Day 11 String 过关。今天上后端存数据的**主力容器**——ArrayList，面试和项目天天用。

## 1. 数组的痛点 → ArrayList 出场

```java
int[] a = new int[3];   // 长度定死 3，想存第 4 个？没门
```

数组三个硬伤：
1. **长度定死**，不知道将来要存几个
2. **插入/删除要自己搬元素**（挪下标），烦且易错
3. 删一个元素，长度也不会变小

**ArrayList = 能自动扩容的数组**：往死里 add，它自己会"长大"（内部自动换更大的数组并搬数据，你无感）。

## 2. 使用前提（三件套）

```java
import java.util.ArrayList;           // ① 导入（在文件第一行）

ArrayList<String> names = new ArrayList<>();   // ② 创建：<泛型> 指定装什么类型
names.add("小明");                              // ③ 使用
```

**⚠️ 泛型里只能放"类"，不能放基本类型**——`ArrayList<int>` 编译报错！要写包装类：

| 基本类型 | 包装类 |
|---|---|
| int | `Integer` |
| double | `Double` |
| char | `Character` |
| boolean | `Boolean` |

> 好消息：用的时候不用管——`list.get(i)` 返回 `Integer`，和 `int` 直接混用会自动"拆箱"，`nums.add(3)` 会自动"装箱"。

## 3. 常用方法表（背下来，天天用）

| 方法 | 作用 | 例子 |
|---|---|---|
| `add(元素)` | 尾部添加 | `list.add("Java")` |
| `add(下标, 元素)` | 指定位置插入（后面的自动后移）| `list.add(0, "顶")` |
| `get(下标)` | 取出 | `list.get(0)` |
| `set(下标, 新值)` | 修改 | `list.set(0, "改")` |
| `remove(下标)` | 删除并**返回被删的** | `list.remove(2)` |
| `remove(对象)` | 按内容删（只删第一个匹配）| `list.remove("Java")` |
| `size()` | 元素个数（**不是 length！**）| `list.size()` |
| `contains(元素)` | 是否包含 | `list.contains("Java")` |
| `indexOf(元素)` | 找下标，没有返回 -1 | `list.indexOf("Java")` |
| `isEmpty()` | 是否为空 | `list.isEmpty()` |
| `clear()` | 清空所有 | `list.clear()` |

**类型两个整天踩的坑：**
- `size()` 是**方法**（带括号），数组才是 `length` 属性
- 输出整个 list：`System.out.println(list)` 直接打印 `[Java, Python]`（ArrayList 重写过 toString）

## 4. 数组 vs ArrayList（面试会问）

| | 数组 int[] | ArrayList |
|---|---|---|
| 长度 | 固定 | 自动扩容 |
| 个数 | `length` 属性 | `size()` 方法 |
| 取/改 | `a[0]` | `get(0)` / `set(0, x)` |
| 装基本类型 | ✅ 直接 | ❌ 要包装类 |
| 插入/删除 | 手写搬移 | `add(i, x)` / `remove(i)` 一行 |
| 泛型 | 无 | `<Integer>` 指定类型 |

## 5. 遍历的两种方式

```java
// 方式A：普通 for + get（能边遍历边改）
for (int i = 0; i < list.size(); i++) {
    System.out.println(list.get(i));
}

// 方式B：增强 for（只读遍历，最简单）
for (String s : list) {
    System.out.println(s);
}
```

## 6. 常见坑清单（背）

1. `ArrayList<int>` **编译报错**——包装类：`ArrayList<Integer>`
2. `list.size()` 带括号，**不是** `list.length`
3. 下标越界：`get(5)` 但只有 3 个 → `IndexOutOfBoundsException`
4. **边遍历边删必须从后往前**：`for (i = size-1; i >= 0; i--)`——正着删会跳过元素（删了 2 号，3 号顶上变 2 号，i++ 就漏了）
5. `remove(2)` 删的是**下标 2**；想删"内容 2"要 `remove(Integer.valueOf(2))`
6. `get(i)` 返回包装类，参与计算时自动拆箱，但**调用方法**（如 `.equals`）前要判非 null

## 7. 一句话总结 + 明天预告
