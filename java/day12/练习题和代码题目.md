## 题目详情

### 题 1：求和（SumUtil.sum）

写一个类：
- **类 `SumUtil`**：`static int sum(ArrayList<Integer> nums)`——把所有元素加起来返回
- `main` 里（已写好）：`[3,5,7]` 和一个空表
- 期望输出：
  ```
  总和：15
  空表：0
  ```
- 💡：`for` 循环 + `get(i)`，循环条件用 `nums.size()`（不是 length！）；空表循环不执行 → 0

### 题 2：增删查（EditUtil）

写一个类：
- **类 `EditUtil`**：两个 static 方法——
  - `String lastItem(ArrayList<String> list)`：返回最后一个元素
  - `String removeAt(ArrayList<String> list, int index)`：删除指定下标并**返回被删的**
- `main` 里（已写好）：对 `[Java, Python, C]` 操作
- 期望输出：
  ```
  最后一个：C
  删掉的：Python
  删除后还有 2 个
  ```
- 💡：最后一个下标 = `size()-1`；`remove(下标)` **会返回被删的元素**（这个返回值很多人不知道）

### 题 3：找最长（WordUtil.longest）

写一个类：
- **类 `WordUtil`**：`static String longest(ArrayList<String> words)`——返回**最长**的字符串
- `main` 里（已写好）：`[Java, Python, C++]` 和 `[a, bb]`
- 期望输出：
  ```
  最长的：Python
  最长的：bb
  ```
- 💡：**打擂法**——先拿第一个当"擂主"，遍历时谁更长谁上位；相等不换（保持先出现的）

### 题 4：删除所有指定值（DedupeUtil.removeAll）⚠️

写一个类：
- **类 `DedupeUtil`**：`static void removeAll(ArrayList<Integer> nums, int target)`——把**所有**等于 target 的元素删光
- `main` 里（已写好）：`[1,2,3,2,4,2]` 删 2
- 期望输出：
  ```
  [1, 3, 4]
  ```
- 💡⚠️ **这是今天最重要的一题**：正着 `for i++` 边遍历边删会**跳过元素**（删了 2 号，3 号顶上变 2 号，i 却继续往后）→ 必须**从后往前删**（`i` 从 `size()-1` 到 0）；`Integer` 和 `int` 直接 `==` 比较会自动拆箱，可以放心用

### 题 5：综合——成绩表（GradeUtil.top / raise）

写一个类：
- **类 `GradeUtil`**：两个 static 方法——
  - `int top(ArrayList<Integer> scores)`：返回最高分
  - `void raise(ArrayList<Integer> scores)`：把所有**低于 60** 的分数改成 60（set 用法）
- `main` 里（已写好）：`[45, 80, 59, 100]`
- 期望输出：
  ```
  最高分：100
  修改后：[60, 80, 60, 100]
  ```
- 💡：打擂法学过了直接复用；改值用 `set(下标, 新值)`；`System.out.println(list)` 直接打印整表
