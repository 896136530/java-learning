## 题目详情

### 题 1：比较内容（CompareUtil.isSame）

写一个类：
- **类 `CompareUtil`**：一个 `static boolean isSame(String a, String b)`——返回两个字符串**内容**是否相等
- `main` 里（已写好）：比较字面量对、new 出来的对、大小写不同的对
- 期望输出：
  ```
  true
  true
  false
  ```
- 💡：内容相等永远 `a.equals(b)`（不是 `==`）；大小写敏感，`"hello"` ≠ `"HELLO"`

### 题 2：长度和字符（CharUtil）

写一个类：
- **类 `CharUtil`**：三个 static 方法——`int len(String s)` 返回长度；`char firstChar(String s)` 返回第一个字符；`char lastChar(String s)` 返回最后一个字符
- `main` 里（已写好）：对 `"Java"` 分别调用
- 期望输出：
  ```
  4
  J
  a
  ```
- 💡：`length()` 是字符个数；**下标从 0 开始**；最后一个字符的下标是 `length()-1`

### 题 3：常用方法（TextUtil）

写一个类：
- **类 `TextUtil`**：四个 static 方法——
  - `String shout(String s)`：全转大写
  - `String whisper(String s)`：全转小写
  - `String trimIt(String s)`：去掉首尾空格
  - `String upFirst(String s)`：**首字母大写**（其余不动），如 `"java"` → `"Java"`
- `main` 里（已写好）：四次调用
- 期望输出：
  ```
  HELLO
  world
  Java
  Java
  ```
- 💡：方法返回的是**新字符串**，原串不变；首字母大写 = `substring(0,1)` 大写 + 剩余部分

### 题 4：字符统计（SearchUtil.countChar）

写一个类：
- **类 `SearchUtil`**：一个 `static int countChar(String s, char c)`——数出字符 `c` 在 `s` 里出现几次
- `main` 里（已写好）：统计 banana 里的 a、hello 里的 l、java 里的 x
- 期望输出：
  ```
  3
  2
  0
  ```
- 💡：`for` 循环遍历每个字符 + `charAt(i)`；**char 是基本类型，用 `==` 比较没问题**
  （进阶技巧：`s.length() - s.replace(c + "", "").length()` 一行搞定，先看明白循环版）

### 题 5：反转字符串（ReverseUtil.reverse）

写一个类：
- **类 `ReverseUtil`**：一个 `static String reverse(String s)`——把字符串倒过来
- `main` 里（已写好）：反转 `"abc"`、`"Hello"`、空串 `""`
- 期望输出：
  ```
  cba
  olleH
    
  ```
- 💡：倒着遍历（`i` 从 `length()-1` 到 0），边遍历边拼接；空串循环不执行，不会崩
