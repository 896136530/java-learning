## 题 1 答案（比较内容）

```java
class CompareUtil {
    public static boolean isSame(String a, String b) {
        return a.equals(b);   // 比内容，永远别用 ==
    }
}
```

（main 输出：**true** / **true** / **false**）

**考点**：equals 比内容（new 出来的也算内容相等）；大小写敏感。
**刁钻用例**：`isSame(null, "a")` → NullPointerException（对 null 调方法崩）——实际项目会加 `a != null && a.equals(b)` 或 `Objects.equals(a, b)`。

## 题 2 答案（长度和字符）

```java
class CharUtil {
    public static int len(String s) {
        return s.length();
    }

    public static char firstChar(String s) {
        return s.charAt(0);              // 第一个字符，下标 0
    }

    public static char lastChar(String s) {
        return s.charAt(s.length() - 1); // 最后一个，下标 length-1
    }
}
```

（main 输出：**4** / **J** / **a**）

**考点**：length() 是字符个数；下标从 0 开始；最后一个下标是 length-1。
**刁钻用例**：`firstChar("")` → StringIndexOutOfBoundsException（空串 getCharAt(0) 越界）；`lastChar` 一样会崩——先判 `s.length() == 0` 再取。

## 题 3 答案（常用方法）

```java
class TextUtil {
    public static String shout(String s) {
        return s.toUpperCase();
    }

    public static String whisper(String s) {
        return s.toLowerCase();
    }

    public static String trimIt(String s) {
        return s.trim();                 // 只去首尾空格，中间的留着
    }

    public static String upFirst(String s) {
        return s.substring(0, 1).toUpperCase() + s.substring(1); // 首字母大写 + 剩余
    }
}
```

（main 输出：**HELLO** / **world** / **Java** / **Java**）

**考点**：所有方法返回**新字符串**、原串不动；substring(0,1) 取第一个字符（[0,1) 闭开区间）；拼接用 `+`。
**刁钻用例**：`upFirst("")` → `substring(0,1)` 越界崩——先判空；`trimIt("  a  b  ")` → `a  b`（中间空格不动）。

## 题 4 答案（字符统计）

```java
class SearchUtil {
    public static int countChar(String s, char c) {
        int count = 0;
        for (int i = 0; i < s.length(); i++) {
            if (s.charAt(i) == c) {   // char 是基本类型，用 ==
                count++;
            }
        }
        return count;
    }
}
```

（main 输出：**3** / **2** / **0**）

**考点**：for 遍历字符串的标准模板（`i < s.length()`，别写 `<=`）；char 用 `==` 没问题。
**进阶一行版**（理解即可）：`return s.length() - s.replace(c + "", "").length();`
**刁钻用例**：`countChar("", 'a')` → 0（循环一次不执行，不会崩）。

## 题 5 答案（反转字符串）

```java
class ReverseUtil {
    public static String reverse(String s) {
        String result = "";
        for (int i = s.length() - 1; i >= 0; i--) {  // 从最后一个字符往前
            result = result + s.charAt(i);           // 边取边拼
        }
        return result;
    }
}
```

（main 输出：**cba** / **olleH** / **（空串）**）

**考点**：倒序遍历模板（`i = length-1` 到 `0`）；空串循环不执行，天然安全。
**刁钻用例**：`reverse(null)` → 崩（对 null 调 length()）；超长字符串用 `+` 拼会慢（面试点：应改用 `StringBuilder`）。
