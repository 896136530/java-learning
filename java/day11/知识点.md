# Day 11 知识点：String 字符串（面试最爱考）

> 前提：Day 10 Object 三件套过关。今天上"字符串"——Java 里用到最多的类型，面试官最爱在这里挖坑。

## 1. String 是类，不是基本类型

- `int`/`double`/`boolean` 是基本类型；String 是**引用类型**（一个类）
- 但写法太简单：`String s = "你好";`——所以很多人忘了它是类
- **两种创建方式**：
  ```java
  String a = "hello";             // 字面量 → 放"字符串常量池"
  String b = new String("hello"); // new → 堆里的新对象
  System.out.println(a == b);     // false！一个在常量池，一个在堆
  ```
- 常量池规则（背）：**相同的字面量只存一份**——`"hello"` 写 100 次也只有一个对象

## 2. 字符串不可变（面试必问）

- **String 一旦创建，内容永远不能改**
- 你以为改了，其实是**生成了新字符串**，原串原封不动：
  ```java
  String s = "abc";
  String t = s.toUpperCase(); // "ABC" 是全新字符串
  System.out.println(s);      // abc（s 没变！）
  ```
- 为什么设计成不可变？（答出这两条就是加分）：
  1. **安全**：字符串到处传，不用怕有人在背后改它（文件名、密码都靠它）
  2. **常量池复用**：反正不会变，所有人共用一份，省内存

## 3. 比较：永远 equals，别 ==（Day 10 复习 + 实战）

- 比内容：`a.equals(b)`；忽略大小写：`a.equalsIgnoreCase(b)`
- `==` 只能用于：基本类型比数值，或确实要"是不是同一个对象"
- 经典坑：`new String("hi") == "hi"` → **false**（一个在堆、一个在常量池）

## 4. 常用方法表（这页背下来，天天用）

| 方法 | 作用 | 例子 |
|---|---|---|
| `length()` | 字符个数 | `"Java".length()` → 4 |
| `charAt(i)` | 取第 i 个字符（**从 0 开始**）| `"Java".charAt(0)` → J |
| `toUpperCase()` / `toLowerCase()` | 转大写 / 转小写 | `"aB".toUpperCase()` → AB |
| `trim()` | 去掉首尾空格 | `" a ".trim()` → a |
| `substring(a,b)` | 截取 [a, b)（含头不含尾）| `"hello".substring(1,3)` → el |
| `indexOf(s)` | 找子串位置，找不到返回 -1 | `"hello".indexOf("ll")` → 2 |
| `contains(s)` | 是否包含 | `"hello".contains("ell")` → true |
| `startsWith(s)` / `endsWith(s)` | 以…开头 / 以…结尾 | `"abc".startsWith("ab")` → true |
| `replace(a,b)` | 替换 | `"a-b".replace("-","+")` → a+b |
| `split(s)` | 按分隔符拆成数组 | `"a,b".split(",")` → {a, b} |

> 脑子里存两张图：**下标从 0 开始**（charAt/substring 都适用）；**substring 是半开区间 [a,b)**。

## 5. 字符串拼接

```java
String s = "你好" + "，" + "世界";   // 最简单，直接用 +
System.out.println("长度：" + 5);    // "长度：5"——任何类型 + 字符串 = 字符串
char ch = 'A';
String t = ch + "";                  // char 想变成字符串，记得拼个空串
```

- 性能提示（面试加分）：**循环里大量拼接用 `StringBuilder`**（Day 17 讲），用 `+` 会不停造新对象

## 6. 常见坑清单（背）

1. **比内容用 equals**，`==` 是地址（常量池的坑）
2. `charAt(越界)` → `StringIndexOutOfBoundsException`——最后一个字符是 `length()-1`
3. `substring` 想截到末尾，可以省略终点：`s.substring(3)` 表示从 3 到结尾
4. **字符串方法不会改原串**——要接住返回值：`s = s.toUpperCase();`
5. 空串 `""` 和 `null` 不一样：`"".length()` 是 0；`null.length()` 直接崩
6. 中文没有大小写，`toUpperCase` 对中文无效（别拿它做中文处理）

> **String = 不可变的字符序列：比内容用 equals，下标从 0 开始，方法返回新串、原串不动。**
