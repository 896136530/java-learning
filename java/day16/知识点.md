# Day 16 知识点：泛型（Generic `<T>`）

> 前提：集合（HashMap/HashSet/Queue…）都用过 `<String>`、`<Integer>`，今天把尖括号讲透——**面试必问，写框架基础**。

## 1. 为什么要有泛型？

```java
// 没有泛型：得强转，转错了运行时才炸
ArrayList list = new ArrayList();
list.add("hello");
String s = (String) list.get(0);   // 强转，麻烦

// 有泛型：类型写死在尖括号里，错了编译期就报
ArrayList<String> list2 = new ArrayList<>();
list2.add("hello");
String s2 = list2.get(0);          // 不用转，安全
```

**泛型 = 把"类型"当参数传**——容器要装什么类型，用的时候尖括号里告诉它，编译期就检查，杜绝运行时 ClassCastException。

## 2. 泛型类：自带 `<T>` 的类

```java
class Box<T> {          // T 是"类型参数"，用的时候才定具体类型
    private T value;

    public void set(T v) {
        this.value = v;
    }

    public T get() {
        return value;
    }
}
```

使用：
```java
Box<String> box = new Box<>();   // T = String
box.set("你好");
String s = box.get();            // 拿回来就是 String，不用强转

Box<Integer> num = new Box<>();  // T = Integer
num.set(42);
```

> 新代码里 `new Box<>()` 可以省略尖括号里面的类型（菱形语法），Java 自己推断。

## 3. 泛型方法：方法自己的 `<T>`

```java
public static <T> T first(T[] arr) {    // <T> 写在返回值类型前面！
    return arr[0];
}
```

```java
String[] s = {"a", "b"};
String f1 = first(s);        // 自动推断 T = String
Integer[] n = {5, 6};
Integer f2 = first(n);       // 自动推断 T = Integer
```

**同一个方法，参数类型随便换**——这就是"泛型"两个字的意思。

## 4. 约定俗成的字母

| 字母 | 习惯含义 |
|---|---|
| `T` | Type，泛指类型 |
| `E` | Element，集合元素 |
| `K` / `V` | Key / Value，键值对 |
| `N` | Number，数字 |

写的时候跟主流一致，面试官看着舒服。

## 5. 面试必背三句话

1. **好处**：类型安全（编译期检查）+ 省去强转 + 代码复用（一套逻辑多种类型）
2. **泛型类**：`class Box<T>`；**泛型方法**：`<T>` 写在返回值前
3. **类型擦除**（一句话带过）：JVM 运行时不认识泛型，编译后 `<T>` 会被擦掉换成 Object——知道这个概念面试就够
