## 题目详情

### 题 1：泛型盒（Box\<T\>）
写一个类：
- **类 `Box<T>`**：一个私有字段 `T value`，两个方法 `void set(T v)` 和 `T get()`
- main 里（已写好）：`Box<String>` 装"你好"，`Box<Integer>` 装 42
- 期望输出：
  ```
  你好
  42
  ```
- 💡：类名后跟 `<T>`，字段、方法参数、返回值都用 T——一个盒子装什么由使用方决定

### 题 2：双泛型对（Pair\<K,V\>）
写一个类：
- **类 `Pair<K,V>`**：两个私有字段 `K key` 和 `V value`，方法 `void set(K k, V v)`、`K getKey()`、`V getValue()`
- main 里（已写好）：`Pair<String,Integer>` 存"小明"和 18
- 期望输出：
  ```
  小明
  18
  ```
- 💡：两个类型参数，逗号隔开——K 和 V 各管各的

### 题 3：泛型方法 first
写一个类：
- **类 `FirstEl`**：`static <T> T first(T[] arr)`——返回数组第一个元素
- main 里（已写好）：`String[]` 传"a"、"Integer[]" 传 5
- 期望输出：
  ```
  a
  5
  ```
- 💡：`<T>` 写在 static 和返回值类型之间——方法自己带类型参数

### 题 4：泛型方法 printAll
写一个类：
- **类 `Printer`**：`static <T> void printAll(T[] arr)`——把数组元素**空格隔开**打印成一行（结尾不要多余空格）
- main 里（已写好）：`{"猫","狗","鸟"}`
- 期望输出：
  ```
  猫 狗 鸟
  ```
- 💡：循环里打印，注意最后一个元素后面不加空格

### 题 5：泛型方法 swap
写一个类：
- **类 `Swapper`**：`static <T> void swap(T[] arr, int i, int j)`——交换数组里两个位置的元素
- main 里（已写好）：`{1,2,3}` 交换下标 0 和 2，再打印
- 期望输出：
  ```
  3 2 1
  ```
- 💡：交换要一个临时变量；泛型方法里 `T temp` 存中间值
