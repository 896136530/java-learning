## 题 1 答案（泛型盒）

```java
class Box<T> {
    private T value;

    public void set(T v) {
        this.value = v;
    }

    public T get() {
        return value;
    }
}
```

（main 输出：**你好** / **42**——同一个类，装 String 是 String，装 Integer 是 Integer）

**考点**：泛型类的定义——`class Box<T>`，T 贯穿字段/参数/返回值。
**刁钻用例**：不写 `Box<String>` 直接 `new Box()`（原始类型）也能跑，但丢了类型检查，IDE 会警告——永远带尖括号。

## 题 2 答案（双泛型对）

```java
class Pair<K, V> {
    private K key;
    private V value;

    public void set(K k, V v) {
        this.key = k;
        this.value = v;
    }

    public K getKey() {
        return key;
    }

    public V getValue() {
        return value;
    }
}
```

（main 输出：**小明** / **18**）

**考点**：多个类型参数逗号隔开，各司其职。
**刁钻用例**：`Pair<String, String>` 两个都传 String 也行——K、V 只是代号，用什么类型使用方定。

## 题 3 答案（泛型方法 first）

```java
class FirstEl {
    public static <T> T first(T[] arr) {
        return arr[0];
    }
}
```

（main 输出：**a** / **5**）

**考点**：**`<T>` 写在 static 和返回值之间**——泛型方法的关键位置。
**刁钻用例**：空数组 `first(new String[0])` → `ArrayIndexOutOfBoundsException`——泛型方法不背锅，是数组越界；调用 `first(s)` 时 Java 自动推断 T=String，不用手写。

## 题 4 答案（泛型方法 printAll）

```java
class Printer {
    public static <T> void printAll(T[] arr) {
        for (int i = 0; i < arr.length; i++) {
            if (i > 0) {
                System.out.print(" ");
            }
            System.out.print(arr[i]);
        }
        System.out.println();
    }
}
```

（main 输出：**猫 狗 鸟**）

**考点**：**`void` 也是"返回值类型"**——`<T> void` 照样成立；"最后不加空格"用 `if (i > 0)` 套路。
**刁钻用例**：空数组 → 什么都不打印就换行（不崩）；一个元素 → 就打印它自己。

## 题 5 答案（泛型方法 swap）

```java
class Swapper {
    public static <T> void swap(T[] arr, int i, int j) {
        T temp = arr[i];
        arr[i] = arr[j];
        arr[j] = temp;
    }
}
```

（main 输出：**3 2 1**——1 和 3 换了位置）

**考点**：交换必须**临时变量**（`T temp`）；泛型方法里 T 能当普通类型用。
**刁钻用例**：`swap(nums, 0, 0)` 自己换自己 → 结果不变，没问题；i 或 j 越界 → 抛异常（调用方保证，方法不管）。
