**① `findByScore(min, max)`（9 分）**
要求：分数在 `[min, max]` 闭区间，**按分数升序**，返回 `List<Student>`。
提示：`WHERE score BETWEEN #{min} AND #{max}`。
达标：传入 80、100 → 5 人，顺序 `82, 88, 90, 95, 100`。

**② `insert(student)`（9 分）**
要求：插入 `name / score / cls_id`，插入后 **MyBatis 把自增主键回填到 `student.id`**。
提示：`<insert id="insert" useGeneratedKeys="true" keyProperty="id">`。
达标：插入"测试同学 77 1 班" → `影响行数=1，回填的 id=9`。

**③ `updateScore(id, score)`（9 分）**
要求：改一个学生的分数，返回影响行数。
提示：`<update>` 标签；改不存在的 id 会返回 0（正常）。
达标：`updateScore(1, 99)` → `影响行数=1，现在 id=1 的分数=99`。

**④ `findWithClass(id)`（9 分）**
要求：按 id 查一个学生，**同时带出班级信息**（联表 + `association`）。
提示：照抄 `findAllWithClass` 的 `SELECT` 和 `resultMap`，只把 `ORDER BY` 换成 `WHERE s.id = #{id}`。
达标：`findWithClass(2)` → `Student{id=2, name='李四', score=95, clsId=1, 班级=一班/王老师}`。

**⑤ `deleteById(id)`（9 分）**
要求：按 id 删，返回影响行数；删不存在的行返回 0，**不要抛异常**。
提示：`<delete>` 标签。
