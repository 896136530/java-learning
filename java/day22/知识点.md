## 一、两大门派（先把地图刻进脑子）

```
Collection（单列：一列数据）
├── List（有序、可重复）: ArrayList / LinkedList
└── Set（无序、不重复）: HashSet / TreeSet
Map（双列：键值对 key→value）
├── HashMap（快，但无序）★ 面试最爱问
└── TreeMap（有序，按键排序，慢一点）
```

**口诀**：List 排队、Set 拒绝插队、Map 成双成对。

## 二、HashMap 原理（背下来，面试默写）

- 底层 = **数组 + 链表**（Java 8+ 链表太长会转红黑树，知道名字即可）
- `put(k, v)` 干三件事：① 用 `k.hashCode()` 算一个"桶号" ② 落到数组的桶里 ③ 桶里已经有元素就 `equals` 逐个比——相同就**覆盖**，不同就**挂链表**
- `get(k)` 也是先算桶号，进去用 `equals` 找
- **所以 HashSet 其实就是 HashMap**（value 全为同一个占位对象）

**面试三句话**：
1. HashMap 底层是数组加链表，靠 hashCode 定位桶、equals 判相等；
2. 重写 equals 必须重写 hashCode（否则同一个对象 get 不到）；
3. HashMap 无序，要顺序就用 LinkedHashMap 或 TreeMap。

## 三、TreeMap / TreeSet（排序世家）

- TreeMap **按键自动排序**，TreeSet 元素自动排序
- 排序规则两种来源：
  1. **自然排序 Comparable**：让类实现 `Comparable<T>`，重写 `int compareTo(T o)`——"我是谁、我跟谁比、比完返回正负零"
  2. **定制排序 Comparator**：单独写一个"裁判类"实现 `Comparator<T>`，重写 `int compare(T a, T b)`——不改原类也能换规则
- **返回值的意义（统一）**：负数=前者小/在前，零=相等（会覆盖！），正数=前者大/在后

**口诀**：`compareTo 返回负 → 我排前面`。

## 四、复杂度速查（写代码前先想用哪个）

| 操作 | ArrayList | LinkedList | HashMap | TreeMap |
|---|---|---|---|---|
| 按位置/按键查 | O(1) | O(n) | **O(1)** | O(log n) |
| 插入/删除 | O(n)（要挪） | O(1)（改指针） | **O(1)** | O(log n) |
| 有序遍历 | 插入序 | 插入序 | 无序 | **有序** |

**选型口诀**：要快用 HashMap；要排序用 TreeMap；要排队用 List。

## 五、遍历姿势（背三种）

```java
// ① keySet：拿所有钥匙
for (String k : map.keySet()) { System.out.println(k + "=" + map.get(k)); }
// ② entrySet：一次性拿钥匙+值（面试推荐，少查一次）
for (Map.Entry<String, Integer> e : map.entrySet()) { ... }
// ③ values：只要值
for (Integer v : map.values()) { ... }
```
