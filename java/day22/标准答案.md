## Ex1：HashMap 数水果

**考点**：HashMap 计数套路 `getOrDefault`；`split(" ")` 切词。

```java
class FruitCounter {
    static int count(String sentence, String word) {
        Map<String, Integer> map = new HashMap<>();
        for (String w : sentence.split(" ")) {
            map.put(w, map.getOrDefault(w, 0) + 1);
        }
        return map.getOrDefault(word, 0);
    }
}
```

- 期望输出：`apple 出现 3 次`
- 易错：忘了 `getOrDefault(w, 0)` 会 NPE（第一次 put 的是 null）

## Ex2：HashMap 增删改查

**考点**：`put` 同 key 即覆盖（天然就是 update）；`get` 不到返回 null；用 `Integer` 包装判断"不存在"。

```java
class ScoreBook {
    Map<String, Integer> map = new HashMap<>();

    void addScore(String name, int score) {
        map.put(name, score);
    }

    void updateScore(String name, int score) {
        map.put(name, score);   // put 相同的 key 就是覆盖
    }

    Integer getScore(String name) {
        return map.get(name);   // 不存在返回 null
    }
}
```

- 期望输出：
  ```
  张三 当前成绩：95
  小明 不存在
  ```
- 易错：`getScore` 返回 `int` 会 NPE（自动拆箱炸），返回 `Integer` 最稳

## Ex3：TreeMap 自动排序

**考点**：TreeMap 按键自动升序，插入顺序无所谓。

```java
class StudentMap {
    static TreeMap<Integer, String> build() {
        TreeMap<Integer, String> map = new TreeMap<>();
        map.put(102, "李四");
        map.put(101, "张三");
        map.put(103, "王五");
        return map;
    }
}
```

- 期望输出：
  ```
  101 张三
  102 李四
  103 王五
  ```
- 易错：用 `HashMap` 则顺序不确定，判题必挂

## Ex4：Comparable 自然排序

**考点**：`Comparable<T>` + `compareTo`，分数降序 = 把 this 和 o 倒过来比。

```java
class Student implements Comparable<Student> {
    String name;
    int score;

    Student(String name, int score) {
        this.name = name;
        this.score = score;
    }

    @Override
    public int compareTo(Student o) {
        return Integer.compare(o.score, this.score);   // 分数高的排前面
    }
}
```

- 期望输出：
  ```
  李四 95
  张三 88
  王五 76
  ```
- 易错：`compareTo` 写成 `this.score - o.score` 就是升序，方向反了
- 加分：用 `Integer.compare` 代替裸减法，防溢出

## Ex5：Comparator 定制排序

**考点**：`Comparator<T>` 的 `compare`；长度相等再比字典序（`String.compareTo`）。

```java
class Student {
    String name;
    int score;

    Student(String name, int score) {
        this.name = name;
        this.score = score;
    }
}

class NameLenComparator implements Comparator<Student> {
    @Override
    public int compare(Student a, Student b) {
        int len = Integer.compare(a.name.length(), b.name.length());
        if (len != 0) {
            return len;
        }
        return a.name.compareTo(b.name);
    }
}
```

- 期望输出：
  ```
  李四
  王五
  张三丰
  欧阳修
  ```
- 易错：只比长度不比字典序，李四/王五（同 2 字）顺序就不可控
- 结论对比：Ex4 是"类自己会排序"（Comparable），Ex5 是"外挂裁判排序"（Comparator）——**面试就爱问这个区别**

## Review：排行榜全家桶

**考点**：TreeMap（学号→学生）取值后按分数排序；`Map.Entry`；`List.sort` + lambda 比较器；取前 3 名。

```java
class Student {
    String name;
    int score;

    Student(String name, int score) {
        this.name = name;
        this.score = score;
    }
}

class RankBoard {
    static void printTop3(TreeMap<Integer, Student> students) {
        List<Map.Entry<Integer, Student>> list = new ArrayList<>(students.entrySet());
        list.sort((a, b) -> b.getValue().score - a.getValue().score);   // 分数降序
        for (int i = 0; i < Math.min(3, list.size()); i++) {
            Map.Entry<Integer, Student> e = list.get(i);
            System.out.println("第" + (i + 1) + "名：" + e.getValue().name + " " + e.getValue().score);
        }
    }
}
```

- 期望输出：
  ```
  第1名：钱七 100
  第2名：李四 95
  第3名：张三 88
  ```
- 易错：TreeMap 按键排序——成绩不是 key，必须取出来重排（换个树或用 list.sort），直接遍历 map 出来的是学号序
- 加分：分数并列时再加"学号小的排前"兜底
