## Ex1：HashMap 数水果（初体验）

修 `countApple(String sentence)`：统计句子里每种水果的个数，返回 `apple` 出现了几次。

- 句子固定：`"apple banana apple orange apple banana"`（3 个 apple）
- 期望输出：`apple 出现 3 次`
- 提示：`String.split(" ")` 切成单词 → HashMap<String,Integer> 计数 → `get("apple")`

## Ex2：HashMap 增删改查（成绩本）

修 `ScoreBook` 的三个方法：`addScore(name, score)`、`updateScore(name, score)`、`getScore(name)`。

- main 会依次：加 张三=88 → 改成 95 → 查张三 → 查"小明"
- 期望输出：
  ```
  张三 当前成绩：95
  小明 不存在
  ```
- 提示：查不存在的 key 用 `containsKey` 判断；`get` 不到会返回 null

## Ex3：TreeMap 自动排序（按学号升序）

修 `buildMap()`：把三个学生放进 TreeMap（**学号做 key**，姓名做 value），main 会按 map 的迭代顺序打印。

- 插入顺序故意打乱：`李四(102)` `张三(101)` `王五(103)`
- 期望输出（TreeMap 按学号自动升序）：
  ```
  101 张三
  102 李四
  103 王五
  ```

## Ex4：Comparable 自然排序（按分数降序）

写 `Student` 类：字段 `name`、`score`，实现 `Comparable<Student>`，**分数高的排前面**。

- main 造 3 个学生（张三88 李四95 王五76）装进 TreeSet 打印
- 期望输出：
  ```
  李四 95
  张三 88
  王五 76
  ```
- 提示：`compareTo` 返回 `o.score - this.score`（倒过来就是降序）

## Ex5：Comparator 定制排序（按姓名长度）

写 `NameLenComparator implements Comparator<Student>`：**姓名短的排前面**，一样长再按字典序。

- 数据：`王五(王五=2字)`、`张三丰(3字)`、`李四(2字)`、`欧阳修(3字)`
- 期望输出：
  ```
  李四
  王五
  张三丰
  欧阳修
  ```
- 提示：`Integer.compare(a.name.length(), b.name.length())`，长度相等时再 `compareTo` 姓名

## Review：排行榜全家桶

修 `RankBoard`：二叉树……噢不，用 TreeMap 实现"学号→成绩"，再用 `entrySet` 按**成绩从高到低**排出前 3 名。

- 数据：101 张三88 / 102 李四95 / 103 王五76 / 104 赵六60 / 105 钱七100
- 期望输出：
  ```
  第1名：钱七 100
  第2名：李四 95
  第3名：张三 88
  ```
- 提示：TreeMap 按键有序，要按值排 → 遍历时先把 (成绩, 学号) 放进另一个 TreeMap（成绩做 key，自动降序思路见 Ex4）
