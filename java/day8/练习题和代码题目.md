## 题目详情

### 题 1：向上转型 + 动态绑定（Animal + Dog）

写两个类：
- **父类 `Animal`**：属性 `String name`；构造 `Animal(String name)`；方法 `sound()` 打印 `XX发出声音`
- **子类 `Dog`**：`extends Animal`，**重写** `sound()`（加 @Override）打印 `XX汪汪叫`
- `main` 里（已写好）：`Animal a = new Dog("旺财");` → 调用 `a.sound()`
- 期望输出：
  ```
  旺财汪汪叫
  ```
- 💡思考：`a` 的类型明明是 Animal，为什么输出的不是"旺财发出声音"？（口诀：运行看右边！）

### 题 2：多态参数（Fruit + Apple/Orange）

写三个类：
- **父类 `Fruit`**：属性 `String name`；构造 `Fruit(String name)`；方法 `info()` 打印 `我是水果：XX`
- **子类 `Apple`**：`extends Fruit`，**重写** `info()` 打印 `我是苹果：XX`
- **子类 `Orange`**：`extends Fruit`，重写 `info()` 打印 `我是橘子：XX`
- `main` 里（已写好）：`show(new Apple("红富士"));` 和 `show(new Orange("甜橙"));`，`show(Fruit f)` 的参数**用父类类型**，方法体里调 `f.info()`
- 期望输出：
  ```
  我是苹果：红富士
  我是橘子：甜橙
  ```
- 💡思考：`show()` 方法只写了一份，为什么传苹果就输出苹果、传橘子就输出橘子？

### 题 3：多态数组（Shape + Circle/Rect）

写三个类：
- **父类 `Shape`**：方法 `area()` 返回 `0.0`
- **子类 `Circle`**：属性 `double radius`；构造 `Circle(double radius)`；重写 `area()` 返回 `3.14 * radius * radius`
- **子类 `Rect`**：属性 `double w, h`；构造 `Rect(double w, double h)`；重写 `area()` 返回 `w * h`
- `main` 里（已写好）：建 `Shape[]` 数组，装一个圆（半径 5）和一个矩形（4×6），for 循环遍历，打印每个的 `area()`
- 期望输出：
  ```
  面积：78.5
  面积：24.0
  ```
- 💡思考：数组的类型是 Shape，遍历时调用的是同一个 `area()`，为什么一个算圆、一个算矩形？

### 题 4：instanceof + 向下转型（Person + Student）

写两个类：
- **父类 `Person`**：属性 `String name`；构造 `Person(String name)`；方法 `introduce()` 打印 `我是人，我叫XX`
- **子类 `Student`**：`extends Person`，构造里 `super(name)`；**新方法** `study()` 打印 `XX在学习`（注意：Student 不重写 introduce，直接用父类的）
- `main` 里（已写好）：
  1. `Person p = new Student("小明");`（向上转型）
  2. 打印 `p instanceof Student` 的结果
  3. `p.introduce()`（父类方法，直接能调）
  4. `if (p instanceof Student)` 判断为真后，**向下转型** `Student s = (Student) p;` 再调 `s.study()`
- 期望输出：
  ```
  p 是学生？true
  我是人，我叫小明
  小明在学习
  ```
- 💡思考：如果去掉 `instanceof` 判断直接 `(Student) p`，这道题能跑吗？（能跑，但这是坏习惯；等以后 p 里万一装的是别的类，直接崩溃）

### 题 5：综合——动物园喂食员（Bird + Penguin/Eagle）

写三个类：
- **父类 `Bird`**：属性 `String name`；构造 `Bird(String name)`；方法 `eat()` 打印 `XX在吃东西`；方法 `fly()` 打印 `XX在飞`
- **子类 `Penguin`**：重写 `eat()` 打印 `XX在吃鱼`；重写 `fly()` 打印 `XX不会飞`（企鹅真的不会飞）
- **子类 `Eagle`**：重写 `eat()` 打印 `XX在吃肉`；重写 `fly()` 打印 `XX飞得又高又快`
- `main` 里（已写好）：`feed(new Penguin("小企鹅"));` 和 `feed(new Eagle("大鹏"));`，`feed(Bird b)` 方法体里先 `b.eat()` 再 `b.fly()`
- 期望输出：
  ```
  小企鹅在吃鱼
  小企鹅不会飞
  大鹏在吃肉
  大鹏飞得又高又快
  ```
- 💡思考：喂食员只写了一个 `feed` 方法，喂企鹅和喂老鹰用的是同一份代码。以后动物园加一只"孔雀"，需要改 `feed` 吗？（不用！——这就是多态"扩展容易"的好处）
