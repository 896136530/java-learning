## 题 1 答案（向上转型 + 动态绑定）

```java
class Animal {
    String name;

    Animal(String name) {
        this.name = name;
    }

    void sound() {
        System.out.println(name + "发出声音");
    }
}

class Dog extends Animal {
    Dog(String name) {
        super(name);
    }

    @Override
    void sound() {
        System.out.println(name + "汪汪叫");
    }
}
```

（main：`Animal a = new Dog("旺财");` → `a.sound()` 输出 **旺财汪汪叫**）

**考点**：向上转型后调方法，**编译看左边**（Animal 有 sound，编译通过），**运行看右边**（实际是 Dog → 汪汪叫）。

**刁钻用例**：
- `a.bark()` → **编译报错**：左边是 Animal，没有 bark（即使右边是 Dog 也不行）
- 想看 `name` 属性：`a.name` 输出的是 **Animal 的 name**（属性不参与多态）

## 题 2 答案（多态参数）

```java
class Fruit {
    String name;

    Fruit(String name) {
        this.name = name;
    }

    void info() {
        System.out.println("我是水果：" + name);
    }
}

class Apple extends Fruit {
    Apple(String name) {
        super(name);
    }

    @Override
    void info() {
        System.out.println("我是苹果：" + name);
    }
}

class Orange extends Fruit {
    Orange(String name) {
        super(name);
    }

    @Override
    void info() {
        System.out.println("我是橘子：" + name);
    }
}
```

（main：`show(new Apple("红富士"))` → **我是苹果：红富士**；`show(new Orange("甜橙"))` → **我是橘子：甜橙**）

**考点**：`show(Fruit f)` 的参数是父类——**多态参数**，传谁进去就调用谁重写后的 info()。这是多态最大的好处：**写一次，通吃所有子类**。

## 题 3 答案（多态数组）

```java
class Shape {
    double area() {
        return 0.0;
    }
}

class Circle extends Shape {
    double radius;

    Circle(double radius) {
        this.radius = radius;
    }

    @Override
    double area() {
        return 3.14 * radius * radius;
    }
}

class Rect extends Shape {
    double w;
    double h;

    Rect(double w, double h) {
        this.w = w;
        this.h = h;
    }

    @Override
    double area() {
        return w * h;
    }
}
```

（main：`Shape[] shapes = { new Circle(5), new Rect(4, 6) };` 遍历 → **面积：78.5** / **面积：24.0**）

**考点**：**多态数组**——数组类型是父类 Shape，却能装不同类型的子类；遍历时同一个 `area()`，每个对象自己算自己的（圆算圆，矩形算矩形）。

## 题 4 答案（instanceof + 向下转型）

```java
class Person {
    String name;

    Person(String name) {
        this.name = name;
    }

    void introduce() {
        System.out.println("我是人，我叫" + name);
    }
}

class Student extends Person {
    Student(String name) {
        super(name);
    }

    void study() {
        System.out.println(name + "在学习");
    }
}
```

（main 输出：**p 是学生？true** / **我是人，我叫小明** / **小明在学习**）

**考点**：
1. `p.introduce()` 能直接调——父类方法，编译看左边 OK
2. `study()` 是 Student **独有**的方法，父类引用调不了 → 必须**向下转型** `(Student) p`
3. 转型前先 `instanceof` 判断，**防止 ClassCastException**

**刁钻用例**：
- `Person p2 = new Person("老李");` → `p2 instanceof Student` 是 **false**，不会崩溃
- 如果跳过判断直接 `Student s = (Student) p2;` → **运行时崩溃**：ClassCastException（类型装不进去）
- 以后写代码的原则：**向下转型一定配 instanceof**

## 题 5 答案（综合：动物园喂食员）

```java
class Bird {
    String name;

    Bird(String name) {
        this.name = name;
    }

    void eat() {
        System.out.println(name + "在吃东西");
    }

    void fly() {
        System.out.println(name + "在飞");
    }
}

class Penguin extends Bird {
    Penguin(String name) {
        super(name);
    }

    @Override
    void eat() {
        System.out.println(name + "在吃鱼");
    }

    @Override
    void fly() {
        System.out.println(name + "不会飞");
    }
}

class Eagle extends Bird {
    Eagle(String name) {
        super(name);
    }

    @Override
    void eat() {
        System.out.println(name + "在吃肉");
    }

    @Override
    void fly() {
        System.out.println(name + "飞得又高又快");
    }
}
```

（main 输出：**小企鹅在吃鱼** / **小企鹅不会飞** / **大鹏在吃肉** / **大鹏飞得又高又快**）

**考点（综合）**：继承 + 重写 + 多态参数一条龙。`feed(Bird b)` 只写一份，喂企鹅、喂老鹰、将来喂孔雀都用它——**不用改现有代码**（开闭原则的雏形）。这就是多态最实用的价值。
