# Day 25 标准答案（MySQL 基础）

> 本机 MySQL 8.4.5 实测通过（root/root，库 `day25`），输出与各题期望一致。
> 用法：把每题的 SQL 填进对应的 `Ex*.sql` 中间空位，再双击 `运行SQL.bat`。

## Ex1：建库建表

```sql
DROP DATABASE IF EXISTS day25;
CREATE DATABASE day25 DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;
USE day25;
CREATE TABLE student (
  id         INT PRIMARY KEY AUTO_INCREMENT,
  name       VARCHAR(20) NOT NULL,
  score      INT DEFAULT 0,
  class_name VARCHAR(20)
) DEFAULT CHARSET = utf8mb4;
```

**实测输出**：

```
Database (day25)
day25
Tables_in_day25
student
Field	Type	Null	Key	Default	Extra
id	int	NO	PRI	NULL	auto_increment
name	varchar(20)	NO		NULL	
score	int	YES		0	
class_name	varchar(20)	YES		NULL	
```

- 易错：`CREATE DATABASE` 忘了 utf8mb4 → 后面中文变 `??`；`id` 忘了 `AUTO_INCREMENT` → 每次插入都得手写 id

## Ex2：插入数据

```sql
INSERT INTO student (name, score, class_name) VALUES
('张三', 88, '一班'),
('李四', 95, '一班'),
('王五', 76, '一班');
```

**实测输出**：

```
id	name	score	class_name
1	张三	88	一班
2	李四	95	一班
3	王五	76	一班
人数
3
```

- 易错：字符串用双引号（MySQL 里会被当成列名）→ 报 *Unknown column '张三'*
- 加分理解：一条 INSERT 带多组 VALUES 比写三条 INSERT 快（少一次网络往返），项目里批量导入就这么干

## Ex3：条件查询

```sql
SELECT name, score FROM student
WHERE class_name = '一班' AND score >= 80
ORDER BY score DESC
LIMIT 2;
```

**实测输出**：

```
name	score
李四	95
张三	88
```

- 易错：`LIMIT` 写到 `ORDER BY` 前面 → 语法错；`DESC` 忘写 → 变成升序（张三在前）
- 加分理解：**先 WHERE 筛、再 ORDER BY 排、最后 LIMIT 取**——数据库就是这么执行的，也决定了你该给哪个字段建索引（Day26 会讲）

## Ex4：更新与删除

```sql
UPDATE student SET score = score + 5 WHERE class_name = '一班';
DELETE FROM student WHERE score < 60;
```

**实测输出**：

```
id	name	score	class_name
1	张三	93	一班
2	李四	100	一班
3	王五	81	一班
4	赵六	60	二班
5	钱七	100	二班
7	周九	82	三班
剩余人数
6
```

- 看两个细节：一班的 88/95/76 → **93/100/81**（用 `score = score + 5` 算的）；孙八的 id=6 消失，剩 6 人
- 易错 ⚠️：**WHERE 忘写** → `UPDATE student SET score = score + 5;` 全班都加 5，`DELETE FROM student WHERE score < 60` 写成 `DELETE FROM student;` **整张表清空**（生产环境的事故 90% 出自这两条语句）
- 加分理解：真实项目里改数据前先 `SELECT` 一遍同样的 WHERE（"先看看要动哪些行"），确认无误再改

## Ex5：分组统计

```sql
SELECT class_name AS 班级,
       COUNT(*)   AS 人数,
       ROUND(AVG(score), 2) AS 平均分,
       MAX(score) AS 最高分
FROM student
GROUP BY class_name
ORDER BY AVG(score) DESC;
```

**实测输出**：

```
班级	人数	平均分	最高分
一班	3	86.33	95
二班	2	80.00	100
三班	2	63.50	82
```

- 易错 ①：`AVG(score)` 不 `ROUND` → 输出一长串小数
- 易错 ②：`SELECT class_name, ... ` 但 `GROUP BY` 里没写 `class_name` → 语法错（MySQL 8 默认开启 ONLY_FULL_GROUP_BY）
- 加分理解：`ROUND(AVG(score),2)` 只改**显示**；真要存成两位小数用 `DECIMAL(5,2)` 字段类型

## 🎯 复习：多表查询（JOIN）

```sql
SELECT s.name AS 姓名, s.score AS 分数, c.class_name AS 班级, c.teacher AS 班主任
FROM student s
JOIN class_info c ON s.class_name = c.class_name
ORDER BY s.score DESC;

SELECT c.class_name AS 班级, COUNT(*) AS 人数, c.teacher AS 班主任
FROM student s
JOIN class_info c ON s.class_name = c.class_name
GROUP BY c.class_name, c.teacher
ORDER BY COUNT(*) DESC, c.class_name;
```

**实测输出**：

```
姓名	分数	班级	班主任
钱七	100	二班	李老师
李四	95	一班	王老师
张三	88	一班	王老师
周九	82	三班	张老师
王五	76	一班	王老师
赵六	60	二班	李老师
孙八	45	三班	张老师
班级	人数	班主任
一班	3	王老师
三班	2	张老师
二班	2	李老师
```

- 易错 ①：**漏写 `ON`** → 21 行的笛卡尔积
- 易错 ②：第二条里 `SELECT c.teacher` 却没在 `GROUP BY` 写它 → 报错（`GROUP BY c.class_name, c.teacher` 才对）
- 易错 ③：排序想"人数降序、同人数按班级名升序" → `ORDER BY COUNT(*) DESC, c.class_name`（多关键字用逗号）
- 加分理解：为什么"三班"排在"二班"前面？因为两人并列时按班级名升序，`三`(U+4E09) < `二`(U+4E8C)

## 六题一句话总复习

| 题 | 语句 | 一句话 |
|---|---|---|
| Ex1 | `CREATE DATABASE / TABLE` | 库要 utf8mb4，主键要自增 |
| Ex2 | `INSERT` | 一条插多行，id 不用写 |
| Ex3 | `SELECT + WHERE/ORDER BY/LIMIT` | 先筛、再排、最后取 |
| Ex4 | `UPDATE / DELETE` | **WHERE 就是命**（忘写 = 全表遭殃）|
| Ex5 | `GROUP BY + COUNT/AVG/MAX` | 先分堆，每堆算一次聚合 |
| Review | `JOIN` | ON 是接头暗号，漏了就是笛卡尔积 |

## 附：两句面试可背

1. **CRUD 四句话**：`SELECT` 查、`INSERT` 增、`UPDATE` 改、`DELETE` 删；**改和删永远配 WHERE**。
2. **SQL 执行顺序**：`FROM → WHERE → GROUP BY → 聚合 → HAVING → SELECT → ORDER BY → LIMIT`（记住这个，就知道别名为什么能在 ORDER BY 用、不能在 WHERE 用）。
