## 一、一句话心智模型

```
MySQL 服务器（一个进程，监听 3306 端口）
└── 数据库 database（一个"仓库"，比如 day25）
    └── 表 table（一张"表格"，比如 student）
        └── 行 row（一条记录）/ 列 column（字段）
```

- **库 → 表 → 行/列**，跟 Excel 差不多，只是它被你用**文字命令**操作
- 一个 MySQL 里可以有很多库，我们只用自己的库（别动 `mysql` / `sys` 这些系统库）

## 二、四条核心语句（今天只学这四条）

| 语句 | 干什么 | 记忆点 |
|---|---|---|
| `SELECT` | 查 | `SELECT 列 FROM 表 WHERE 条件;` |
| `INSERT` | 增 | `INSERT INTO 表 (列1,列2) VALUES (值1,值2);` |
| `UPDATE` | 改 | `UPDATE 表 SET 列 = 值 WHERE 条件;` |
| `DELETE` | 删 | `DELETE FROM 表 WHERE 条件;` |

**记忆口诀**：*查 SELECT、增 INSERT、改 UPDATE、删 DELETE* ——简称 **CRUD**（Create 增 / Read 查 / Update 改 / Delete 删），面试八股里天天出现。

## 三、建表：字段类型 + 三个约束

```sql
CREATE TABLE student (
  id         INT PRIMARY KEY AUTO_INCREMENT,   -- 编号：主键 + 自增（插入时不用写它）
  name       VARCHAR(20) NOT NULL,             -- 姓名：最多 20 字符，不能为空
  score      INT DEFAULT 0,                    -- 分数：整数，不填默认 0
  class_name VARCHAR(20)                       -- 班级
) DEFAULT CHARSET = utf8mb4;                   -- ⚠️ 中文必须 utf8mb4
```

| 类型 | 用来存 | 注意 |
|---|---|---|
| `INT` | 整数（年龄、分数、编号） | 分数要小数就用 `DECIMAL(5,2)`，**别用 FLOAT** |
| `VARCHAR(n)` | 短文本（姓名、班级名） | n 是最大字符数，够用就行 |
| `DATE` | 日期 | 格式 `'2026-09-16'` |

| 约束 | 意思 | 说白了 |
|---|---|---|
| `PRIMARY KEY` | 主键 | 这一行的"身份证号"，不能重复、不能空 |
| `AUTO_INCREMENT` | 自增 | 插入时自动 +1，**INSERT 里不用写 id** |
| `NOT NULL` | 不能为空 | 该字段必须给值 |
| `DEFAULT 0` | 默认值 | 不写就用 0 |

## 四、查询四件套：WHERE / ORDER BY / LIMIT / GROUP BY

```sql
SELECT name, score                 -- ① 要哪几列
FROM student                       -- ② 从哪张表
WHERE class_name = '一班' AND score >= 80   -- ③ 筛什么（字符串用单引号！）
ORDER BY score DESC                -- ④ 排序：DESC 降序 / 省略 = 升序
LIMIT 2;                           -- ⑤ 只要前 2 条
```

**顺序不能乱**：`SELECT → FROM → WHERE → ORDER BY → LIMIT`（背下来，写错顺序直接报语法错）

### 聚合函数 + 分组（统计必备）

| 函数 | 意思 | 例子 |
|---|---|---|
| `COUNT(*)` | 有几行 | 每个班几个人 |
| `SUM(score)` | 求和 | 全班总分 |
| `AVG(score)` | 平均 | `ROUND(AVG(score), 2)` 保留两位 |
| `MAX` / `MIN` | 最大 / 最小 | 最高分 / 最低分 |

```sql
SELECT class_name, COUNT(*) AS 人数, ROUND(AVG(score), 2) AS 平均分
FROM student
GROUP BY class_name            -- 按班级"分组"，每组算一遍聚合
ORDER BY AVG(score) DESC;
```

> 白话理解 **GROUP BY**：先把行按班级分成几堆，然后**每堆单独**算人数和平均分。

## 五、多表查询：JOIN

数据分表存（学生表里有**班级名**，班级表里有**班主任**），想看"学生 + 他的班主任"就要**连接两张表**：

```sql
SELECT s.name, s.score, c.teacher
FROM student s                            -- s 是 student 的短名
JOIN class_info c ON s.class_name = c.class_name   -- ON = 两表怎么对上
ORDER BY s.score DESC;
```

**`ON` 就是"接头暗号"**：拿 student 的 class_name 去 class_info 里找同名的行。
⚠️ 忘了写 `ON` → 变成**笛卡尔积**（7 个学生 × 3 个班 = 21 行），数据全乱。

## 六、⚠️ 今天最大的坑：WHERE 忘了写

| 坑 | 后果 | 正解 |
|---|---|---|
| **`UPDATE`/`DELETE` 忘写 `WHERE`** | **整张表的分数全被改 / 整张表被删空** | 动手前先默念："我的 WHERE 在哪？" |
| 字符串用了双引号 | 报错"未知的列"（MySQL 里双引号默认当列名） | 字符串一律**单引号** `'一班'` |
| `= NULL` 查不到数据 | 结果 0 行，怎么想都不对 | MySQL 里判空用 `IS NULL` / `IS NOT NULL` |
| 中文变成问号 `??` | 建库/建表没写字符集 | `DEFAULT CHARSET = utf8mb4` + 客户端 `--default-character-set=utf8mb4` |
| `DELETE FROM student;` | 表空了但表还在 | 想连表一起清用 `TRUNCATE TABLE student;` |
| 平均分变成 `86.33` 又像 `86.3333` | 没 `ROUND` | `ROUND(AVG(score), 2)` |
