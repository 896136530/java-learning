## Ex1：建库建表

- 要求：
  1. `day25` 库若已存在先删掉，然后创建它（字符集 `utf8mb4`）
  2. 切到 `day25`
  3. 建 `student` 表：`id`（INT，主键 + 自增）、`name`（VARCHAR(20)，非空）、`score`（INT，默认 0）、`class_name`（VARCHAR(20)）
- 验证：`SHOW DATABASES` 有 day25 → `SHOW TABLES` 有 student → `DESC student` 四个字段、`id` 的 Key=PRI、Extra=auto_increment
- 💡：`DROP DATABASE IF EXISTS` / `CREATE DATABASE ... DEFAULT CHARACTER SET utf8mb4` / `PRIMARY KEY AUTO_INCREMENT`
- ⚠️ 忘了 utf8mb4，后面存中文会变问号

## Ex2：插入数据（INSERT）

- 用**一条** INSERT 插入三条：张三 88 一班 / 李四 95 一班 / 王五 76 一班
- 期望输出：
  ```
  id  name  score  class_name
  1   张三   88     一班
  2   李四   95     一班
  3   王五   76     一班
  人数：3
  ```
- 💡：`INSERT INTO student (name, score, class_name) VALUES (...), (...), (...);`（三组值用逗号隔开）
- ⚠️ `id` 是自增的，**不用写**；字符串用**单引号**

## Ex3：条件查询

- 数据已有 7 人。**一条 SELECT** 查出：一班的、分数 ≥ 80、只要 `name` 和 `score` 两列、按分数从高到低、只取前 2 条
- 期望输出：
  ```
  name  score
  李四   95
  张三   88
  ```
- 💡：`WHERE class_name = '一班' AND score >= 80 ORDER BY score DESC LIMIT 2;`
- ⚠️ 子句顺序 `SELECT → FROM → WHERE → ORDER BY → LIMIT` 不能乱

## Ex4：更新与删除（最危险的两条语句）

- ① `UPDATE`：给**一班**所有同学每人 **+5** 分（用 `score = score + 5`，别写死数字）
- ② `DELETE`：把分数 **< 60** 的同学删掉
- 期望输出（验证语句打印）：
  ```
  一班三人 → 93 / 100 / 81
  孙八（45 分）被删掉
  剩余 6 人
  ```
- 💡：`UPDATE student SET score = score + 5 WHERE class_name = '一班';` / `DELETE FROM student WHERE score < 60;`
- ⚠️⚠️ **这两条语句忘写 WHERE 就是灾难**：一个把全班改完、一个把整表删空。写之前先确认 WHERE

## Ex5：分组统计

- **一条 SELECT**：按班级分组，输出班级名、人数、平均分（2 位小数）、最高分，按平均分从高到低
- 期望输出：
  ```
  班级  人数  平均分  最高分
  一班   3    86.33   95
  二班   2    80.00   100
  三班   2    63.50   82
  ```
- 💡：`COUNT(*) AS 人数, ROUND(AVG(score), 2) AS 平均分, MAX(score) AS 最高分 ... GROUP BY class_name ORDER BY AVG(score) DESC;`
- ⚠️ 非聚合列（这里是 `class_name`）必须出现在 `GROUP BY` 里

## 🎯 复习：多表查询（JOIN）

- 两张表：`student`（7 人）+ `class_info`（3 个班：班级名 / 班主任 / 教室）
- ① 查每个学生的 姓名、分数、班级、班主任（连表），按分数**降序**
- ② 查每个班的 班级、人数、班主任，按**人数降序**（人数一样时按班级名升序兜底）
- 期望输出（② 是这样三行）：
  ```
  班级  人数  班主任
  一班   3    王老师
  三班   2    张老师
  二班   2    李老师
  ```
- 💡：`FROM student s JOIN class_info c ON s.class_name = c.class_name`；多关键字排序 `ORDER BY COUNT(*) DESC, c.class_name`
- ⚠️ 忘了 `ON` → 7 × 3 = 21 行（笛卡尔积）
