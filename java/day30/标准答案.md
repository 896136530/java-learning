## 三、批改口径（避免误判）

1. **端口被占**：学生报 `Port 8080 was already in use` → 是**他自己的旧进程**没关，不是代码错。
   教他：`netstat -ano | findstr ":8080"` → `taskkill /PID xxx /F`，或改 `server.port`。
2. **H2 数据没了**：内存库，重启就空 —— **正常**，不是 bug。答对这点要表扬。
3. **`h2-console` 打不开**：检查 `spring.h2.console.enabled=true`；路径 `/h2-console`（3.3.5 实测可用）。
4. **接口 404 但编译全过**：⭐ 经典坑 —— `@SpringBootApplication` 所在包**扫不到** Controller。
   检查 `Day30Application` 是不是在 `com.xiaoming.day30`（或更上层）。
5. **JSON 里字段是 null**：`Task` 少了 getter → Jackson 序列化不出来。**要指出**（新手第二坑）。
6. **`javax.persistence` 报错**：老教程抄来的。SpringBoot 3 必须用 **`jakarta.persistence`**。
7. **`@RequestParam` 报 `Name for argument of type [java.lang.Integer] not specified`**：
   本项目**显式写了参数名**（`@RequestParam("day")`）+ pom 里开了 `maven.compiler.parameters=true`，所以不该出现。
   学生自己新增接口时若省略名字才可能遇到 —— 提示补名字或检查 pom。
8. **测接口要用两个终端**：`spring-boot:run` 前台阻塞。学生说"跑不起来"时先确认这点。
9. **curl 在 Windows 的引号**：POST 测试建议用 H2 控制台或 `/tasks` 复查，别卡在 curl 转义上。
   （AI 批改时用 `curl -s -o 文件` 拿原始字节 + `[System.Text.Encoding]::UTF8` 解码，
   不要用 `Invoke-WebRequest` —— 它会把 UTF-8 当 Latin-1 显示成乱码。）
10. **`spring.jpa.open-in-view` WARN**：默认开启的提示，不影响运行，**不用管**（Day31 会讲）。
11. **启动慢（20 秒+）**：Hibernate 初始化 + 建表，正常。第二次启动会快一些。
