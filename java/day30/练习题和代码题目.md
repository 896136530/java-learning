## 题 8（代码 ⭐⭐⭐）：新增接口（TODO④）

**文件**：`TaskController.java` → `add()`

**要求**：`POST /tasks` 能把请求体里的 JSON 存进数据库，并返回**存好之后的对象**（带自增 id）。

**提示**：Repository 已经有 `save` 方法了；注意 `save` 的返回值要用 `return` 出去。

**验收**（Windows 的 curl 引号很坑，建议这样测）：

```bash
# 方式 1：curl（注意 JSON 里的双引号要转义）
curl -X POST http://localhost:8080/tasks -H "Content-Type: application/json" -d "{\"title\":\"新任务\",\"dayNo\":6,\"type\":\"Java\",\"done\":false}"

# 方式 2（更推荐）：打开 H2 控制台，刷新看数据多了一行
# 方式 3：再访问 /tasks，看数组末尾有没有新任务
```

**该看到**：返回的 JSON 里 `"id":9`（自增主键，数据库生成的）。

**⭐ 想清楚一件事**：返回的这个 `id` 有什么意义？
（答：调用方拿到它才能后续"改这条/删这条"。这就是**接口要有返回值**的原因。）
