## 题目详情

### 题 1：抽象类入门（Animal + Dog）

写两个类：
- **抽象类 `Animal`**：属性 `String name`；构造 `Animal(String name)`；**抽象方法** `eat()`；普通方法 `sleep()` 打印 `XX在睡觉`
- **子类 `Dog`**：`extends Animal`，**实现** `eat()` 打印 `XX啃骨头`
- `main` 里（已写好）：`new Dog("旺财")` → 调用 `eat()` 和 `sleep()`
- 期望输出：
  ```
  旺财啃骨头
  旺财在睡觉
  ```
- 💡：`Animal` 是抽象类，**不能 `new Animal(...)`**；`Dog` 必须实现 `eat()`，否则编译报错

### 题 2：接口入门（Flyable + Bird/Plane）

写三个东西：
- **接口 `Flyable`**：方法 `fly()`（不用写实现，自动是 public abstract）
- **类 `Bird`**：属性 `String name` + 构造；`implements Flyable`，实现 `fly()` 打印 `XX扇翅膀飞了`
- **类 `Plane`**：属性 `String name` + 构造；`implements Flyable`，实现 `fly()` 打印 `XX喷气起飞`
- `main` 里（已写好）：`Flyable f1 = new Bird("麻雀");` → `f1.fly()`；`Flyable f2 = new Plane("波音747");` → `f2.fly()`
- 期望输出：
  ```
  麻雀扇翅膀飞了
  波音747喷气起飞
  ```
- 💡：接口引用指向实现类对象（接口多态）；**实现接口的方法必须写 `public`**，少写会编译报错

### 题 3：一个类实现多个接口（Swimmer/Runner + Athlete）

写三个东西：
- **接口 `Swimmer`**：方法 `swim()`
- **接口 `Runner`**：方法 `run()`
- **类 `Athlete`**：属性 `String name` + 构造；**同时实现两个接口**——`swim()` 打印 `XX在蛙泳`，`run()` 打印 `XX在冲刺跑`
- `main` 里（已写好）：`new Athlete("小明")` → 调 `swim()`、`run()`；再用 `Swimmer s = a;` 调 `s.swim()`
- 期望输出：
  ```
  小明在蛙泳
  小明在冲刺跑
  小明在蛙泳
  ```
- 💡：一个类可以 `implements` 多个接口——这是 Java 单继承的"补丁"，面试常问

### 题 4：抽象类 + 接口组合（Employee/Coder + JavaDev）

写四个东西：
- **抽象类 `Employee`**：属性 `String name` + 构造；**抽象方法** `work()`；普通方法 `punchCard()` 打印 `XX打卡上班`
- **接口 `Coder`**：方法 `writeCode()`
- **类 `JavaDev`**：`extends Employee implements Coder`——实现 `work()` 打印 `XX开发系统`，实现 `writeCode()` 打印 `XX写 Java 代码`
- `main` 里（已写好）：`new JavaDev("小李")` → 调 `work()`、`writeCode()`、`punchCard()`
- 期望输出：
  ```
  小李开发系统
  小李写 Java 代码
  小李打卡上班
  ```
- 💡思考：为什么"员工"用抽象类、"会写代码"用接口？（身份 is-a 用继承，能力 can-do 用接口——二者组合）

### 题 5：综合——宠物店（Pet/Soundable + Cat/Duck）

写五个东西：
- **接口 `Soundable`**：方法 `makeSound()`
- **抽象类 `Pet`**：属性 `String name` + 构造；**抽象方法** `eat()`；普通方法 `sleep()` 打印 `XX在睡觉`
- **类 `Cat`**：`extends Pet implements Soundable`——`eat()` 打印 `XX吃鱼`，`makeSound()` 打印 `XX喵喵叫`
- **类 `Duck`**：`extends Pet implements Soundable`——`eat()` 打印 `XX吃谷物`，`makeSound()` 打印 `XX嘎嘎叫`
- `main` 里（已写好）：`show(new Cat("猫咪"));`、`speak(new Cat("猫咪"));`、`show(new Duck("鸭鸭"));`、`speak(new Duck("鸭鸭"));`
  - `show(Pet p)`：`p.eat()` + `p.sleep()`（参数用抽象类）
  - `speak(Soundable s)`：`s.makeSound()`（参数用接口）
- 期望输出：
  ```
  猫咪吃鱼
  猫咪在睡觉
  猫咪喵喵叫
  鸭鸭吃谷物
  鸭鸭在睡觉
  鸭鸭嘎嘎叫
  ```
- 💡思考：以后加一只"仓鼠"（会吱吱叫），`show` 和 `speak` 需要改吗？（不用！抽象类管"是宠物"，接口管"会叫"，各通吃）
