## 题 1 答案（抽象类入门）

```java
abstract class Animal {
    String name;

    Animal(String name) {
        this.name = name;
    }

    void sleep() {
        System.out.println(name + "在睡觉");
    }

    abstract void eat();   // 抽象方法：只声明，不实现
}

class Dog extends Animal {
    Dog(String name) {
        super(name);
    }

    @Override
    void eat() {
        System.out.println(name + "啃骨头");   // 必须实现，否则编译报错
    }
}
```

（main：`new Dog("旺财")` → **旺财啃骨头** / **旺财在睡觉**）

**考点**：抽象类不能 new；子类必须实现全部抽象方法。
**刁钻用例**：
- `new Animal("??")` → **编译报错**（抽象类不能实例化）
- Dog 不写 `eat()` → 编译报错（未实现抽象方法）；除非 Dog 自己也写成 `abstract class`

## 题 2 答案（接口入门）

```java
interface Flyable {
    void fly();   // 自动是 public abstract
}

class Bird implements Flyable {
    String name;

    Bird(String name) {
        this.name = name;
    }

    @Override
    public void fly() {
        System.out.println(name + "扇翅膀飞了");
    }
}

class Plane implements Flyable {
    String name;

    Plane(String name) {
        this.name = name;
    }

    @Override
    public void fly() {
        System.out.println(name + "喷气起飞");
    }
}
```

（main：`Flyable f1 = new Bird("麻雀")` → f1.fly() 输出 **麻雀扇翅膀飞了**；`Flyable f2 = new Plane("波音747")` → **波音747喷气起飞**）

**考点**：接口多态 + 接口方法实现必须写 `public`。
**刁钻用例**：`void fly()` 不写 public → 编译报错（attempting to assign weaker access privileges——接口方法默认 public，实现不能降级）

## 题 3 答案（一个类实现多个接口）

```java
interface Swimmer {
    void swim();
}

interface Runner {
    void run();
}

class Athlete implements Swimmer, Runner {
    String name;

    Athlete(String name) {
        this.name = name;
    }

    @Override
    public void swim() {
        System.out.println(name + "在蛙泳");
    }

    @Override
    public void run() {
        System.out.println(name + "在冲刺跑");
    }
}
```

（main 输出：**小明在蛙泳** / **小明在冲刺跑** / **小明在蛙泳**——第三行是 `Swimmer s = a; s.swim();`，接口引用指向实现类）

**考点**：一个类可以 `implements` 多个接口（`implements Swimmer, Runner`），弥补 Java 单继承。

## 题 4 答案（抽象类 + 接口组合）

```java
abstract class Employee {
    String name;

    Employee(String name) {
        this.name = name;
    }

    abstract void work();

    void punchCard() {
        System.out.println(name + "打卡上班");
    }
}

interface Coder {
    void writeCode();
}

class JavaDev extends Employee implements Coder {
    JavaDev(String name) {
        super(name);
    }

    @Override
    void work() {
        System.out.println(name + "开发系统");
    }

    @Override
    public void writeCode() {
        System.out.println(name + "写 Java 代码");
    }
}
```

（main 输出：**小李开发系统** / **小李写 Java 代码** / **小李打卡上班**）

**考点（重点）**：**身份用继承（抽象类），能力用接口（implements）**，两者组合——这就是 Spring 里"类 + 接口"满天飞的原因。

## 题 5 答案（综合：宠物店）

```java
interface Soundable {
    void makeSound();
}

abstract class Pet {
    String name;

    Pet(String name) {
        this.name = name;
    }

    abstract void eat();

    void sleep() {
        System.out.println(name + "在睡觉");
    }
}

class Cat extends Pet implements Soundable {
    Cat(String name) {
        super(name);
    }

    @Override
    void eat() {
        System.out.println(name + "吃鱼");
    }

    @Override
    public void makeSound() {
        System.out.println(name + "喵喵叫");
    }
}

class Duck extends Pet implements Soundable {
    Duck(String name) {
        super(name);
    }

    @Override
    void eat() {
        System.out.println(name + "吃谷物");
    }

    @Override
    public void makeSound() {
        System.out.println(name + "嘎嘎叫");
    }
}
```

（main 输出 6 行：**猫咪吃鱼** / **猫咪在睡觉** / **猫咪喵喵叫** / **鸭鸭吃谷物** / **鸭鸭在睡觉** / **鸭鸭嘎嘎叫**）

**考点（综合全家桶）**：
- `show(Pet p)` 参数用**抽象类** → 通吃所有宠物（eats + sleep 两件套）
- `speak(Soundable s)` 参数用**接口** → 通吃所有会叫的
- 以后加"仓鼠"类：`class Hamster extends Pet implements Soundable`，**show/speak 一行都不用改**——这就是"面向抽象编程"的威力
