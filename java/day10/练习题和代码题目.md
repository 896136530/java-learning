## 题目详情

### 题 1：重写 toString（Student）

写一个类：
- **类 `Student`**：属性 `String name`、`int studentId`；构造 `Student(String name, int studentId)`；**重写 `toString()`** 返回 `姓名：XX，学号：XX`
- `main` 里（已写好）：`System.out.println(s);` 和 `System.out.println(s.toString());`
- 期望输出：
  ```
  姓名：小明，学号：2025001
  姓名：小明，学号：2025001
  ```
- 💡：`println(对象)` 会自动调 toString；不重写会打出 `Student@16进制乱码`

### 题 2：== vs equals（Phone + String）

写一个类 + 看输出：
- **类 `Phone`**：属性 `String brand`；构造 `Phone(String brand)`（**不用重写 equals**，保持默认）
- `main` 里（已写好）：比对两个字符串字面量、`new` 出来的字符串、两个 Phone 对象
- 期望输出：
  ```
  a==b：true
  a==c：false
  a.equals(c)：true
  p1==p2：false
  p1.equals(p2)：false
  ```
- 💡思考：为什么 `a==b` 是 true，`a==c` 是 false？（字面量共用常量池；new 一定新对象）；`p1.equals(p2)` 没重写 = 默认比地址 = false

### 题 3：重写 equals（Person 按内容比）

写一个类：
- **类 `Person`**：属性 `String name`、`int age`；构造；**重写 `equals(Object o)`**——先 `o instanceof Person` 判断，再向下转型，比较 name 和 age
- `main` 里（已写好）：两个"小明18"比较、再和"小红20"比较
- 期望输出：
  ```
  p1==p2：false
  p1.equals(p2)：true
  p1.equals(p3)：false
  ```
- 💡：equals 参数**必须写 `Object`**（写 Person 是重载不是重写，白干）；`==` 永远是地址比较

### 题 4：getClass + instanceof（Animal/Dog）

写两个类：
- **父类 `Animal`**：属性 `String name`；构造 `Animal(String name)`
- **子类 `Dog`**：`extends Animal`，构造里 `super(name)`
- `main` 里（已写好）：`Animal a = new Dog("旺财");` → 打印 `getClass().getName()` 和两次 instanceof
- 期望输出：
  ```
  真实类型：Dog
  是 Dog？true
  是 Animal？true
  ```
- 💡：getClass 拿"右边"真实类型（多态实锤）；instanceof 沿继承链向上都算 true

### 题 5：综合——三件套（Book）

写一个类：
- **类 `Book`**：属性 `String title`、`int price`；构造；**重写三件套**：
  - `toString()` 返回 `书名：XX，价格：XX`
  - `equals(Object o)` 比较 title 和 price
  - `hashCode()` 返回 `title.hashCode() + price`
- `main` 里（已写好）：两个"Java入门/59"的 Book，打印对象 + 比较内容 + 比较哈希
- 期望输出：
  ```
  书名：Java入门，价格：59
  内容相等？true
  哈希相等？true
  ```
- 💡：equals 相等 → hashCode 必须相等（这里都是 `title.hashCode()+price`，必然相等）
