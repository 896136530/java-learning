## 题 1 答案（重写 toString）

```java
class Student {
    String name;
    int studentId;

    Student(String name, int studentId) {
        this.name = name;
        this.studentId = studentId;
    }

    @Override
    public String toString() {
        return "姓名：" + name + "，学号：" + studentId;
    }
}
```

（main 输出两行都是 **姓名：小明，学号：2025001**）

**考点**：`println(对象)` 就是调 `toString()`；不重写会打出 `Student@16进制` 乱码。
**刁钻用例**：把 `toString()` 的 `public` 去掉 → 编译报错（重写不能降低访问权限）；返回值写 `void` → 编译报错。

## 题 2 答案（== vs equals）

```java
class Phone {
    String brand;

    Phone(String brand) {
        this.brand = brand;
    }
}
```

（main 输出：**a==b：true** / **a==c：false** / **a.equals(c)：true** / **p1==p2：false** / **p1.equals(p2)：false**）

**考点**：`==` 永远比地址；字符串字面量共用常量池（`a==b` true），`new` 一定新对象（`a==c` false）；String 重写了 equals 所以比内容；Phone 没重写 equals，默认=比地址。

## 题 3 答案（重写 equals）

```java
class Person {
    String name;
    int age;

    Person(String name, int age) {
        this.name = name;
        this.age = age;
    }

    @Override
    public boolean equals(Object o) {
        if (o instanceof Person) {   // 先验类型，防止 ClassCastException
            Person p = (Person) o;   // 再向下转型
            return name.equals(p.name) && age == p.age; // 逐项比内容
        }
        return false;
    }
}
```

（main 输出：**p1==p2：false** / **p1.equals(p2)：true** / **p1.equals(p3)：false**）

**考点**：equals 参数**必须写 `Object`**（写 Person 是重载，Java 不认，等于没重写）；三件套：先 instanceof → 再向下转型 → 逐项比。
**刁钻用例**：`p1.equals("小明18")` → 先 instanceof 检查 → false，不会崩；不写 instanceof 直接转型 → ClassCastException。

## 题 4 答案（getClass + instanceof）

```java
class Animal {
    String name;

    Animal(String name) {
        this.name = name;
    }
}

class Dog extends Animal {
    Dog(String name) {
        super(name);
    }
}
```

（main 输出：**真实类型：Dog** / **是 Dog？true** / **是 Animal？true**）

**考点**：`getClass()` 拿运行时真实类型（多态"看右边"）；`instanceof` 沿继承链向上都算 true。
**刁钻用例**：`Dog d = (Dog) new Animal("x")` → ClassCastException（父转子必须真实类型是子才行）；`Object o = "hi"; o.getClass()` → java.lang.String（所有类的写真名）。

## 题 5 答案（三件套）

```java
class Book {
    String title;
    int price;

    Book(String title, int price) {
        this.title = title;
        this.price = price;
    }

    @Override
    public String toString() {
        return "书名：" + title + "，价格：" + price;
    }

    @Override
    public boolean equals(Object o) {
        if (o instanceof Book) {
            Book b = (Book) o;
            return title.equals(b.title) && price == b.price;
        }
        return false;
    }

    @Override
    public int hashCode() {
        return title.hashCode() + price;
    }
}
```

（main 输出：**书名：Java入门，价格：59** / **内容相等？true** / **哈希相等？true**）

**考点**：equals 相等 → hashCode 必须相等（本实现都是 `title.hashCode()+price`，两本书相同字段值必然相等）；toString 拼接顺序别乱。
**刁钻用例**：奖一场——把 `hashCode()` 改成 `return 1;`（所有对象哈希都是 1），equals 依然相同、程序照样跑——哈希相同是"尽量散开"，不要求唯一。
