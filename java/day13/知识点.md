# Day 13 知识点：HashMap（键值对，后端"查表"神器）

> 前提：Day 12 ArrayList 过关。今天上面试/项目里出现率 TOP3 的容器——HashMap。**按名字查东西**就靠它。

## 1. 为什么需要键值对

ArrayList 只能按下标查：`list.get(0)` —— 你得记住每个元素的**位置**。
但现实中我们想的是"**小明考了多少分？**"、"**苹果多少钱？**"——按**名字**查。

> HashMap 就是一个"查表"：存进去的时候 `{名字=信息}`，查的时候报名字，直接拿到信息。

```java
import java.util.HashMap;   // 导入

HashMap<String, Integer> score = new HashMap<>();  // <键类型, 值类型>
score.put("小明", 90);       // 存：小明 = 90
score.put("小红", 80);
int x = score.get("小明");   // 查：报名字，得到 90
```

## 2. 长什么样 / 两个铁规矩

- 里面是一条条 `键=值`：`{小明=90, 小红=80}`
- **铁规矩 1：键（key）唯一**——同一个键存两次，后面的覆盖前面的（后写胜出）
- **铁规矩 2：没有顺序**——存进去的顺序不代表取出来的顺序，**别依赖打印顺序**

## 3. 常用方法表（背，天天用）

| 方法 | 作用 | 例子 |
|---|---|---|
| `put(键, 值)` | 存入；键已存在则**覆盖** | `map.put("小明", 90)` |
| `get(键)` | 取出；**键不存在返回 null**（不是 0！）| `map.get("小明")` |
| `containsKey(键)` | 有没有这个键（比 get 判空更准）| `map.containsKey("小明")` |
| `remove(键)` | 删除并返回被删的值 | `map.remove("小明")` |
| `size()` | 有多少对 | `map.size()` |
| `keySet()` | 拿到**所有键**（配合遍历/get）| `map.keySet()` |
| `isEmpty()` | 是否空 | `map.isEmpty()` |
| `getOrDefault(键, 默认值)` | 不存在时给默认值（偷懒神器）| `map.getOrDefault("小明", 0)` |

## 4. 遍历的两种姿势（记住）
HashMap 没有下标，遍历靠"先拿所有键，再挨个查"：

```java
// 姿势A：普通 for - each 遍历 keySet()，再 get
for (String key : map.keySet()) {
    System.out.println(key + " = " + map.get(key));
}

// 姿势B：value 不关心键？keySet 依然要；想知道值也用 get
```

## 5. 为什么它快？（面试爱问）

ArrayList 查元素要**从头挨个找**（O(n)，人越多越慢）。
HashMap 把键丢进"**哈希函数**"算出编号，直接去对应**储物柜**取（O(1)，人再多也是瞬间）。
> 比喻：ArrayList 是排长队找书包；HashMap 是每人一个编号储物柜，报号直接开柜。
> （两把钥匙放一个柜子叫"冲突"，HashMap 内部用链表/红黑树兜底——一句话带过就行。）

## 6. 键用什么好？

**用不可变对象当键**：`String`、`Integer` 最保险（哈希编号不会变）。
自己写的可变类当键是深水区，以后遇到再说——现阶段**键一律 String/Integer**。

## 7. 坑清单（背）

1. `get(不存在的键)` 返回 **null**，不是 0、不是异常——所以 `int x = map.get("xx")` 会**报空指针**（拆箱失败）！
2. 判断"有没有"用 **`containsKey`**，别用 `get(...) != null` 猜（万一值本身是 null 就误判）
3. **顺序不定**：打印 `map` 顺序跟你 put 的不一样，别惊讶别依赖
4. 重复 `put` 同键 = 覆盖，不是多存一条
5. 统计模板（一定要会写）：
   ```java
   if (map.containsKey(w)) { map.put(w, map.get(w) + 1); }  // 存在就 +1
   else                    { map.put(w, 1); }               // 不存在就记 1
   ```

## 8. 三种容器对比（面试直接默写）

| | 数组 / ArrayList | HashMap |
|---|---|---|
| 按什么找 | 下标（位置）| 键（名字/编号）|
| 查得快不快 | 挨个找 O(n) | 哈希直取 O(1) |
| 键唯一？ | — | ✅ |
| 有顺序？ | 有 | 无 |
| 典型场景 | 存列表、遍历 | 查表、统计、字典 |

## 9. 一句话总结 + 明天预告

> **HashMap = 按名字查东西的表：put 存、get 取（不在返回 null）、containsKey 判断、keySet 遍历；键唯一、无顺序、查得快。**
