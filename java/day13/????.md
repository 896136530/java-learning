## 题 1 答案（查表）

```java
class PriceMap {
    public static Integer get(HashMap<String, Integer> map, String key) {
        return map.get(key);
    }

    public static boolean has(HashMap<String, Integer> map, String key) {
        return map.containsKey(key);
    }
}
```

（main 输出：**苹果 3 元** / **西瓜 null 元** / **有香蕉？true**）

**考点**：`get(不存在的键)` 返回 **null**（不是 0，也不是异常）；"有没有"用 `containsKey`。
**刁钻用例**：`get(null)` 也能查（HashMap 允许 null 键，但别乱用）；如果值本身存的就是 null，`containsKey` 和 `get()==null` 结果不一样——所以判断存在性**永远用 containsKey**。

## 题 2 答案（单词统计）⭐ 高频

```java
class Counter {
    public static HashMap<String, Integer> countWords(String[] words) {
        HashMap<String, Integer> map = new HashMap<>();
        for (String w : words) {
            if (map.containsKey(w)) {        // 这个单词之前出现过
                map.put(w, map.get(w) + 1);  // 次数 +1
            } else {
                map.put(w, 1);               // 第一次见到，记 1
            }
        }
        return map;
    }
}
```

（main 输出：**apple 出现 3 次** / **banana 出现 1 次** / **grape 出现 null 次**）

**考点**：统计模板（containsKey 判断 + put 自增）——**面试/刷题第一名模板，必须背**。
**偷懒版（可预习）**：`map.put(w, map.getOrDefault(w, 0) + 1);` 一行顶上面 4 行。
**刁钻用例**：空数组 → 返回空表，不会崩；重复 put 只算一次 +1 的语义要对。

## 题 3 答案（改工资）

```java
class Wage {
    public static int raise(HashMap<String, Integer> map, String name, int amount) {
        int old = map.get(name);          // 读旧值
        int now = old + amount;           // 算新值
        map.put(name, now);               // 覆盖写回（put 同键 = 覆盖）
        return now;
    }
}
```

（main 输出：**小明新工资：5500** / **小红工资：6000** / **总人数：2**）

**考点**："读旧值 → 算新值 → 覆盖写回"三步曲；put 同键是覆盖不是新增（所以 size 还是 2）。
**刁钻用例**：`raise(map, "查无此人", 100)` → `map.get` 返回 null，`int old` 拆箱**空指针崩**——正规写法先 `containsKey` 判断或 `getOrDefault`。

## 题 4 答案（过滤及格表）

```java
class Filter {
    public static HashMap<String, Integer> keepPass(HashMap<String, Integer> map, int min) {
        HashMap<String, Integer> result = new HashMap<>();
        for (String key : map.keySet()) {       // 遍历所有键
            if (map.get(key) >= min) {          // 值达标才要
                result.put(key, map.get(key));
            }
        }
        return result;
    }
}
```

（main 输出：**小明 在名单？true** / **小红 在名单？false** / **通过人数：2**）

**考点**：`keySet()` 遍历 + `get`；**建新表收集**而不是改原表（改了原表外面的人全被影响）。
**刁钻用例**：`map.get(key) >= min` 里 `get` 返回 Integer 自动拆箱——如果键存在但值是 null 会 NPE；keySet 遍历中**别同时 remove 原表**（会抛 ConcurrentModificationException，先收集后删）。

## 题 5 答案（投票综合）

```java
class VoteUtil {
    public static HashMap<String, Integer> countVotes(String[] votes) {
        HashMap<String, Integer> map = new HashMap<>();
        for (String v : votes) {
            if (map.containsKey(v)) {
                map.put(v, map.get(v) + 1);
            } else {
                map.put(v, 1);
            }
        }
        return map;
    }

    public static String winner(HashMap<String, Integer> map) {
        String best = "";
        int max = -1;
        for (String key : map.keySet()) {       // 打擂法：谁票数高谁上位
            if (map.get(key) > max) {
                max = map.get(key);
                best = key;
            }
        }
        return best;
    }
}
```

（main 输出：**张三票数：3** / **获胜者：张三**）

**考点**：统计模板复用（题 2 一模一样）+ 打擂法复用（Day12 学过的思路换到键值对上）+ `keySet` 遍历。
**刁钻用例**：平票时（张三=李四=3）——HashMap **遍历顺序不保证**，winner 可能是两者任一，这是 HashMap 特性不是 bug；要"先投者胜"得额外记顺序（比如再用一个表存先后），知道这点就行。
