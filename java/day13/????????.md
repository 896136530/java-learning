## 题目详情

### 题 1：查表（PriceMap）

写一个类：
- **类 `PriceMap`**：两个 static 方法——
  - `Integer get(HashMap<String, Integer> map, String key)`：查价格
  - `boolean has(HashMap<String, Integer> map, String key)`：判断水果在不在表里
- `main` 里（已写好）：苹果 3 元、香蕉 2 元
- 期望输出：
  ```
  苹果 3 元
  西瓜 null 元
  有香蕉？true
  ```
- 💡：查不到的键 `get` 会返回 **null**（不是 0、不是报错）；"有没有"用 `containsKey`

### 题 2：单词统计（Counter）⭐

写一个类：
- **类 `Counter`**：`static HashMap<String, Integer> countWords(String[] words)`——统计每个单词出现次数
- `main` 里（已写好）：`{"apple","banana","apple","orange","apple"}`
- 期望输出：
  ```
  apple 出现 3 次
  banana 出现 1 次
  grape 出现 null 次
  ```
- 💡：统计模板——遍历单词，`containsKey` 判断：有过就 `put(w, get(w)+1)`，没有就 `put(w, 1)`。**这是刷题/面试第一高频模板，默写它**

### 题 3：改工资（Wage）

写一个类：
- **类 `Wage`**：`static int raise(HashMap<String, Integer> map, String name, int amount)`——给指定的人加工资 amount，**返回新工资**
- `main` 里（已写好）：小明 5000、小红 6000
- 期望输出：
  ```
  小明新工资：5500
  小红工资：6000
  总人数：2
  ```
- 💡：`put(同一个键, 新值)` = **覆盖**，人数不变；"读旧值 → 算新值 → 覆盖写回"是经典三步

### 题 4：过滤及格表（Filter）

写一个类：
- **类 `Filter`**：`static HashMap<String, Integer> keepPass(HashMap<String, Integer> map, int min)`——把值 ≥ min 的**键值对**放进一张新表返回（原表不动）
- `main` 里（已写好）：小明 90、小红 55、小刚 70，min=60
- 期望输出：
  ```
  小明 在名单？true
  小红 在名单？false
  通过人数：2
  ```
- 💡：`for (String key : map.keySet())` 拿全部键，挨个 `get(key)` 判断，合格的 `put` 进新表

### 题 5：综合——投票（VoteUtil）

写一个类：
- **类 `VoteUtil`**：两个 static 方法——
  - `HashMap<String, Integer> countVotes(String[] votes)`：统计每人票数（复用题 2 模板）
  - `String winner(HashMap<String, Integer> map)`：返回票数最多的人（打擂法，keySet 遍历）
- `main` 里（已写好）：`{"张三","李四","张三","王五","张三","李四"}`
- 期望输出：
  ```
  张三票数：3
  获胜者：张三
  ```
- 💡：winner 复用 Day12 的"打擂法"思路：先拿第一个键当擂主，谁票数高谁上位；初始化擂主票数用 -1
