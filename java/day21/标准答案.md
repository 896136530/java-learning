## Ex1：连接测试

```java
class DBUtil {
    static final String URL = "jdbc:mysql://localhost:3306/day21?useSSL=false&serverTimezone=Asia/Shanghai&characterEncoding=utf8";

    static Connection getConnection() throws SQLException {
        return DriverManager.getConnection(URL, "root", "root");

```

**考点**：`DriverManager.getConnection(url, user, pass)`；URL 里 `characterEncoding=utf8` 是中文不乱码的关键。
**刁钻**：`Class.forName("com.mysql.cj.jdbc.Driver")` 新版可以不用写（驱动自动注册），但面试常被问老写法。

## Ex2：建表

```java
class DBUtil {
    static final String URL = "jdbc:mysql://localhost:3306/day21?useSSL=false&serverTimezone=Asia/Shanghai&characterEncoding=utf8";

    static Connection getConnection() throws SQLException {
        return DriverManager.getConnection(URL, "root", "root");
    }

    static void createTable() throws SQLException {
        Connection conn = getConnection();
        Statement st = conn.createStatement();
        st.executeUpdate("DROP TABLE IF EXISTS student");      // 清掉旧表，保证每次重跑结果一致
        st.executeUpdate("CREATE TABLE IF NOT EXISTS student ("
                + "id INT AUTO_INCREMENT PRIMARY KEY, "        // 自增主键：id 自动 1,2,3...
                + "name VARCHAR(20), "
                + "score INT)");
        st.close();
        conn.close();
    }
}
```

**考点**：`executeUpdate` 执行建表；`AUTO_INCREMENT`（自增）与 `PRIMARY KEY`。
**刁钻**：不写 `DROP` 直接重跑 → 数据一直在 + 主键继续自增，输出就对不上（所以模板 main 每次先建表）。

## Ex3：插入 3 行

```java
class DBUtil {
    static final String URL = "jdbc:mysql://localhost:3306/day21?useSSL=false&serverTimezone=Asia/Shanghai&characterEncoding=utf8";

    static Connection getConnection() throws SQLException {
        return DriverManager.getConnection(URL, "root", "root");
    }

    static void createTable() throws SQLException {
        Connection conn = getConnection();
        Statement st = conn.createStatement();
        st.executeUpdate("DROP TABLE IF EXISTS student");
        st.executeUpdate("CREATE TABLE IF NOT EXISTS student ("
                + "id INT AUTO_INCREMENT PRIMARY KEY, "
                + "name VARCHAR(20), score INT)");
        st.close();
        conn.close();
    }

    static void insertStudent(String name, int score) throws SQLException {
        Connection conn = getConnection();
        PreparedStatement ps = conn.prepareStatement(
                "INSERT INTO student(name, score) VALUES(?, ?)");
        ps.setString(1, name);
        ps.setInt(2, score);
        ps.executeUpdate();
        ps.close();
        conn.close();
    }
}
```

**考点**：**PreparedStatement 必须用**（`?` 占位 + setXxx 赋值），面试必问"为什么不用 Statement 拼字符串"——防 SQL 注入。
**刁钻**：字符串拼接 `"VALUES('" + name + "')"`，遇到姓名 `小明' OR '1'='1` 直接注入炸库。

```java
class DBUtil {

    static Connection getConnection() throws SQLException {

        Statement st = conn.createStatement();
        st.executeUpdate("DROP TABLE IF EXISTS student");
        st.executeUpdate("CREATE TABLE IF NOT EXISTS student ("
                + "id INT AUTO_INCREMENT PRIMARY KEY, "
                + "name VARCHAR(20), score INT)");
        st.close();
        conn.close();
    }

    static void insertStudent(String name, int score) throws SQLException {
        Connection conn = getConnection();
        PreparedStatement ps = conn.prepareStatement(
                "INSERT INTO student(name, score) VALUES(?, ?)");
        ps.setString(1, name);
        ps.setInt(2, score);
        ps.executeUpdate();
        ps.close();
        conn.close();
    }

    static void queryAll() throws SQLException {
        Connection conn = getConnection();
        Statement st = conn.createStatement();
        ResultSet rs = st.executeQuery("SELECT * FROM student");
        while (rs.next()) {                              // next()：翻到下一行，有就 true
            System.out.printf("id=%d name=%s score=%d%n",
                    rs.getInt("id"), rs.getString("name"), rs.getInt("score"));
        }
        rs.close();
        st.close();
        conn.close();
    }
}
```

**考点**：`executeQuery` 返回 ResultSet；`next()` 游标 + `getInt/getString("列名")`。
**刁钻**：不调 `next()` 直接 `getXxx` → `SQLException: ResultSet not positioned properly`；用了 `getInt(0)` → 列从 **1** 开始。

```java
        ps.setString(1, name);
        ps.setInt(2, score);
        ps.executeUpdate();
        ps.close();

    }

    static int updateScore(int id, int score) throws SQLException {
        Connection conn = getConnection();
        PreparedStatement ps = conn.prepareStatement(
                "UPDATE student SET score = ? WHERE id = ?");
        ps.setInt(1, score);
        ps.setInt(2, id);

        ps.close();
        conn.close();

```

**考点**：`executeUpdate` 的返回值就是"影响了几行"，业务上拿它判断操作是否成功。
**刁钻**：忘记 `WHERE id = ?` → 全表分数被改，返回 9。

```java
    }

    static int deleteById(int id) throws SQLException {
        Connection conn = getConnection();
        PreparedStatement ps = conn.prepareStatement("DELETE FROM student WHERE id = ?");
        ps.setInt(1, id);
        int n = ps.executeUpdate();
        ps.close();
        conn.close();
        return n;
    }

    static int updateScore(int id, int score) throws SQLException {
        Connection conn = getConnection();
        PreparedStatement ps = conn.prepareStatement("UPDATE student SET score = ? WHERE id = ?");
        ps.setInt(1, score);
        ps.setInt(2, id);
        int n = ps.executeUpdate();
        ps.close();
        conn.close();
        return n;
    }

    static int getUserCount() throws SQLException {
        Connection conn = getConnection();
        Statement st = conn.createStatement();
        ResultSet rs = st.executeQuery("SELECT COUNT(*) FROM student");
        rs.next();                       // COUNT 结果只有一行一列
        int n = rs.getInt(1);            // 取第 1 列也可以用列名 "COUNT(*)"
        rs.close();
        st.close();
        conn.close();
        return n;
    }

```

**考点**：CRUD 四件套 + 聚合函数 `COUNT(*)`；`rs.getInt(1)` 按下标取列（从 1 开始）。
**刁钻**：`COUNT(*)` 永远返回一行，`next()` 一定 true——不写也行，但写上是好习惯。

## 全绿的规律（下次直接背）

1. 每开一个 Connection，用完必 close（顺序：ResultSet → Statement → Connection）
2. 带参数一律 PreparedStatement + `?`
3. `executeUpdate` 返回行数、`executeQuery` 返回结果集
4. 输出格式先对齐模板注释里的"期望输出"，再谈逻辑
