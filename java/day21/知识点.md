## 一、为什么要学数据库？

程序跑起来时数据在**内存**里（变量、List），一关程序全没了。
**数据库** = 把数据永久存到硬盘的"超级表格"，还可以快速查找。

- 内存里的数据 = 草稿纸（关机就没）
- 数据库里的数据 = 正式档案（永存）

## 二、JDBC 是什么？

> **JDBC**（Java DataBase Connectivity）：Java 官方提供的"连任意数据库"的**统一接口**（包名 `java.sql`）。

换数据库不换代码，只换两样东西：

| 要换的 | 说明 |
|---|---|
| 驱动 jar | 每种数据库一个小包（MySQL 的驱动叫 `mysql-connector-j.jar`，已在 `lib/` 文件夹）|
| 连接 URL | 一行字符串，指名连哪台机器、哪个库 |

## 三、五步曲（背下来！面试要默写）

```java
// ① 导入（文件头部 import java.sql.*;）
// ② 建立连接
Connection conn = DriverManager.getConnection(
        "jdbc:mysql://localhost:3306/day21?useSSL=false&serverTimezone=Asia/Shanghai&characterEncoding=utf8",
        "root", "root");          // URL / 用户名 / 密码

// ③ 写 SQL：Statement（固定 SQL）或 PreparedStatement（带 ? 占位，防注入）
PreparedStatement ps = conn.prepareStatement("INSERT INTO student(name,score) VALUES(?,?)");

// ④ 执行：
//    - executeUpdate()：insert / update / delete → 返回【影响的行数 int】
//    - executeQuery() ：select → 返回 ResultSet（结果集）
int rows = ps.executeUpdate();
ResultSet rs = ps.executeQuery();

// ⑤ 处理结果：next() 像"往下翻一行"，翻得到 true，翻不到 false
while (rs.next()) {
    int id = rs.getInt("id");
    String name = rs.getString("name");
}

// ⑥ 关资源：后开的先关（顺序 ResultSet → Statement → Connection）
ps.close();
conn.close();
```

**重点记忆口诀：连接 → 写 SQL → 执行 → 处理 → 关闭。**

## 四、SQL 三件套速通（单表够用）

```sql
CREATE TABLE IF NOT EXISTS student (          -- 建表：IF NOT EXISTS 防重复建
    id INT AUTO_INCREMENT PRIMARY KEY,        -- 自增主键：不用管它，自动 1,2,3...
    name VARCHAR(20),                          -- 变长字符串
    score INT                                  -- 整数
);
INSERT INTO student(name, score) VALUES(?, ?); -- 插一行（? 是占位符）
SELECT * FROM student;                         -- 查全部
UPDATE student SET score = ? WHERE id = ?;     -- 改（WHERE 限定哪一行）
DELETE FROM student WHERE id = ?;              -- 删（WHERE 限定哪一行）
```

> ⚠️ `WHERE` 是眼睛：没有它，UPDATE/DELETE 会**改/删全表**！

## 五、三坑 & 面试三句话

**坑 1**：`java.sql.SQLException: No suitable driver` → 编译/运行少加了驱动 jar（`-cp lib\mysql-connector-j.jar`）
**坑 2**：中文变成 `??` → 连接 URL 少了 `characterEncoding=utf8`，或建库没用 utf8mb4
**坑 3**：忘了 `close()` → 连接泄漏，跑几次就"Too many connections"，服务挂掉

**面试三句话**：
1. JDBC 是 Java 访问数据库的统一接口；
2. 核心对象是 Connection / Statement / ResultSet；
3. PreparedStatement 用 `?` 预编译，防 SQL 注入。
