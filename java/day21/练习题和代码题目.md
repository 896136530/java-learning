# Day 21 练习题和代码题目（JDBC 连接 MySQL）

> 期望输出写在每题模板注释里，对照它自查。

## 运行方法（每条题一样）

```powershell

javac -encoding UTF-8 -cp "lib\mysql-connector-j.jar" Day21_Ex1.java

# 运行
java -cp ".;lib\mysql-connector-j.jar" Day21_Ex1
```

## Ex1：接上数据库（最简单，先热手）

实现 `DBUtil.getConnection()`：用 `DriverManager.getConnection(URL, "root", "root")` 连上 `day21` 库。

- 模板里已给出 URL 常量，直接抄进代码
- 期望输出：`连接成功`

## Ex2：建表

实现 `DBUtil.createTable()`：先 `DROP TABLE IF EXISTS student` 再 `CREATE TABLE ...`（语句在知识点.md 第四节，抄即可）

- 期望输出：`建表成功`

## Ex3：插入 3 行数据

实现 `DBUtil.createTable()`（同 Ex2）和 `DBUtil.insertStudent(String name, int score)`：插入用 **PreparedStatement** + `?` 占位，执行 INSERT。

- main 会调 3 次：张三/88、李四/95、王五/76
- 期望输出：`插入3行成功`

## Ex4：查出来打印

实现三个方法：`createTable()`、`insertStudent(name, score)`、`queryAll()`。

- `queryAll()`：`SELECT * FROM student`，用 `while (rs.next())` 遍历，每行打印 `id=%d name=%s score=%d`
- 期望输出（顺序固定，id 从 1 开始）：

```
id=1 name=张三 score=88
id=2 name=李四 score=95
id=3 name=王五 score=76
```

## Ex5：改分数

实现 `insertStudent(name, score)`（含 `createTable`，同 Ex2）和 `updateScore(int id, int score)`。

- `updateScore`：UPDATE 后把 `executeUpdate()` 的返回值（影响行数）`return` 给 main
- 期望输出：`更新成功，影响 1 行`

## Review：全家桶（建→插→查→删→改→数）

实现：`createTable()`、`insertStudent`、`queryAll()`、`deleteById(int id)`、`updateScore(int id, int score)`、`getUserCount()`。

- main 顺序：建表 → 插 5 人（张三88 李四95 王五76 赵六60 钱七100）→ 打印全部 → 删 id=3 → 改 id=1 为 100 → 打印人数
- 期望输出：

```
id=1 name=张三 score=88
id=2 name=李四 score=95
id=3 name=王五 score=76
id=4 name=赵六 score=60
id=5 name=钱七 score=100
删除 id=3 成功，影响 1 行
更新 id=1 为 100 成功，影响 1 行
最终剩余 4 人
```
