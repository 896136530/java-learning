# 📒 项目：命令行记账本（第一个 Java 小项目）

> **为什么是这个项目**：它能把 Day1~17 学的东西**全部用上**——变量/循环/集合/HashMap/类/异常/泛型/文件读写。做完它，前面学的不但不会忘，还会变成"我会写项目"的底气。
>
> **做法**：三步，每天 20~40 分钟。每步做完**喊我验收**，我跑一遍给你判 ✅/❌ + 指出问题（不给答案，自己想通才是你的）。
> 项目文件夹：`java/项目-记账本/`，主文件：`Step1_记账本.java` → 之后 Step2 / Step3 接力。

## 目标功能（三步全做完的效果）

打开程序：
1. 记一笔（分类 + 金额，支出填负数，比如 `吃饭 -12`）
2. 按分类查汇总（`吃饭：-20`、`收入：100` 这样一行行列出）
3. 查明细（每一笔都留档，能按分类筛出来看）
4. **退出后再打开，账还在**（自动保存/自动读取）

## 三步任务书

### Step 1（今天）：分类汇总 —— 用到 HashMap + 循环 + 输入

- 菜单循环：`1 记一笔 / 2 查看分类汇总 / 3 退出`
- 记一笔：输入分类、金额 → **存进 HashMap**（分类 → 合计金额）
- 查看汇总：把每个分类和它的合计打印出来
- 验收示例（你跑出来要长这样）：
  ```
  记一笔 → 分类：吃饭  金额：-12
  记一笔 → 分类：吃饭  金额：-8
  记一笔 → 分类：收入  金额：100
  选 2 →
  吃饭：-20
  收入：100
  ```
- 模板 `Step1_记账本.java` 已给好骨架，你只需要填两处 TODO：
  - 记一笔：**分类已存在就累加，不存在就新建**（← 这是 HashMap 核心招式，Day13 的统计模板，用起来）
  - 查看汇总：把 map 遍历打印成 `分类：金额`
- 知识点复习：Day13 HashMap（put 覆盖 / 累加 / keySet 遍历）+ Day2 while 循环 + Day1 输入

### Step 2（明天）：明细留档 + 防崩 —— 用到类 + ArrayList + 异常

- 每笔账记成一条**明细**（分类、金额、备注），能打印全部 / 按分类筛
- 输金额输成"abc" → **提示重来，程序不许崩**（try-catch + 循环重试）
- 菜单加 `4 删除一笔`
- 知识点复习：Day5 类与对象（Bill 类）+ Day4 方法 + Day12 ArrayList + Day15 异常

### Step 3（后天）：持久化 —— 用到 IO 流 + File

- 退出时把全部明细**写进文件**（`账本.txt`）
- 打开程序时**自动读回**，账本接着记
- 文件不存在 → 就当空账本，不崩
- 知识点复习：Day17 IO 流（BufferedReader/Writer）+ Day15 异常 + File 类
