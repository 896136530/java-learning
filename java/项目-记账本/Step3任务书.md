# 📒 Step 3 任务书：持久化——退出后再打开，账还在

> **为什么这一步最重要**：前两步数据都在内存里，一关程序全没。这一步之后，你的记账本**才真的是个"本子"**——这就是真实软件和练习代码的分界线。
> 用时：30~45 分钟。做完喊我验收（我跑两轮：第一轮记几笔退出，第二轮重开看账还在不在）。

| 2 | **退出时自动写账本** | 选 6 退出前，把明细全部写进 `账本.txt` |
| 3 | **新增「查看总账」** | 菜单 5：总收入 / 总支出 / 结余 |
| 4 | 前两步的功能全部保留 | 记一笔、分类汇总、明细+筛选、删除一笔 |

## 文件与格式

数据文件：`账本.txt`（就在 `java/项目-记账本/` 里，程序自动创建）

**每行一笔账，格式是「分类 ⇥ 金额 ⇥ 备注」——中间用 `\t`（Tab 制表符）分隔**：

```
吃饭⇥-12⇥食堂午饭
收入⇥100⇥兼职工资
```

> 💡 为什么用 Tab 不用空格？因为**备注里可能有空格**（"公交 月卡 充值"）。
> 用空格分隔，这句备注就会被拆成三段 → 数据错位。这是真实项目里选分隔符的经典考虑，面试也爱问"CSV 怎么处理逗号"。

## 验收标准（我会这么测）

**第一轮（全新）**：删掉 `账本.txt` → 启动 → 菜单 2/3 应提示"还没有…"、菜单 5 应输出全 0 →

## 提示（卡住再看，别提前看）

<details>
<summary>点开看提示</summary>

**读文件三件套**：
```java
BufferedReader br = new BufferedReader(new FileReader(FILE));
String line;
while ((line = br.readLine()) != null) { ... }   // 读到 null 就是读完了
br.close();                                       // 别忘了关
```

**文件不存在**：`new File(FILE).exists()` 判一下（返回 false 就直接 return）。注意 `FileReader` 找不到文件会抛 `FileNotFoundException`——虽然 `main` 上有 `throws Exception` 能"混过去"，但那样第一次运行就崩，你 Step2 练的防崩白费。

**拆行**：
```java
String[] parts = line.split("\t");
if (parts.length < 3) continue;      // 空行 / 坏行跳过
```

**写文件**（`saveBills` 已给你，看一眼怎么写的）：
```java
try (FileWriter fw = new FileWriter(FILE)) { fw.write(一行); }
```

**为什么 `refresh` 要放在读完之后**：`bills` 里多了从文件读回来的账，分类汇总得跟着重算一遍，否则菜单 2 是空的。
> 📎 `refresh` 是**按明细重算**（先 `map.clear()` 再遍历累加），所以写好它之后平台自动帮你保证"汇总永远和明细一致"——Step2 里你得手动维护累加，Step3 换成重算，这是更省心的做法。

**模板里 `refresh(bills, map)` 已经替你调好了**：启动读完调一次、记一笔后调一次、删除后调一次（C 那题要你自己加）。

**总支出为什么是负数**：支出你本来就记成负数（-12），所以"总支出"直接把这些负数加起来就是 `-20`；结余 = 总收入 + 总支出（100 + (-20) = 80）。**别对 -20 取绝对值**，否则结余算错。
