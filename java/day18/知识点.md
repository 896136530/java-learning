# Day 18 知识点：多线程（Thread）

> 前提：类与对象、异常（sleep 要处理 InterruptedException）已通关。今天学"**一个程序同时干好几件事**"——后端面试最爱问，没有之一。

## 1. 为什么需要多线程

现在程序是"排队干活"：一行代码跑完才跑下一行。可现实是——你在等下载时还想聊天、还想听歌。**多线程 = 一个进程里同时跑多条执行线**，各干各的，谁也不等谁。

| 概念 | 一句话 |
|---|---|
| 进程 | 正在运行的程序（有独立内存）|
| 线程 | 进程里的执行线（共享进程内存）——我们谈的都是线程 |

## 2. 创建线程的两种方式（背）

### 方式一：继承 Thread，重写 run()

```java
class HelloThread extends Thread {
    @Override
    public void run() {           // 线程启动后执行这里
        System.out.println("我是新线程");
    }
}

public class Main {
    public static void main(String[] args) {
        HelloThread t = new HelloThread();
        t.start();                 // ← 开新线程，线程开始跑 run()
        System.out.println("我是主线程");
    }
}
```

### 方式二：实现 Runnable，传给 Thread（**推荐**）

```java
class Runner implements Runnable {
    @Override
    public void run() {
        System.out.println("跑起来了");
    }
}

Thread t = new Thread(new Runner());   // 把任务交给线程
t.start();
```

> 为什么不推荐继承 Thread：Java 是**单继承**，extends Thread 就继承不了别人了；implements Runnable 灵活（还可以 implements 别的接口）。**面试标准答案**。

## 3. start() 和 run() 的区别（必考题）

- `t.start()` → **真的开一条新线程**去跑 run()
- `t.run()` → 不开线程，**当成普通方法**在主线程里顺序执行

> 面试：调用错了就是"没有并发"。

## 4. join()：等线程跑完

```java
t.start();
t.join();          // 主线程在这等着，t 跑完才继续
System.out.println("接下来……");
```

> 用途：主线程要"依赖"子线程的结果时，必须 join。

## 5. 线程状态（一句话版）

**新建 → 就绪（等 CPU）→ 运行 →（sleep 阻塞/等待）→ 运行… → 终止**

## 6. 并发问题：为什么 i++ 会乱（重头戏）

两个线程同时执行 `value++`，看起来加两次，实际可能只加一次：

```
线程A读 value=5 →（被打断）→ 线程B读 value=5 → B写 6 → A写 6
```

结果 value=6，白加了一次。这就是**竞态条件**。开枪：**i++ 不是一步，是三步**（读→算→写），三步之间会被打断。

## 7. synchronized：上锁（解决之道）

```java
static synchronized void add() {   // 加锁：同一时刻只允许一个线程进来
    value++;
}
```

也可以锁代码块：
```java
synchronized (锁对象) {
    // 临界区
}
```

> 理解：**厕所门**。synchronized = 门锁，一个人进去锁门，出来才放下一个进。保证"读-算-写"三步一气呵成，不再被打断。

## 8. sleep()：让线程歇一会儿

```java
Thread.sleep(500);   // 停 500 毫秒
```

> ⚠️ `sleep` 抛 **InterruptedException**（受检异常）——必须处理。在 run() 里只能 try-catch（run 不能 throws）。

## 9. 面试必背三句话

1. 创建线程：**继承 Thread（重写 run）或实现 Runnable（推荐）**；`start()` 开线程，`run()` 只是普通方法
2. **synchronized** 是解决多线程改共享变量竞态的锁（原子性——三步变一步的保证）
3. 并发三特性（背名字）：**原子性（synchronized）/ 可见性（volatile）/ 顺序性**——今天深入原子性，后两个了解即可
