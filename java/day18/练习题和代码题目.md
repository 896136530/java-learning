## 题目详情

### 题 1：问候线程（HelloThread）
写一个类：
- **类 `HelloThread` extends `Thread`**：重写 `run()`，循环打印 3 次 `线程1：第i次`（i 从 1 到 3）
- main 里（已写好）：`start()` 后 `join()`，最后打印 `主线程结束`
- 期望输出（有序，因为 join 保证了）：
  ```
  线程1：第1次
  线程1：第2次
  线程1：第3次
  主线程结束
  ```
- 💡：`extends Thread` + `@Override run()`；join 让主线程乖乖等

### 题 2：双线程任务（Runner）
写一个类：
- **类 `Runner` implements `Runnable`**：`run()` 里打印一次 `跑起来了`
- main 里（已写好）：**同一个** Runner 起两个线程 t1、t2，都 start 后都 join，最后打印 `完成`
- 期望输出：
  ```
  跑起来了
  跑起来了
  完成
  ```
  （两行"跑起来了"顺序可能交换——线程谁先跑不确定，**数量对就行**）
- 💡：`implements Runnable`，任务类不继承 Thread；`new Thread(r)` 把任务包进线程

### 题 3：同步计数器（Adder）
写一个类：
- **类 `Adder` implements `Runnable`**：
  - `static int value = 0`
  - `static synchronized void add()`：让 value 加 1（**synchronized 锁住**）
  - `run()`：循环 500 次调用 `add()`
- main 里（已写好）：两个线程各跑一个 Adder，join 后打印 `计数结果：` + value
- 期望输出（**必须是**，不是约等于）：
  ```
  计数结果：1000
  ```
- 💡：500×2=1000。**先写不带 synchronized 的试试**，多跑几次看会不会变 999/998——这就是竞态现场；加上 synchronized 再看

### 题 4：睡眠闹钟（Alarm）
写一个类：
- **类 `Alarm` extends `Thread`**：`run()` 里循环 3 次：打印 `叮咚 i`（i 从 1 到 3），然后 `Thread.sleep(200)` 歇 200 毫秒
- main 里（已写好）：start + join，最后打印 `闹钟结束`
- 期望输出：
  ```
  叮咚 1
  叮咚 2
  叮咚 3
  闹钟结束
  ```
- 💡：`sleep` 抛 **InterruptedException**，在 run() 里只能 **try-catch 包住**（run 方法签名不能 throws）——Day15 的异常派上用场

### 题 5：卖票战（Seller）
写一个类（两个：Seller + TicketBox）：
- **类 `TicketBox`**：`static int tickets = 5`；`static synchronized boolean sell()`——有票就 `tickets--` 返回 true，没票返回 false（**synchronized 锁住，防止卖超**）
- **类 `Seller` implements `Runnable`**：`run()` 里 `while (TicketBox.sell())` 打印 `卖出一张，剩余 X`（X 是剩余票数）
- main 里（已写好）：两个线程各卖票，join 后打印 `剩余票数：` + tickets
- 期望输出：
  ```
  卖出一张，剩余 4
  卖出一张，剩余 3
  卖出一张，剩余 2
  卖出一张，剩余 1
  卖出一张，剩余 0
  剩余票数：0
  ```
  （卖出行的顺序可能交换，"5 行卖出 + 剩余 0"数量对即可）
- 💡：卖的票数 5 张不能多不能少。**先不写 synchronized 跑几次**，看会不会出现负数——经典事故现场
