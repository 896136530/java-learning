## Ex1：一行数据 → 一个对象

写两个 class：

- **`Student`**：`private String name` / `private int score` / `private String className`
  + 构造器 + 三个 getter + `toString()`（返回 `姓名 分数 班级`）
- **`RowMapper`**：
  - `static Student mapRow(ResultSet rs)` → 按列名取值，`new Student(...)` 返回
  - `static Student one(Connection conn, String name)` → 查一个人，查不到返回 `null`

期望输出：
```
张三 88 一班
分数：88
班级：一班
查不到的人：null
```

- 💡：`rs.getString("name")` / `rs.getInt("score")` / `rs.getString("class_name")`
- ⚠️ 不写 `toString()` → 打印出来是 `Student@1b6d3586`（Day10 老知识今天开始天天用）

## Ex4：⭐ 事务转账（TransferService）

- `static boolean transfer(Connection conn, String from, String to, int amount)`
- 余额不足 / 账户不存在 → **抛 `SQLException`**（`throw new SQLException("余额不足")`）

期望输出：
```
初始：钱七 1000 赵六 1000 对账：5000
--- 钱七 → 赵六 转 400 ---
返回：true
钱七：600 赵六：1400
对账：5000
--- 赵六 → 钱七 转 99999（余额不够）---
转账失败：余额不足
钱七：600 赵六：1400
对账：5000
```

- 💡 步骤：查余额 → `setAutoCommit(false)` → 两条 UPDATE → `commit()`
- 💡 失败：`catch` 里 `conn.rollback()` 然后把异常 `throw e` 出去；`finally` 里 `setAutoCommit(true)`
- ⚠️ 只写 `setAutoCommit(false)` 忘了 `commit()` → 数据一点没变（看着像"没执行"）
- ⚠️ 记住：**转账只是钱搬家**，所以对账（所有账户余额合计）前后**必须一模一样**

## Ex5：事务三道防线（SafeTransferService）

- `static String tryTransfer(...)` → 成功 `return "true"`，失败 `return 失败原因`
- 校验顺序：金额 ≤ 0 → 不能给自己转 → 付款方不存在 → 收款方不存在 → 余额不足

期望输出：
```
--- 转给不存在的人 ---
失败：账户不存在
张三余额：1000
对账：3000
--- 自己转给自己 ---
失败：不能给自己转账
对账：3000
--- 负数金额 ---
失败：金额必须大于 0
对账：3000
--- 正常转账 200 ---
成功：true
张三余额：800
李四余额：1200
对账：3000
```

- 💡：查账户用 `Setup.balanceOf(conn, owner)`，查不到返回 `-1`（这就是"没这个人"的信号）
- 💡：**参数校验都放在开事务之前**——不可能成功的事，别浪费事务
- ⚠️ 方法里**不要**自己 println，只 `return` 原因字符串（main 会拼成 `失败：账户不存在`）

## 🎯 复习：成绩管理 v2（ScoreService）

五个方法（Day26 的四个 + 事务）：

| 方法 | 干什么 |
|---|---|
| `static void ensureAccount(Connection conn, String owner, int balance)` | 没这个账户就开一个（钱七/赵六 不在 Setup 里）|
| `static int addStudent(Connection conn, String name, int score, String cls)` | 参数化插入，返回**插完后的总人数** |
| `static List<Student> ranking(Connection conn)` | 全校排名（分数降序、同分姓名升序），返回 `List<Student>` |
| `static Map<String,Integer> countByClass(Connection conn)` | 每班人数（**LinkedHashMap**）|
| `static boolean transfer(Connection conn, String from, String to, int amount)` | 事务转账，**用 boolean 通知成败** |

- 期望输出：
  ```
  插入成功，当前人数：8
  --- 排行榜前 3 ---
  第1名：钱七 100 二班
  第2名：李四 95 一班
  第3名：吴十 90 二班
  --- 每班人数 ---
  一班 3 人
  二班 3 人
  三班 2 人
  --- 钱七 → 赵六 转 400 ---
  转账结果：true
  钱七：600 赵六：1400
  对账：5000
  --- 钱七 → 赵六 转 99999（余额不足，必须不生效）---
  转账结果：false
  钱七：600 赵六：1400
  对账：5000
  ```
- ⚠️ 对账是 **5000**（张三/李四/王五 3000 + 钱七/赵六 2000）；两次转账后**必须还是 5000**
- ⚠️ `countByClass` 用 `LinkedHashMap`（`HashMap` 会打乱 SQL 排好的顺序）
- ⚠️ 余额不足时 `return false`（不抛异常）——注意和 Ex4 风格不同
