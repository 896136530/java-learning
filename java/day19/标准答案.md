## 题 1 答案（分段求和）

```java
class SumWorker implements Runnable {
    static int total = 0;

    static synchronized void merge(int v) {
        total += v;
    }

    private int start, end;

    public SumWorker(int s, int e) {
        start = s;
        end = e;
    }

    @Override
    public void run() {
        int s = 0;
        for (int i = start; i <= end; i++) {
            s += i;
        }
        merge(s);
    }
}
```

（main 输出：**总和：5050**）

**考点**：多线程**分工-合并**模式；合并共享变量必须 synchronized。
**刁钻用例**：把 `merge` 的 synchronized 去掉 → 偶尔总和不全（冒烟测试可能全过，加大 n 或多跑就现形）；把 4 个线程改成 8 个、区间缩小——模式不变。

## 题 2 答案（银行取款）

```java
class Account {
    private int balance;

    public Account(int b) {
        balance = b;
    }

    public synchronized void withdraw(int m) {
        if (balance >= m) {
            balance -= m;
        }
    }

    public int getBalance() {
        return balance;
    }
}

class Person implements Runnable {
    private Account acc;

    public Person(Account a) {
        acc = a;
    }

    @Override
    public void run() {
        for (int i = 0; i < 3; i++) {
            acc.withdraw(1000);
        }
    }
}
```

（main 输出：**余额：4000**）

**考点**：**共享同一个对象** → 锁加在对象的方法上（synchronized 方法），两线程互斥进入。
**刁钻用例**：去掉 synchronized → 余额可能 5000/6000（第二个人读到旧余额）——经典"查余额后扣款"竞态；**锁的对象要对**（锁 this=同一个 acc 才有效，锁成各自的 Person 对象就白锁）。

## 题 3 答案（线程安全列表）

```java
class ListAdder implements Runnable {
    static List<String> list = Collections.synchronizedList(new ArrayList<>());

    @Override
    public void run() {
        for (int i = 0; i < 5000; i++) {
            list.add("x");
        }
    }
}
```

（main 输出：**列表大小：10000**）

**考点**：**普通集合非线程安全** → `Collections.synchronizedList` 包装（内部每步加锁）。
**刁钻用例**：直接用 `new ArrayList<>()` → 概率性丢数据（9999/9998）甚至 `ConcurrentModificationException`；面试延伸：读多写少用 `CopyOnWriteArrayList`。

## 题 4 答案（下载进度条）

```java
class Downloader implements Runnable {
    static int progress = 0;

    @Override
    public void run() {
        for (int i = 0; i < 100; i++) {
            try {
                Thread.sleep(10);
            } catch (InterruptedException e) {
                e.printStackTrace();
            }
            progress++;
        }
    }
}
```

（main 输出：**进度：100 下载完成**）

**考点**：join 等待子线程完成（join 有 happens-before 保证，写读都有序）。
**刁钻用例**：若改成主线程**轮询**读 progress 而不 join，就要给 progress 加 `volatile`（否则可能读到旧值死循环）——这就是 volatile 的用武之地，理解即可。

## 题 5 答案（大卖票）

```java
class TicketBox {
    static int tickets = 100;

    static synchronized boolean sell() {
        if (tickets > 0) {
            tickets--;
            return true;
        }
        return false;
    }
}

class Seller implements Runnable {
    @Override
    public void run() {
        while (TicketBox.sell()) {
            // 卖出一张
        }
    }
}
```

（main 输出：**剩余票数：0**）

**考点**：并发量放大（6 窗口 × 100 张）后，**锁不牢立刻丢票/负票**——synchronized 把"判-减"包成一步。
**刁钻用例**：去掉 synchronized → 剩余票数可能是 1~5 或负数（100 张并发下几乎必翻车）；这是 Day18 Ex5 的加压版，锁的作用肉眼可见。
