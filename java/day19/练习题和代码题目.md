## 题目详情

### 题 1：分段求和（SumWorker）
写一个类：
- **类 `SumWorker` implements `Runnable`**：构造接收 `start`、`end`；`run()` 里求 start~end 的和，调 `static synchronized void merge(int v)` 把结果并进 `static int total`
- main 里（已写好）：4 个线程各算一段（1~25 / 26~50 / 51~75 / 76~100），join 后打印总和
- 期望输出：
  ```
  总和：5050
  ```
- 💡：合并是共享变量操作，**不加 synchronized 会丢和**——这就是分治思想的坑

### 题 2：银行取款（Account + Person）
写两个类：
- **类 `Account`**：私有 `int balance`；构造传初始余额；`synchronized void withdraw(int m)`（够就扣）；`int getBalance()`
- **类 `Person` implements `Runnable`**：构造收一个 Account；`run()` 里**取 3 次**，每次 1000
- main 里（已写好）：余额 10000，两个人各取 3 次，打印余额
- 期望输出：
  ```
  余额：4000
  ```
- 💡：10000 − 2×3×1000 = 4000。**withdraw 不加 synchronized 就会变成 5000/6000**——亲眼看看

### 题 3：线程安全列表（ListAdder）
写一个类：
- **类 `ListAdder`**：
  - `static List<String> list = Collections.synchronizedList(new ArrayList<>())`（要 import java.util.*）
  - `run()`：循环 5000 次 `list.add("x")`
  - 让它 implements Runnable（两个线程跑同款）
- main 里（已写好）：两个线程跑，join 后打印列表大小
- 期望输出：
  ```
  列表大小：10000
  ```
- 💡：**先试试直接 `new ArrayList<>()`** 跑几次——可能不到 10000，甚至 ConcurrentModificationException；换 synchronizedList 再看

### 题 4：下载进度条（Downloader）
写一个类：
- **类 `Downloader` implements `Runnable`**：`static int progress = 0`；`run()` 里循环 100 次：每 `Thread.sleep(10)` 后 `progress++`（模拟下载一格）
- main 里（已写好）：启动下载线程，`join()` 等它，打印进度
- 期望输出：
  ```
  进度：100 下载完成
  ```
- 💡：这次用 join 而不是轮询——**join 自带"等其他线程"的保证**；知识点里 volatile 先记个概念

### 题 5：大卖票（TicketBox + Seller）
写两个类：
- **类 `TicketBox`**：`static int tickets = 100`；`static synchronized boolean sell()`——有票就减一返回 true，没票 false
- **类 `Seller` implements `Runnable`**：`run()` 里 `while (TicketBox.sell())` 卖到没票为止
- main 里（已写好）：**6 个窗口线程**同时卖，join 后打印剩余票数
- 期望输出：
  ```
  剩余票数：0
  ```
- 💡：Day18 的 5 张变 100 张、2 窗口变 6 窗口——**并发量上去，锁不牢立刻现原形**
