## 三、P0：必须修，否则交不了

### P0-1 ⛔ 编译失败 —— `SkuService.java:97-102`

删"先查再插"时，把 **return 和方法的 `}` 一起注释掉了**：

```java
        //if (form.getCode() != null && repo.existsByCode(form.getCode())) {
           // throw new BizRuleException("商品编码已存在：" + form.getCode());   // 409
        //}                                     ← if 块注释掉，正确

        //return repo.insert(form);             ← ❌ 这行不该注释
    // }                                        ← ❌ 方法的右括号也不该注释
```

于是 `save()` 既没有返回值也没有闭合，`update()` 被当成"方法里的方法" → 编译器在 105 行报错。

**修法**（第 101、102 行恢复成代码）：

```java
        return repo.insert(form);
    }
```

### P0-2 ⛔ 运行时必 500 —— `SkuRepository.java:223`

```java
return jdbc.update("UPDATE sku SET is_deleted = 1 WHERE id = ? AND is_deleted = 0", id, 0);
```

SQL 里只有 **1 个** `?`，却传了 **2 个**参数（`id` 和 `0`）。`is_deleted = 0` 里的 `0` 是字面量，不需要占位符。执行时会抛 `Parameter index out of range (2 > number of parameters, which is 1)`，`DELETE /sku/3` → **500**。第 8 步 7 行验收全过不了。

**修法**：去掉末尾的 `, 0`：

```java
return jdbc.update("UPDATE sku SET is_deleted = 1 WHERE id = ? AND is_deleted = 0", id);
```

### P0-3 ⛔ 文案没写 —— `GlobalExceptionHandler.java:183`

```java
.body(Result.fail(ResultCode.BIZ_CONFLICT, "……"));
```

`"……"` 是题目占位符。第 6 步验收要求"409 + 一句人话"，现在返回给前端的是省略号。

**修法**（不要用 `e.getMessage()`，那里面有表名索引名）：

```java
.body(Result.fail(ResultCode.BIZ_CONFLICT, "商品编码已存在，请换一个"));
```

## 四、P1：TODO③ 只做了一半（15 分只拿 6 的原因）

`schema.sql` 和 `spring.sql.init` 都就位了，但 `DataInitializer.java`（mtime 还是 10-23）**一行没改**，于是：

1. **`init()`（84-88 行）还在 `dropTables()` + 4 个 `create*()`** → schema.sql 刚建好的表，启动时立刻被 DROP 再重建一次。DDL 搬家等于没搬，日志里也不会出现题目要求的 `[db] 表结构自检通过：...`。
2. **`reset()` 还是 H2 方言**：`SET REFERENTIAL_INTEGRITY FALSE`、`TRUNCATE TABLE xxx RESTART IDENTITY`。MySQL 不认这两个词 → `POST /db/reset` **必 500** → 第 5、7、8 步的实验全都做不了。

**修法**（题目第 5 步 ③ 的原文要求）：

- 删掉 `dropTables / createSkuTable / createOrdersTable / createAuditLogTable / createCharsetDemo` 五个方法；
- `init()` 改成：查 `information_schema.tables` 自检 3 张表在不在 + 打印库名/版本，然后只调 `seedSku()` / `seedAuditLog()`；
- `reset()` 改成：

```java
jdbc.execute("SET FOREIGN_KEY_CHECKS = 0");
try {
    jdbc.execute("TRUNCATE TABLE orders");
    jdbc.execute("TRUNCATE TABLE audit_log");
    jdbc.execute("TRUNCATE TABLE sku");
    jdbc.execute("TRUNCATE TABLE ch_demo");
    seedSku();
    seedAuditLog();
} finally {
    jdbc.execute("SET FOREIGN_KEY_CHECKS = 1");   // ⚠️ 必须在 finally
}
```

（`TRUNCATE` 自带重置自增，不用 `RESTART IDENTITY`。）
