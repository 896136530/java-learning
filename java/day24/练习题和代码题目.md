> 每题独立文件，`main` 已固定（打印语句是判题标准，**别改 main**）。
> 期望输出写在每题注释里。纯 JDK，不需要数据库。
> **难度递进**：Ex1~Ex2 写出/读入，Ex3~Ex4 追加与兜底，Ex5 解析统计，Review 综合大题。

## Ex1：把成绩单写成文件（写出）

写 `class ScoreWriter`：`static void write(String path, List<String> lines)`

- 把 `lines` 每一行写进 `path`（**覆盖**模式，不是追加）
- 中文不能乱码

- 期望输出：
  ```
  已写入 3 行
  文件存在：true
  文件非空：true
  ```
- 💡：`new PrintWriter(new OutputStreamWriter(new FileOutputStream(path), StandardCharsets.UTF_8))`；用 `try (...)` 包起来就不用手写 `close()`
- ⚠️ 忘了 close/flush → 文件是 0 字节（这是今天第一个坑）

## Ex2：把文件读回来（读入 + 解析）

写 `class ScoreReader`：`static List<String> read(String path)`

- 逐行读文件，返回所有行（每行是像 `张三,88` 这样的文本）

- 期望输出：
  ```
  共读到 3 行
  张三,88
  李四,95
  王五,76
  第一行解析：张三 考了 88 分
  ```
- 💡：`BufferedReader` + `readLine()`，**读到 `null` 就是文件末尾**
- ⚠️ 判断条件写 `line != null` 而不是 `line != ""`

## Ex3：追加一行（append 开关）

写 `class AppendUtil`：`static void append(String path, String line)`

- 在文件**末尾**追加一行；**原来那两行必须还在**

- 期望输出：
  ```
  最终 3 行
  [张三,88, 李四,95, 王五,76]
  ```
- 💡：`new FileOutputStream(path, true)`——那个 `true` 就是 append
- ⚠️ 漏掉 `true` 的后果：前两行被清空，只剩 1 行（这条判题会挂）

## Ex4：文件不存在也不能崩（异常兜底）

写 `class SafeReader`：`static List<String> read(String path)`

- 文件不存在 → 打印 `[提示] 文件不存在：<path>`，返回**空列表**
- 其他读取错误 → 打印 `[提示] 读取失败：<path>`
- 方法签名里**没有 throws**（异常必须自己接住）

- 期望输出：
  ```
  [提示] 文件不存在：no_such_file.txt
  不存在文件读到 0 行
  存在文件读到 3 行
  ```
- 💡：`catch (FileNotFoundException e)` 写在前、`catch (IOException e)` 写在后（子类在前）
- ⚠️ 返回 `null` 的话，main 里的 `.size()` 立刻 NPE → 必须返回**空列表**

## Ex5：统计与筛选（把文本变成数据）

写 `class ScoreStat`：

- `static int total(List<String> lines)` → 所有分数的总和
- `static List<String> passOnly(List<String> lines)` → 返回分数 **≥ 60** 的原始行

- 数据：`张三,88 / 李四,95 / 王五,76 / 赵六,60 / 陈七,45 / （一个空行）`
- 期望输出：
  ```
  总分：364
  及格 4 人
  张三,88
  李四,95
  王五,76
  赵六,60
  ```
- 💡：`line.split(",")` → `parts[0]` 姓名、`parts[1]` 分数；`Integer.parseInt(parts[1])`
- ⚠️ 空行必须跳过（否则 `parseInt("")` 直接抛 `NumberFormatException`）；两处判断重复，建议抽一个 `private static String[] split(String line)` 复用

## Review：成绩单导入导出系统（综合）⭐

写 `class GradeBook` 的四个方法：

| 方法 | 干什么 |
|---|---|
| `static void save(String path, Map<String,Integer> scores)` | 每行写 `姓名,分数`（UTF-8）|
| `static Map<String,Integer> load(String path)` | 读回来，放进 **LinkedHashMap**（保持顺序）|
| `static void printTop3(Map<String,Integer> scores)` | 按成绩降序打印前 3 名（全角冒号）|
| `static String average(Map<String,Integer> scores)` | 平均分，保留两位小数 |

- 数据：张三88 / 李四95 / 王五76 / 赵六60 / 钱七100
- 期望输出：
  ```
  已保存 5 人
  读回 5 人
  第1名：钱七 100
  第2名：李四 95
  第3名：张三 88
  平均分：83.80
  ```
- 💡：
  - `save`：`for (Map.Entry<String,Integer> e : scores.entrySet())` → `pw.println(e.getKey() + "," + e.getValue())`
  - `load`：`split(",")` → `map.put(parts[0], Integer.parseInt(parts[1]))`；空行 `continue`
  - `printTop3`：**Day23 的原题再来一遍**——entrySet 倒进 List → 按 value 降序（同分按姓名升序）→ 取前 3
  - `average`：`(double) sum / size` 再 `String.format("%.2f", ...)`
- ⚠️ 三个易错点：全角冒号 `：`、`Math.min(3, list.size())` 防越界、`double` 转换（不然输出 `83` 或 `83.0`）
