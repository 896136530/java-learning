## Ex1：把成绩单写成文件

**考点**：字符流写出、try-with-resources、UTF-8 编码。

```java
class ScoreWriter {
    static void write(String path, List<String> lines) throws IOException {
        try (PrintWriter pw = new PrintWriter(
                new OutputStreamWriter(new FileOutputStream(path), StandardCharsets.UTF_8))) {
            for (String line : lines) {
                pw.println(line);
            }
        }
    }
}
```

- 期望输出：`已写入 3 行` / `文件存在：true` / `文件非空：true`
- 易错：不用 try-with-resources 又不 close → 文件 0 字节；不指定 UTF-8 → 中文乱码

## Ex2：把文件读回来

**考点**：`readLine()` 读到末尾返回 `null`；逐行收集。

```java
class ScoreReader {
    static List<String> read(String path) throws IOException {
        List<String> lines = new ArrayList<>();
        try (BufferedReader br = new BufferedReader(
                new InputStreamReader(new FileInputStream(path), StandardCharsets.UTF_8))) {
            String line;
            while ((line = br.readLine()) != null) {
                lines.add(line);
            }
        }
        return lines;
    }
}
```

- 期望输出：`共读到 3 行` + 三行原文 + `第一行解析：张三 考了 88 分`
- 易错：把结束条件写成 `line != ""` → 死循环或读到最后一行就停
- 写法细节：`while ((line = br.readLine()) != null)` 是"读一行、判断、再进循环"的经典一行式

## Ex3：追加一行（append）

**考点**：`FileOutputStream(path, true)` 的 append 开关。

```java
class AppendUtil {
    static void append(String path, String line) throws IOException {
        try (PrintWriter pw = new PrintWriter(
                new OutputStreamWriter(new FileOutputStream(path, true), StandardCharsets.UTF_8))) {
            pw.println(line);
        }
    }
}
```

- 期望输出：`最终 3 行` / `[张三,88, 李四,95, 王五,76]`
- 易错：漏掉 `true` → 只剩 1 行（旧数据被覆盖）

## Ex4：文件不存在也不能崩

**考点**：受检异常处理；catch 顺序；**返回空集合而不是 null**。

```java
class SafeReader {
    static List<String> read(String path) {
        List<String> lines = new ArrayList<>();
        try (BufferedReader br = new BufferedReader(
                new InputStreamReader(new FileInputStream(path), StandardCharsets.UTF_8))) {
            String line;
            while ((line = br.readLine()) != null) {
                lines.add(line);
            }
        } catch (FileNotFoundException e) {
            System.out.println("[提示] 文件不存在：" + path);
        } catch (IOException e) {
            System.out.println("[提示] 读取失败：" + path);
        }
        return lines;
    }
}
```

- 期望输出：`[提示] 文件不存在：no_such_file.txt` / `不存在文件读到 0 行` / `存在文件读到 3 行`
- 易错 ①：抓到异常后 `return null` → 调用方 NPE。**空集合是"安全的空值"**
- 易错 ②：`catch (IOException e)` 写在 `catch (FileNotFoundException e)` 前面 → 编译报错（子类已被父类捕获）

## Ex5：统计与筛选

**考点**：`split` + `parseInt`、"先校验再解析"的防御式写法、抽私有小方法。

```java
class ScoreStat {
    static int total(List<String> lines) {
        int sum = 0;
        for (String line : lines) {
            String[] parts = split(line);
            if (parts != null) {
                sum += Integer.parseInt(parts[1]);
            }
        }
        return sum;
    }

    static List<String> passOnly(List<String> lines) {
        List<String> result = new ArrayList<>();
        for (String line : lines) {
            String[] parts = split(line);
            if (parts != null && Integer.parseInt(parts[1]) >= 60) {
                result.add(line);
            }
        }
        return result;
    }

    private static String[] split(String line) {
        if (line == null || line.trim().isEmpty()) {
            return null;                 // 空行：不合法
        }
        String[] parts = line.split(",");
        return parts.length == 2 ? parts : null;   // 不是两段：不合法
    }
}
```

- 期望输出：`总分：364` / `及格 4 人` / 四行及格名单
- 易错：不判空行 → `parseInt("")` 抛 `NumberFormatException`（数据的最后一个元素就是空行）
- 加分理解：`split` 里返回 `null` 表示"这行不合法"——把"校验"和"业务"分开，两个方法都干净

## Review：成绩单导入导出系统（全家桶）

**考点**：写文件 → 读文件 → 还原成 Map → 排行榜（Day23 的 entrySet + sort）→ 平均分格式化。

```java
class GradeBook {
    static void save(String path, Map<String, Integer> scores) throws IOException {
        try (PrintWriter pw = new PrintWriter(
                new OutputStreamWriter(new FileOutputStream(path), StandardCharsets.UTF_8))) {
            for (Map.Entry<String, Integer> e : scores.entrySet()) {
                pw.println(e.getKey() + "," + e.getValue());
            }
        }
    }

    static Map<String, Integer> load(String path) throws IOException {
        Map<String, Integer> map = new LinkedHashMap<>();
        try (BufferedReader br = new BufferedReader(
                new InputStreamReader(new FileInputStream(path), StandardCharsets.UTF_8))) {
            String line;
            while ((line = br.readLine()) != null) {
                if (line.trim().isEmpty()) {
                    continue;
                }
                String[] parts = line.split(",");
                map.put(parts[0], Integer.parseInt(parts[1]));
            }
        }
        return map;
    }

    static void printTop3(Map<String, Integer> scores) {
        List<Map.Entry<String, Integer>> list = new ArrayList<>(scores.entrySet());
        list.sort((a, b) -> {
            int c = Integer.compare(b.getValue(), a.getValue());   // 成绩降序
            return c != 0 ? c : a.getKey().compareTo(b.getKey());  // 同分按姓名升序
        });
        for (int i = 0; i < Math.min(3, list.size()); i++) {
            System.out.println("第" + (i + 1) + "名："
                    + list.get(i).getKey() + " " + list.get(i).getValue());
        }
    }

    static String average(Map<String, Integer> scores) {
        int sum = 0;
        for (int v : scores.values()) {
            sum += v;
        }
        return String.format("%.2f", (double) sum / scores.size());
    }
}
```

- 期望输出：`已保存 5 人` / `读回 5 人` / `第1名：钱七 100` / `第2名：李四 95` / `第3名：张三 88` / `平均分：83.80`
- 易错 ①：`load` 用 `HashMap` 也能跑，但顺序会乱 → 用 `LinkedHashMap` 保持文件顺序
- 易错 ②：打印 `list.get(i)` 直接输出 `Map.Entry` → 会得到 `钱七=100`（`=` 而不是空格）→ 必须 `getKey()` + `getValue()`
- 易错 ③：`for (int i = 0; i < 3; i++)` 写死 3 → 数据不足 3 人时 `IndexOutOfBoundsException` → 用 `Math.min(3, list.size())`
- 易错 ④：`sum / scores.size()` 两个 int 相除 → `83.0`，必须 `(double) sum`

## 六题一句话总复习

| 题 | 武器 | 一句话 |
|---|---|---|
| Ex1 | 字符流写出 | try-with-resources + UTF-8，写完文件不能是空的 |
| Ex2 | 字符流读入 | `readLine()` 读到 `null` 为止 |
| Ex3 | append 开关 | `new FileOutputStream(path, true)`，一个 `true` 决定覆盖还是追加 |
| Ex4 | 异常兜底 | 受检异常自己接住，**返回空集合不返回 null** |
| Ex5 | 解析 | 先校验（空行/段数）再 parseInt |
| Review | 全家桶 | 写出去、读回来、还原成 Map、再排前 3 名 |

## 附：本章两句话（面试可背）

1. **"内存管运算，文件管留存"**——数据要活过进程，就得落盘（文件或数据库）。
2. **"读文本用字符流 + 显式 UTF-8"**——`InputStreamReader/OutputStreamWriter` 上指定 `StandardCharsets.UTF_8`，是 Windows 上不乱码的最短路径。
