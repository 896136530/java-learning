# Day 14 知识点：其他集合轻扫（HashSet / LinkedList / Queue）

> 前提：Day 12 ArrayList、Day 13 HashMap 已过关。今天把集合家族最后三张牌认全——**不深挖，重点是"什么时候用哪个"**。

## 1. 集合家族地图（面试直接默写）

| 容器 | 特点 | 经典用途 |
|---|---|---|
| ArrayList | 按下标找，有顺序 | 存列表、遍历（主力）|
| HashMap | 按"键"找，键唯一，无顺序 | 查表、统计 |
| **HashSet** | **元素唯一**，无顺序 | 去重、查"在不在" |
| **LinkedList** | **两头操作快** | 头尾频繁增删、当队列/栈用 |
| **Queue** | **先进先出**（排队）| 叫号、任务队列 |

## 2. HashSet：去重神器

```java
import java.util.HashSet;

HashSet<String> set = new HashSet<>();
set.add("小明");     // 返回 true（成功）
set.add("小明");     // 返回 false（重复，没加进去！）
set.size();          // 1
set.contains("小明"); // true —— 查在不在 O(1)
for (String s : set) { ... }   // 遍历（顺序不定！）
```

**铁规矩**：里面的元素**不可能重复**。`add` 有返回值：`true`=加进去了，`false`=重复被拒。
**坑**：和 HashMap 一样**没顺序**，别依赖打印顺序。

## 3. LinkedList：两头快的列表

```java
import java.util.LinkedList;

LinkedList<String> list = new LinkedList<>();
list.addLast("a");       // 尾部加（= add）
list.addFirst("x");      // 头部加
list.getFirst();         // 看头
list.getLast();          // 看尾
list.removeFirst();      // 拿走头
list.removeLast();       // 拿走尾
```

**对比**：ArrayList 查中间快（按下标直取）；LinkedList **头尾增删快**（改两头指针就行，不用搬元素），但按下标取中间慢（要一个个走）。
> 记忆：ArrayList 像"书架"（挨着放，翻哪本都快）；LinkedList 像"火车车厢链"（前后加卸快，找中间车厢要一节节走）。

## 4. Queue：排队叫号（先进先出）

```java
import java.util.Queue;
import java.util.LinkedList;

Queue<String> q = new LinkedList<>();  // Queue 是接口，LinkedList 是"排队版"实现
q.offer("张三");   // 入队（排队尾）
q.offer("李四");
q.peek();          // 偷看队头是谁（不拿走）
q.poll();          // 出队（队头的先走并拿走）
q.isEmpty();       // 队空了吗
```

**铁规矩：谁先来谁先走（FIFO）**——先进先出。
**坑**：`poll()` 空队返回 **null**（不崩）；`peek()` 空队也是 null。

## 5. 一张图记住选择（背这个）

> **去重 → HashSet；按名字查 → HashMap；头尾折腾 → LinkedList；排队处理 → Queue；兜底 → ArrayList。**

面试问"你用什么存"直接对号入座，答完加一句为什么，就是满分回答。
