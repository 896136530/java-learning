## 题目详情

### 题 1：去重统计（SetStats）

写一个类：
- **类 `SetStats`**：`static int uniqueCount(String[] names)`——返回**不重复**的名字个数
- `main` 里（已写好）：`{"小明","小红","小明","小刚","小红"}`
- 期望输出：
  ```
  不重复人数：3
  ```
- 💡：HashSet 加进去自动去重，最后 `set.size()` 就是答案——加完不用数

### 题 2：叫号排队（QueueSim）

写一个类：
- **类 `QueueSim`**：`static String serveNext(Queue<String> queue)`——让队头的人出队并返回他
- `main` 里（已写好）：张三、李四、王五依次入队
- 期望输出：
  ```
  叫号：张三
  下一个：李四
  还剩：2
  ```
- 💡：`queue.poll()` 拿走队头并返回；`peek()` 偷看不拿走；Queue 是接口，用 `LinkedList<>()` 当实现（main 里已写好）

### 题 3：头尾操作（LinkedOps）

写一个类：
- **类 `LinkedOps`**：三个 static 方法——
  - `String first(LinkedList<String> list)`：看头元素
  - `String last(LinkedList<String> list)`：看尾元素
  - `void pushFront(LinkedList<String> list, String s)`：往头部加一个
- `main` 里（已写好）：`[a, b, c]`
- 期望输出：
  ```
  头：a
  头：x
  尾：c
  长度：4
  ```
- 💡：看头 `getFirst()`，看尾 `getLast()`，头插 `addFirst()`；长度还是 `size()`

### 题 4：找共同元素（WordSet）

写一个类：
- **类 `WordSet`**：`static int common(String[] a, String[] b)`——返回两个数组**都出现**的元素个数
- `main` 里（已写好）：`{猫,狗,鸟}` 和 `{狗,鸟,鱼}`
- 期望输出：
  ```
  共同：2
  ```
- 💡：先把 a 全部塞进 HashSet（自动去重），再遍历 b 用 `contains` 逐个问"你在不在"

### 题 5：任务队列耗时（TaskQueue）

写一个类：
- **类 `TaskQueue`**：`static int totalWait(Queue<Integer> jobs)`——把队列里的任务**逐个 poll 出来**，累加处理时间返回总耗时
- `main` 里（已写好）：任务时长 5、3、7 入队
- 期望输出：
  ```
  总耗时：15
  队列空？true
  ```
- 💡：`while (!jobs.isEmpty())` 循环 + `poll()` 拿一个加一个——处理完队列自然清空；空队进来返回 0 别崩
