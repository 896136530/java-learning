## 题 1 答案（去重统计）

```java
class SetStats {
    public static int uniqueCount(String[] names) {
        HashSet<String> set = new HashSet<>();
        for (String n : names) {
            set.add(n);        // 重复的自动被拒
        }
        return set.size();
    }
}
```

（main 输出：**不重复人数：3**）

**考点**：HashSet 自动去重，`size()` 即答案；`add` 重复元素返回 false（事实：大工程里常用这个返回值计数）。
**刁钻用例**：全重复数组 `{"a","a"}` → 1 不崩；空数组 → 0。

## 题 2 答案（叫号排队）

```java
class QueueSim {
    public static String serveNext(Queue<String> queue) {
        return queue.poll();    // 拿队头并删掉（先进先出）
    }
}
```

（main 输出：**叫号：张三** / **下一个：李四** / **还剩：2**）

**考点**：`poll()` 出队并返回；`peek()` 只看不拿。
**刁钻用例**：空队 `poll()` 返回 **null**（不抛异常）——真正"没了"和"叫了没人"都靠 null 判断。

## 题 3 答案（头尾操作）

```java
class LinkedOps {
    public static String first(LinkedList<String> list) {
        return list.getFirst();
    }

    public static String last(LinkedList<String> list) {
        return list.getLast();
    }

    public static void pushFront(LinkedList<String> list, String s) {
        list.addFirst(s);
    }
}
```

（main 输出：**头：a** / **头：x** / **尾：c** / **长度：4**）

**考点**：`getFirst/getLast/addFirst` 三件套；头插不挤掉尾。
**刁钻用例**：空链表 `getFirst()` → NoSuchElementException——先判 `isEmpty()`；`pushFront` 后 `size()` 正常 +1。

## 题 4 答案（找共同元素）

```java
class WordSet {
    public static int common(String[] a, String[] b) {
        HashSet<String> set = new HashSet<>();
        for (String s : a) {
            set.add(s);
        }
        int count = 0;
        for (String s : b) {
            if (set.contains(s)) {
                count++;
            }
        }
        return count;
    }
}
```

（main 输出：**共同：2**）

**考点**：HashSet 做"集合 A"，遍历 B 用 `contains` 查——交集模板，刷题高频。
**刁钻用例**：b 里元素重复（`{"狗","狗"}`）→ 会数 2 次！要严格交集先去重 b 或统计时跳过已算过的——知道这个坑就行。

## 题 5 答案（任务队列耗时）

```java
class TaskQueue {
    public static int totalWait(Queue<Integer> jobs) {
        int total = 0;
        while (!jobs.isEmpty()) {
            total = total + jobs.poll();   // 拿一个处理一个
        }
        return total;
    }
}
```

（main 输出：**总耗时：15** / **队列空？true**）

**考点**：`while + poll` 消费队列的**标准清空模式**（处理完队列自然为空）；`poll` 返回的 Integer 自动拆箱累加。
**刁钻用例**：空队 → while 不执行 → 返回 0；`peek` 循环会死循环（永远不空），必须 poll。
