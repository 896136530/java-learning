## Ex1：第一次查询（BasicDao）

- `static int countAll(Connection conn)` → 全校人数（`SELECT COUNT(*)`）
- `static Integer findScoreByName(Connection conn, String name)` → 查不到返回 `null`
- 期望输出：
  ```
  全校人数：7
  李四：95
  陈七：无成绩
  注入尝试：无成绩
  ```
- 💡：`PreparedStatement` + `SELECT score FROM student WHERE name = ?`；`rs.next()` 为 false 就 `return null`
- ⚠️ 返回类型必须是 **`Integer`**（Day23 的老朋友：`int` 装不下 null）；最后那行"注入尝试"用了字符串拼接写法会返回 100——参数化才是对的

## Ex2：ResultSet → List（ParamDao）

- `static List<String> findByClass(Connection conn, String cls)` → 每项 `"姓名 分数"`，按分数降序
- 期望输出：
  ```
  一班 3 人
  李四 95
  张三 88
  王五 76
  三班 2 人
  周九 82
  孙八 45
  ```
- 💡：`while (rs.next())` 逐行走；`rs.getString("name")` + `rs.getInt("score")`
- ⚠️ 别忘了 SQL 里的 `ORDER BY score DESC`（否则顺序不保证）

## Ex3：参数化改与删（UpdateDao）

- `static int addScore(Connection conn, String cls, int delta)` → 返回受影响行数
- `static int deleteBelow(Connection conn, int min)` → 返回受影响行数
- 期望输出：
  ```
  一班加分受影响行数：3
  删除不及格受影响行数：1
  --- 剩余 ---
  张三 93 一班
  李四 100 一班
  王五 81 一班
  赵六 60 二班
  钱七 100 二班
  周九 82 三班
  ```
- 💡：用 `executeUpdate()`；`score = score + ?` 里 `?` 放**加多少**
- ⚠️ `setInt` 的序号要和 `?` 一一对应（1、2 两个坑别填反）

## Ex4：聚合查询（AggDao）

- `static String avgOfClass(Connection conn, String cls)` → 例 `"86.33"`
- `static String avgAll(Connection conn)` → 全校平均分
- 期望输出：
  ```
  一班平均分：86.33
  二班平均分：80.00
  三班平均分：63.50
  全校平均分：78.00
  ```
- 💡：`SELECT ROUND(AVG(score), 2) FROM student`；结果用 `rs.getDouble(1)` 取，再 `String.format("%.2f", v)`
- ⚠️ 注意 `78.00`——`%.2f` 会补零，不是 `78`

## Ex5：排行榜（RankDao）

- `static List<String> ranking(Connection conn, int limit)` → 分数降序、**同分姓名升序**、取前 `limit`
- 期望输出：
  ```
  钱七 100
  李四 95
  张三 88
  --- 前 5 ---
  钱七 100
  李四 95
  张三 88
  周九 82
  王五 76
  ```
- 💡：`ORDER BY score DESC, name ASC LIMIT ?`——**LIMIT 也能用 `?` 参数化**
- ⚠️ 同分不加姓名兜底 → 顺序不稳定（Day23 踩过的坑）

## 🎯 复习：成绩管理系统 v1（ScoreService）

四个方法拼成一个小系统：

| 方法 | 干什么 |
|---|---|
| `static void insert(Connection, String name, int score, String cls)` | 参数化插入 |
| `static List<String> ranking(Connection)` | 全校排名（分数降序、同分姓名升序）|
| `static String avgAll(Connection)` | 全校平均分（2 位小数）|
| `static Map<String,Integer> countByClass(Connection)` | 每班人数（用 **LinkedHashMap**）|

- 期望输出：
  ```
  插入成功，当前人数：8
  --- 排行榜前 3 ---
  第1名：钱七 100
  第2名：李四 95
  第3名：吴十 90
  全校平均分：79.50
  --- 每班人数 ---
  一班 3 人
  二班 3 人
  三班 2 人
  ```
- 💡：`countByClass` 的 SQL：`SELECT class_name, COUNT(*) FROM student GROUP BY class_name ORDER BY COUNT(*) DESC, class_name`；**必须用 `LinkedHashMap`** 才能保住 SQL 排好的顺序
- ⚠️ 插入的是"吴十 90 二班"，插完人数从 7 变 8、平均分也跟着变（79.50）
