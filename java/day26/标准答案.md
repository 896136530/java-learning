## Ex1：第一次查询（BasicDao）

```java
class BasicDao {
    static int countAll(Connection conn) throws SQLException {
        try (Statement st = conn.createStatement();
             ResultSet rs = st.executeQuery("SELECT COUNT(*) FROM student")) {
            rs.next();
            return rs.getInt(1);
        }
    }

    static Integer findScoreByName(Connection conn, String name) throws SQLException {
        String sql = "SELECT score FROM student WHERE name = ?";
        try (PreparedStatement ps = conn.prepareStatement(sql)) {
            ps.setString(1, name);
            try (ResultSet rs = ps.executeQuery()) {
                if (rs.next()) {
                    return rs.getInt("score");
                }
                return null;
            }
        }
    }
}
```

**实测输出**：`全校人数：7` / `李四：95` / `陈七：无成绩` / `注入尝试：无成绩`

- 易错：返回类型写 `int` → 查不到时 `return null` 编译不过；真写了 `rs.getInt` 又没判 `next()` → `Before start of result set`
- 加分理解：`"王五' OR '1'='1"` 这个名字用**拼接**写法会变成 `WHERE name = '王五' OR '1'='1'`（条件恒真，返回钱七的 100 分）——**这就是 SQL 注入**，参数化写法把它当普通字符串，所以"无成绩" ✅

## Ex2：ResultSet → List（ParamDao）

```java
class ParamDao {
    static List<String> findByClass(Connection conn, String cls) throws SQLException {
        List<String> list = new ArrayList<>();
        String sql = "SELECT name, score FROM student WHERE class_name = ? ORDER BY score DESC";
        try (PreparedStatement ps = conn.prepareStatement(sql)) {
            ps.setString(1, cls);
            try (ResultSet rs = ps.executeQuery()) {
                while (rs.next()) {
                    list.add(rs.getString("name") + " " + rs.getInt("score"));
                }
            }
        }
        return list;
    }
}
```

**实测输出**：`一班 3 人` / 李四 95 / 张三 88 / 王五 76 / `三班 2 人` / 周九 82 / 孙八 45

- 易错：忘了 `ORDER BY` → 顺序不保证（本机小表看起来"刚好对"，数据一多就乱）
- 加分理解：`rs.getString("name")` 比 `rs.getString(1)` 更抗改动（SQL 里加一列，序号全错）

## Ex3：参数化改与删（UpdateDao）

```java
class UpdateDao {
    static int addScore(Connection conn, String cls, int delta) throws SQLException {
        String sql = "UPDATE student SET score = score + ? WHERE class_name = ?";
        try (PreparedStatement ps = conn.prepareStatement(sql)) {
            ps.setInt(1, delta);
            ps.setString(2, cls);
            return ps.executeUpdate();
        }
    }

    static int deleteBelow(Connection conn, int min) throws SQLException {
        String sql = "DELETE FROM student WHERE score < ?";
        try (PreparedStatement ps = conn.prepareStatement(sql)) {
            ps.setInt(1, min);
            return ps.executeUpdate();
        }
    }
}
```

**实测输出**：`一班加分受影响行数：3` / `删除不及格受影响行数：1` / 剩余 6 人（张三93、李四100、王五81、赵六60、钱七100、周九82）

- 易错：`setInt(1, delta)` / `setString(2, cls)` 顺序写反 → 要么报错，要么把班级当数字
- 加分理解：返回的"受影响行数"是**结果，不是错误码**——返回 0 表示 WHERE 没匹配（比如班级名打错），程序**没出错**

## Ex4：聚合查询（AggDao）

```java
class AggDao {
    static String avgOfClass(Connection conn, String cls) throws SQLException {
        String sql = "SELECT ROUND(AVG(score), 2) FROM student WHERE class_name = ?";
        try (PreparedStatement ps = conn.prepareStatement(sql)) {
            ps.setString(1, cls);
            try (ResultSet rs = ps.executeQuery()) {
                rs.next();
                return String.format("%.2f", rs.getDouble(1));
            }
        }
    }

    static String avgAll(Connection conn) throws SQLException {
        try (Statement st = conn.createStatement();
             ResultSet rs = st.executeQuery("SELECT ROUND(AVG(score), 2) FROM student")) {
            rs.next();
            return String.format("%.2f", rs.getDouble(1));
        }
    }
}
```

**实测输出**：一班 86.33 / 二班 80.00 / 三班 63.50 / 全校 **78.00**

- 易错：`String.format("%.1f", …)` → `78.0`；不 format 直接 `getDouble` → 可能 `77.99999`
- 加分理解：为什么让 SQL 算？**省网络传输 + 省内存**。100 万行学生的平均分，这样只传回 1 个数字

## Ex5：排行榜（RankDao）

```java
class RankDao {
    static List<String> ranking(Connection conn, int limit) throws SQLException {
        List<String> list = new ArrayList<>();
        String sql = "SELECT name, score FROM student ORDER BY score DESC, name ASC LIMIT ?";
        try (PreparedStatement ps = conn.prepareStatement(sql)) {
            ps.setInt(1, limit);
            try (ResultSet rs = ps.executeQuery()) {
                while (rs.next()) {
                    list.add(rs.getString("name") + " " + rs.getInt("score"));
                }
            }
        }
        return list;
    }
}
```

**实测输出**：前 3 = 钱七 100 / 李四 95 / 张三 88；前 5 再加 周九 82 / 王五 76

- 易错：`LIMIT '3'`（拼字符串）→ 语法错或注入；用 `setInt` 才对
- 加分理解：`LIMIT ?` 参数化还有个好处——**分页**（第 2 页就是 `LIMIT ?, ?`）

## 🎯 复习：成绩管理系统 v1（ScoreService）

```java
class ScoreService {
    static void insert(Connection conn, String name, int score, String cls) throws SQLException {
        String sql = "INSERT INTO student (name, score, class_name) VALUES (?, ?, ?)";
        try (PreparedStatement ps = conn.prepareStatement(sql)) {
            ps.setString(1, name);
            ps.setInt(2, score);
            ps.setString(3, cls);
            ps.executeUpdate();
        }
    }

    static List<String> ranking(Connection conn) throws SQLException {
        List<String> list = new ArrayList<>();
        String sql = "SELECT name, score FROM student ORDER BY score DESC, name ASC";
        try (Statement st = conn.createStatement();
             ResultSet rs = st.executeQuery(sql)) {
            while (rs.next()) {
                list.add(rs.getString("name") + " " + rs.getInt("score"));
            }
        }
        return list;
    }

    static String avgAll(Connection conn) throws SQLException {
        try (Statement st = conn.createStatement();
             ResultSet rs = st.executeQuery("SELECT AVG(score) FROM student")) {
            rs.next();
            return String.format("%.2f", rs.getDouble(1));
        }
    }

    static Map<String, Integer> countByClass(Connection conn) throws SQLException {
        Map<String, Integer> map = new LinkedHashMap<>();
        String sql = "SELECT class_name, COUNT(*) FROM student GROUP BY class_name "
                + "ORDER BY COUNT(*) DESC, class_name";
        try (Statement st = conn.createStatement();
             ResultSet rs = st.executeQuery(sql)) {
            while (rs.next()) {
                map.put(rs.getString(1), rs.getInt(2));
            }
        }
        return map;
    }
}
```

**实测输出**：

```
插入成功，当前人数：8
--- 排行榜前 3 ---
第1名：钱七 100
第2名：李四 95
第3名：吴十 90
全校平均分：79.50
--- 每班人数 ---
一班 3 人
二班 3 人
三班 2 人
```

- 易错 ①：`countByClass` 用 `HashMap` → 输出顺序乱（SQL 排好的顺序白排了）→ 用 **`LinkedHashMap`**
- 易错 ②：`GROUP BY` 的 `ORDER BY` 想"人数降序、同人数按班级名升序" → `ORDER BY COUNT(*) DESC, class_name`
- 加分理解：插了吴十（90 分）之后，平均分从 78.00 变 **79.50**、人数 7→8——**数据变了结果就该变**，这正是"程序连数据库"的意义

## 六题一句话总复习

| 题 | 武器 | 一句话 |
|---|---|---|
| Ex1 | `PreparedStatement` | `?` 占位符让参数永远只是"值"——SQL 注入的克星 |
| Ex2 | `ResultSet` | `while (rs.next())` 一行行走，组装成 List |
| Ex3 | `executeUpdate` | 返回值是**受影响行数**，0 行不是错误 |
| Ex4 | 聚合下推 | 能 SQL 算的别搬回 Java（省 IO 省内存） |
| Ex5 | `LIMIT ?` | 排序 + 取前 N 都在数据库里干完 |
| Review | 全拼装 | 插入 / 排名 / 平均 / 分组，四合一 |

## 附：两句面试可背

1. **"JDBC 六步"**：注册驱动（现在自动）→ 拿连接 → 建 `PreparedStatement` → 设参数 → `executeQuery/executeUpdate` → 关资源（try-with-resources）。
2. **"为什么用 PreparedStatement"**：① 防 SQL 注入（参数不当语法解析）② 预编译，批量执行更快 ③ 不用自己转义引号、日期等类型。
