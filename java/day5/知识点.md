# Day 5 知识点：类与对象（面向对象入门）

> 本文件只讲知识点，练习题见《练习题和代码题目.md》，做完再看《标准答案.md》。

## 1. 为什么需要面向对象
之前写代码是"面向过程"：上来就是变量、循环、方法，全堆在 `main` 里。
但真实世界是**由对象组成的**：学生、老师、汽车、订单……每个对象都有
**属性**（名字、年龄）和**行为**（吃饭、开车）。

- **类（class）** = 对象的图纸 / 模板
- **对象（object）** = 按图纸造出来的实物

## 2. 类与对象的第一印象
```java
// 定义类（画图纸）：描述"猫"有什么属性和行为
class Cat {
    String name;    // 属性：名字
    int age;        // 属性：年龄

    void meow() {   // 方法：行为
        System.out.println(name + "：喵~");
    }
}

// main 里创建对象（按图纸造一只真猫）
Cat c = new Cat();
c.name = "小白";
c.age = 2;
c.meow();           // 输出：小白：喵~
```

## 3. 定义类的基本格式（背下来）
```java
class 类名 {            // 类名用大驼峰 Cat、Student
    数据类型 属性名;      // 属性：描述"有什么"

    返回值类型 方法名() {  // 方法：描述"能做什么"
    }
}
```

## 4. new 创建对象
```java
类名 变量名 = new 类名();
```
- `new` = 按图纸造一台新机器
- **每次 `new` 都是独立的一个对象**，改一个不影响另一个

## 5. 构造方法（重点）
- **名字必须和类名一模一样**，且没有返回值类型（连 void 都不写）
- 创建对象时**自动执行**，用来给属性"填初始值"
- 你不写构造方法，Java 会默认送一个"无参构造"

```java
class Student {
    String name;
    int age;

    // 自己写的构造方法（new 时自动调用）
    Student(String n, int a) {
        name = n;
        age = a;
    }
}

Student s = new Student("小明", 18);   // 创建时自动把 name/age 填好
```

## 6. this 关键字（区分"参数"和"属性"）
当参数名和属性名**同名**时，`this` 指"当前对象自己的属性"：
```java
Student(String name, int age) {
    this.name = name;    // 左边 name 是属性，右边 name 是参数
    this.age = age;      // this 就是"这个对象自己"
}
```
> 参数和属性不同名时可以不写 this，但同名时必须写，不然 `name = name` 就是自己给自己，属性没被赋上值（经典 bug）。

## 7. 常见坑（记住）
1. **`public class` 的类名必须和文件名一致**（如 `Day5_Ex1.java` 里 `public class Day5_Ex1`）
2. 普通方法、属性**不写 static**；`main` 里的 `static` 是固定写法（后面学到再说区别）
3. 属性有默认值：数字 → 0，`boolean` → false，String 等引用类型 → null
4. 一个 `.java` 文件只能有一个 `public class`（想再加类就写不带 public 的）
5. 构造方法名写错成别的 → 编译报错；`new` 忘写 → 编译报错
6. 不 new 直接 `s.name` → 空指针（NullPointerException），先 new 再用
