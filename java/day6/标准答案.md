## 题 1 答案（Student 封装入门）

```java
class Student {
    private String name;
    private int age;

    public String getName() {
        return name;
    }
    public void setName(String name) {
        this.name = name;   // this 区分参数和属性
    }
    public int getAge() {
        return age;
    }
    public void setAge(int age) {
        this.age = age;
    }

    void printInfo() {
        System.out.println("我叫" + name + "，今年" + age + "岁");
    }
}
```

（main 里用 setter 赋值、getter 读取 → 输出 名字：小明 / 年龄：18 / 我叫小明，今年18岁）

## 题 2 答案（Person 年龄校验）

```java
class Person {
    private String name;
    private int age;

    public void setAge(int age) {
        if (age < 0 || age > 150) {
            System.out.println("年龄不合法：" + age);
            return;              // 拒绝修改，直接退出
        }
        this.age = age;
    }

    public int getAge() {
        return age;
    }
}
```

（先 setAge(20) → setAge(-5) 被拒 → setAge(999) 被拒 → getAge() 输出 20）

## 题 3 答案（BankAccount 封装版）

```java
class BankAccount {
    private double balance;

    BankAccount(double balance) {
        this.balance = balance;
    }

    void deposit(double money) {
        if (money < 0) {
            System.out.println("存款金额不能为负");
            return;
        }
        balance += money;
    }

    void withdraw(double money) {
        if (money < 0) {
            System.out.println("取款金额不能为负");
        } else if (balance < money) {
            System.out.println("余额不足");
        } else {
            balance -= money;
        }
    }

    double getBalance() {
        return balance;
    }
}
```

## 题 5 答案（Employee 综合封装）

```java
class Employee {
    private int id;
    private String name;
    private double salary;

    Employee(int id, String name, double salary) {
        this.id = id;
        this.name = name;
        this.salary = salary;
    }

    public int getId() { return id; }
    public String getName() { return name; }
    public double getSalary() { return salary; }

    public void setSalary(double salary) {
        if (salary < 0) {
            System.out.println("薪资不合法：" + salary);
            return;
        }
        this.salary = salary;
    }

    void raise(double amount) {
        if (amount <= 0) {
            System.out.println("加薪金额不合法：" + amount);
            return;
        }
        salary += amount;
    }
}
```

（流程：setSalary(-100) 被拒 → raise(500) 变 8500 → setSalary(9000) 改成 9000 → 输出 员工：1  张三  9000.0）
