## 题目详情

### 题 1：声明 8 种基本类型
声明 `byte`、`short`、`int`、`long`、`float`、`double`、`char`、`boolean` 八个变量各一个，用 `System.out.println` 打印出来。
提示：long 要加 `L`，float 要加 `f`，char 用单引号。

### 题 2：验证运算表达式
预测下面每个表达式的结果，然后用 `println` 打印出来验证：
```
7 / 2       7.0 / 2       7 % 2       (int) 3.99       (int) -3.99
```

### 题 3：圆的面积
半径 `r = 5.5`，用 `3.1415926 * r * r` 计算面积并打印。

### 题 4：交换两个变量
`int a = 3, b = 7;` 交换 a、b 的值。
- 第一步：借助第三个临时变量
- 第二步（挑战）：不借助第三个变量，用加减法

### 题 5：溢出实验 + 思考
- 实验 1：`int x = 9000000000;` 编译会报什么错？改成 `long` 加 `L` 后缀试试。
- 实验 2：`int y = 2000000000 * 4;` 预测 y 是多少，打印出来看看。
- 思考：为什么 `int` 存不下 90 亿？`long` 为什么可以？
