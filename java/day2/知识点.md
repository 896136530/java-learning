# Day 2 知识点：运算符与流程控制

> 本文件只讲知识点，练习题见《练习题和代码题目.md》，做完再看《标准答案.md》。

## 1. 运算符

| 类别 | 符号 | 说明 |
|---|---|---|
| 算术 | `+ - * / %` | `%` 是取余数；`7/2=3`（整数除法） |
| 自增自减 | `++ --` | `i++` 先用后加；`++i` 先加后用 |
| 比较 | `== != > < >= <=` | 结果是 boolean（true/false） |
| 逻辑 | `&& \|\| !` | `&&` 两边都真才真；`\|\|` 一边真就真；`!` 取反 |
| 赋值 | `= += -= *= /=` | `a += 5` 等于 `a = a + 5` |
| 三元 | `条件 ? 值1 : 值2` | 条件为真取值1，否则取值2 |

**短路**：`a && b` 如果 a 为假，b 不会执行（短路）；`a || b` 如果 a 为真，b 不会执行。

```java
int x = 5;
System.out.println(x++);   // 输出 5（先用后加），x 变成 6
System.out.println(++x);   // 输出 7（先加后用）
String s = (x > 6) ? "大" : "小";   // 三元：s = "大"
```

## 2. if / else if / else

```java
if (条件1) {
    // 条件1成立
} else if (条件2) {
    // 条件2成立
} else {
    // 都不成立
}
```

## 3. switch（JDK 14+ 箭头写法）

```java
switch (表达式) {
    case 值1 -> 语句;      // 匹配值1
    case 值2 -> 语句;
    default -> 语句;       // 都不匹配
}
```

老写法（case 穿透）每个 case 结尾必须 `break;`，否则会继续执行下一个 case——这是经典 bug 来源。

## 4. for 循环（适合"知道循环几次"）

```java
for (初始化; 条件; 步进) {
    // 循环体
}
// 例：从 1 数到 10
for (int i = 1; i <= 10; i++) {
    System.out.println(i);
}
```

## 5. while / do-while（适合"不知道几次，看条件"）

```java
while (条件) { }        // 先判断，条件为真才执行
do { } while (条件);    // 先执行一次，再判断（至少执行一次）
```

## 6. break / continue

- `break`：**跳出整个循环**
- `continue`：**跳过本次循环**，直接进入下一次

```java
for (int i = 1; i <= 10; i++) {
    if (i == 3) continue;   // 跳过 3，不打印
    if (i == 8) break;      // 到 8 直接跳出循环
    System.out.println(i);  // 打印 1 2 4 5 6 7
}
```

## 7. 常见坑（记住）

1. **字符串不能用 `==` 比较**（要用 equals，后面学到）——`==` 比的是地址
2. **浮点数不要用 `==` 比较**（0.1+0.2 ≠ 0.3 这种精度问题）
3. 老式 switch 忘写 `break` 会**穿透**执行后面的 case
4. 条件别写成死循环：`while (true)`、`for (;;)` 都是无限循环（有时候是有意为之，配合 break 用）
5. 逻辑优先级：`&&` 高于 `||`，不确定就加括号
